## 【几何】正四面体中特定角的余弦值

**难度：** ⭐⭐⭐（高中竞赛难度说明：立体几何 + 余弦定理/勾股定理的综合运用）

**题目来源：** [2022 AMC 12A Problem 12](https://wiki.randommath.com/amc12/2022/part-a/problem-12)

**知识点：** 正四面体 · 勾股定理 · 余弦定理

**题目：**

在正四面体 $ABCD$ 中，$M$ 是棱 $AB$ 的中点。求 $\cos(\angle CMD)$ 的值。

![正四面体 ABCD 与中点 M](/assets/math/2026-07-20-tetrahedron.svg)

---

### 解题过程

**方法一（利用重心与直角三角形）**

不妨设正四面体的棱长为 $2$。

1. 设 $O$ 为底面正三角形 $\triangle ABC$ 的重心，则 $DO \perp$ 平面 $ABC$。
2. 在 $\triangle BMC$ 中，由勾股定理：
   $$CM = \sqrt{BC^2 - BM^2} = \sqrt{2^2 - 1^2} = \sqrt{3}$$
   同理 $DM = \sqrt{3}$。
3. 由于 $O$ 是等边三角形重心，$OM = \dfrac{1}{3}CM = \dfrac{\sqrt{3}}{3}$。
4. 在直角三角形 $\triangle OMD$ 中（$DO \perp OM$）：
   $$\cos(\angle CMD) = \cos(\angle OMD) = \frac{OM}{DM} = \frac{\frac{\sqrt{3}}{3}}{\sqrt{3}} = \frac{1}{3}$$

**方法二（直接对 $\triangle CMD$ 用余弦定理）**

设 $CD = 2$，则 $CM = DM = \sqrt{3}$。在 $\triangle CMD$ 中由余弦定理：
$$\cos(\angle CMD) = \frac{CM^2 + DM^2 - CD^2}{2 \cdot CM \cdot DM}
= \frac{3 + 3 - 4}{2 \cdot \sqrt{3} \cdot \sqrt{3}}
= \frac{2}{6} = \frac{1}{3}$$

答案：$\boxed{\dfrac{1}{3}}$（选项 **B**）

---

### 常见错误

- 误以为 $M$ 到底面重心的距离等于中线的一半（实际是中线长的 $\frac{1}{3}$）。
- 把 $\angle CMD$ 当成二面角直接套用公式，忘记它本质上是 $\triangle CMD$ 的一个内角。
- 设棱长时未统一，造成 $CM$ 与 $DM$ 计算不一致。

---

### 知识背景

正四面体是最简单的正多面体，四个面都是全等的正三角形。它的高、重心、外心等中心重合于一点。本题的关键在于把空间角 $\angle CMD$ 投影到某个直角三角形中处理（方法一利用了"顶点到底面重心连线垂直于底面"这一性质），或直接用余弦定理在 $\triangle CMD$ 中计算。该角约为 $70.53^\circ$，由于它不是 $180^\circ$ 的整数因子，正四面体无法像立方体那样密铺三维空间。

## 【数论】循环小数的数位谜题

**难度：** ⭐⭐⭐（高中竞赛难度说明：无限循环小数化分数 + 同余方程）

**题目来源：** [2022 AMC 10A Problem 17](https://wiki.randommath.com/amc10/2022/part-a/problem-17)

**知识点：** 循环小数 · 模运算 · 数位分析

**题目：**

有多少个三位数 $\underline{a}\ \underline{b}\ \underline{c}$（其中数字 $a,b,c$ 均非零），满足

$$0.\overline{abc} = \frac{1}{3}\left(0.\overline{a} + 0.\overline{b} + 0.\overline{c}\right)$$

（横线表示循环节，因此 $0.\overline{abc}$ 是无限循环小数 $0.abcabcabc\cdots$）

---

### 解题过程

1. 将循环小数化为分数：
   $$0.\overline{abc} = \frac{100a + 10b + c}{999}, \quad 0.\overline{a} = \frac{a}{9},\ 0.\overline{b} = \frac{b}{9},\ 0.\overline{c} = \frac{c}{9}$$
2. 代入原等式：
   $$\frac{100a + 10b + c}{999} = \frac{1}{3}\left(\frac{a}{9} + \frac{b}{9} + \frac{c}{9}\right) = \frac{a + b + c}{27}$$
3. 两边同乘 $999 = 27 \times 37$：
   $$100a + 10b + c = 37(a + b + c) = 37a + 37b + 37c$$
   整理得：
   $$63a = 27b + 36c \quad \Rightarrow \quad 7a = 3b + 4c$$
4. 对模 $7$ 化简：$3b \equiv -4c \equiv 3c \pmod{7}$，故 $b \equiv c \pmod{7}$。
5. 因 $b,c \in \{1,2,\dots,9\}$，满足 $b \equiv c \pmod 7$ 的有序数对为：
   $$(1,1),(2,2),\dots,(9,9),(1,8),(8,1),(2,9),(9,2)$$
   共 $13$ 组。每组中由 $7a = 3b + 4c$ 可唯一确定 $a$（且 $a$ 均为 $1\sim 9$ 的非零数字）。

对应的 $13$ 个三位数为：
$$111, 222, 333, 444, 555, 666, 777, 888, 999, 518, 481, 629, 592$$

答案：$\boxed{13}$（选项 **D**）

---

### 常见错误

- 循环小数化分数时把 $0.\overline{abc}$ 错写成 $\dfrac{abc}{1000}$（那是有限小数，不是循环）。
- 化简 $7a = 3b + 4c$ 时遗漏模 $7$ 同余的额外解 $(1,8),(8,1),(2,9),(9,2)$，只数了 $9$ 个。
- 忘记题目要求数字非零，误把含 $0$ 的组合也算进去。

---

### 知识背景

任何纯循环小数都可以化为分数：循环节为 $k$ 位时，分母是由 $k$ 个 $9$ 组成的数（如 $0.\overline{abc} = \frac{abc}{999}$），分子即循环节本身。本题把这一代数工具与模 $7$ 同余结合，是 AMC 中典型的"数论 + 代数"综合题。核心技巧在于将等式化为线性丢番图关系后，用同余缩小枚举范围。
