## 【初二】直线平移探索

**难度：** ⭐⭐（中等）

**题目来源：** [NRICH - Translating Lines](https://nrich.maths.org/1396)

**知识点：** 一次函数 · 直线方程 · 图形平移

**题目：**

在坐标系中，有一条红色直线，你可以拖动蓝色直线对其进行**上下平移**。

请探究：**当一条直线沿竖直方向平移时，它的方程会发生怎样的变化？**

1. 设红色直线的方程为 $y = 2x + 1$，将其向上平移 3 个单位后，新直线的方程是什么？
2. 设直线 $y = kx + b$ 向上平移 $m$ 个单位，向右平移 $n$ 个单位，新直线方程是什么？
3. 平移变换会改变直线的斜率吗？请说明理由。

---

### 解题过程

**第1小问：**

直线向上平移 $c$ 个单位，意味着纵截距增大 $c$：

$$y = 2x + 1 \xrightarrow{上移3} y = 2x + (1+3) = 2x + 4$$

**验证：** 原直线上点 $(0, 1)$，平移后变为 $(0, 4)$，满足新方程 $y = 2(0)+4=4$ ✓

**第2小问：**

将直线 $y = kx + b$ 进行复合平移：
- 向上平移 $m$：$y = kx + b + m$
- 向右平移 $n$（将 $x$ 替换为 $x-n$）：

$$y = k(x - n) + b + m = kx - kn + b + m$$

所以新方程为：$y = kx + (b + m - kn)$

**第3小问：**

平移不改变斜率！因为平移是**刚性变换**——直线的方向（斜率）保持不变，只有位置（截距）改变。

代数上：新方程 $y = kx + (b + m - kn)$ 的斜率仍然是 $k$。

---

### 常见错误

- **向右平移混淆方向**：直线右移 $n$ 时，应将 $x$ 替换为 $x-n$（减号不是加号！）
- **误以为平移改变斜率**：斜率 $k$ 反映直线的"倾斜程度"，平移不改变倾斜方向

---

### 知识背景

直线 $y = kx + b$ 中，$k$ 是斜率（决定倾斜程度），$b$ 是纵截距（决定与 $y$ 轴的交点位置）。平移变换属于"刚性变换"，只改变位置，不改变形状和方向。在初中数学中，理解"平移如何改变方程"是学习函数图像变换的基础，也是高中学习三角函数图像变换（$y = A\sin(\omega x + \varphi)$）的重要铺垫。

## 【初三】方位角计算

**难度：** ⭐⭐⭐（较难）

**题目来源：** [NRICH - Overbearing](https://nrich.maths.org/6263)

**知识点：** 三角函数 · 方位角 · 余弦定理

**题目：**

在一个村庄中：
- **酒馆**在**学校正北方** $300 \text{ m}$ 处
- **教堂**在酒馆的北偏东 $60°$ 方向（方位角 $060°$）处，距酒馆 $300 \text{ m}$

**求：学校在教堂的什么方位角方向？**

（方位角从正北顺时针计量，范围 $0° \sim 360°$）

---

### 解题过程

**建立坐标系：** 以学校为原点，正北为 $y$ 轴正方向，正东为 $x$ 轴正方向。

**确定各点坐标：**
- 学校 $S = (0, 0)$
- 酒馆在学校正北 300 m：$P = (0, 300)$
- 教堂在酒馆方位角 $060°$ 方向 300 m处：

$$C_x = 0 + 300\sin 60° = 300 \cdot \frac{\sqrt{3}}{2} = 150\sqrt{3}$$
$$C_y = 300 + 300\cos 60° = 300 + 150 = 450$$

所以教堂 $C = (150\sqrt{3},\ 450)$

**求学校相对于教堂的方向：**

从教堂看学校，位移向量为：
$$\vec{CS} = S - C = (0 - 150\sqrt{3},\ 0 - 450) = (-150\sqrt{3},\ -450)$$

方位角从正北（$y$ 轴正方向）顺时针计量。$\vec{CS}$ 指向西南方向。

$$\tan\theta = \frac{|x\text{分量}|}{|y\text{分量}|} = \frac{150\sqrt{3}}{450} = \frac{\sqrt{3}}{3}$$

$$\theta = 30°$$

由于向量在西南方向（$x < 0, y < 0$），方位角 $= 180° + 30° = 210°$

**答：学校在教堂的方位角 $210°$（南偏西 $30°$）方向。**

---

### 解题验证

用余弦定理检验 $SC$ 距离：

$$SC = \sqrt{(150\sqrt{3})^2 + 450^2} = \sqrt{67500 + 202500} = \sqrt{270000} = 300\sqrt{3} \approx 519.6 \text{ m}$$

也可以通过等边三角形性质验证：$SP = PC = 300$，$\angle SPC = 360° - 360° + 60° = 60°$（计算酒馆处的内角），可判断 $\triangle SPC$ 为等边三角形（三边相等），但实际 $SC = 300\sqrt{3} \neq 300$，说明不是等边三角形，需用坐标法精确计算。✓

---

### 常见错误

- **方位角方向混淆**：方位角从正北顺时针，不是从 $x$ 轴逆时针的数学角
- **直接用"方位角 = 反正切值"**：需要根据象限判断最终方位角是在哪个范围

---

### 知识背景

方位角（Bearing）是导航中的常用概念，在军事地图、航海、测量工程中广泛使用。初三数学中，方位角问题结合了三角函数、向量与坐标系知识，是综合应用题的经典类型。解题关键是建立坐标系，将文字描述转化为代数运算。中考和竞赛中，这类题目考查学生的空间想象力和三角函数的实际应用能力。
