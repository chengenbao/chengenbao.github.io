## 【概率】四枚骰子上的条件概率

**难度：** ⭐⭐⭐（高中竞赛中等难度）

**题目来源：** [2022 AMC 12B Problem 12](https://artofproblemsolving.com/wiki/index.php/2022_AMC_12B_Problems/Problem_12)

**知识点：** 对立事件 · 补集计数 · 容斥原理（PIE） · 独立重复试验

**题目：**

Kayla 同时掷四枚公平的六面骰子。求满足以下两个条件的事件的概率：
- 条件 A：至少有一枚骰子掷出的点数 **大于 4**（即出现 5 或 6）；
- 条件 B：至少有 **两枚** 骰子掷出的点数 **大于 2**（即出现 3、4、5 或 6）。

选项：

$$\textbf{(A)}\ \frac{2}{3} \qquad \textbf{(B)}\ \frac{19}{27} \qquad \textbf{(C)}\ \frac{59}{81} \qquad \textbf{(D)}\ \frac{61}{81} \qquad \textbf{(E)}\ \frac{7}{9}$$

---

### 解题过程

记一枚骰子：
- 大于 4（即 5 或 6）的概率：$\frac{2}{6} = \frac{1}{3}$
- 不大于 4（即 1、2、3、4）的概率：$\frac{4}{6} = \frac{2}{3}$
- 大于 2（即 3、4、5、6）的概率：$\frac{4}{6} = \frac{2}{3}$
- 不大于 2（即 1、2）的概率：$\frac{2}{6} = \frac{1}{3}$

我们用**补集计数**直接算“不满足条件”的概率，再用 1 减去它。

**第 1 步：条件 A 被违反**

条件 A 要求至少一枚 >4。它的反面是“四枚都 ≤4”，概率为：

$$\left(\frac{2}{3}\right)^4 = \frac{16}{81}$$

**第 2 步：条件 A 满足但条件 B 被违反**

此时必须“至少一枚 >4”，但“大于 2 的骰子少于两枚”。因为一枚 >4 的骰子必然也 >2，所以“大于 2 的骰子只有 1 枚”且这唯一一枚就是那枚 >4 的骰子。

即：恰有一枚掷出 5 或 6，其余三枚都 ≤2（即 1 或 2）：

$$\binom{4}{1}\cdot \frac{1}{3}\cdot \left(\frac{1}{3}\right)^3
= 4\cdot \frac{1}{3}\cdot \frac{1}{27}
= \frac{4}{81}$$

**第 3 步：合并（无重叠，可放心相减）**

上述“条件 A 违反”与“条件 A 满足但 B 违反”是互斥的（前者没有任何一枚 >4，后者恰好有一枚 >4），不会重复。于是所求概率为：

$$1 - \frac{16}{81} - \frac{4}{81} = 1 - \frac{20}{81} = \boxed{\frac{61}{81}}$$

对应选项 **(D)**。

> 另法（容斥 PIE）：直接算“A 违反”的概率 $\frac{16}{81}$，加上“B 违反”的概率 $\frac{9}{81}$，再减去两者同时违反（四枚全 ≤2 或恰一枚在 {3,4}）的重叠 $\frac{5}{81}$，同样得到 $1-(\frac{16}{81}+\frac{9}{81}-\frac{5}{81})=\frac{61}{81}$。

---

### 常见错误

- **漏掉“A 满足但 B 违反”这一层**：只减去 A 违反的 $\frac{16}{81}$，得到 $\frac{65}{81}$，恰好不是选项，说明还有“至少一枚>4 但只有这一枚>2”的坏情况要扣。
- **重复扣除重叠**：若用容斥却忘了减去“A、B 同时违反”的重叠部分，会得到错误数值；注意四枚全为 1 或 2 时两个反面同时发生。
- **混淆“大于 4”与“大于 2”的概率**：把 >4 当成 $\frac{1}{2}$ 或把 >2 当成 $\frac{1}{3}$ 都会算错。

---

### 知识背景

本题属于“条件概率 + 补集计数”。在竞赛中，当“至少……”“至多……”类条件出现时，直接计算往往要枚举很多种情况，而**先算它的反面（补集）再用 1 减**通常更简洁。当多个条件并存时，可用**容斥原理（PIE）**避免重复或遗漏：先分别减去各条件被违反的概率，再加回它们同时被违反的重叠部分。骰子的每一枚相互独立，因此可用“独立重复试验”的幂次快速求得联合概率。

## 【代数】三次方程根的对称式

**难度：** ⭐⭐⭐（高中竞赛中等偏上，含复数的技巧解法）

**题目来源：** [2024 AMC 12A Problem 15](https://artofproblemsolving.com/wiki/index.php/2024_AMC_12A_Problems/Problem_15)

**知识点：** 韦达定理（Vieta） · 多项式因式分解 · 复数代入法 · 根的对称多项式

**题目：**

设三次方程 $x^3 + 2x^2 - x + 3 = 0$ 的三个根分别为 $p,\,q,\,r$。求

$$(p^2 + 4)(q^2 + 4)(r^2 + 4)$$

的值。

选项：

$$\textbf{(A) } 64 \qquad \textbf{(B) } 75 \qquad \textbf{(C) } 100 \qquad \textbf{(D) } 125 \qquad \textbf{(E) } 144$$

---

### 解题过程

设 $f(x) = x^3 + 2x^2 - x + 3$。由因式定理，若 $p,q,r$ 是三根，则

$$f(x) = (x-p)(x-q)(x-r)$$

**关键一步（复数代入法）：** 注意到

$$p^2 + 4 = (p+2i)(p-2i)$$

同理对 $q,r$ 成立，于是

$$(p^2+4)(q^2+4)(r^2+4) = (p+2i)(p-2i)(q+2i)(q-2i)(r+2i)(r-2i)$$

把它重新配对：

$$= \big[(p+2i)(q+2i)(r+2i)\big]\cdot\big[(p-2i)(q-2i)(r-2i)\big]$$

而

$$(p+2i)(q+2i)(r+2i) = (-1)^3(-2i-p)(-2i-q)(-2i-r) = -f(-2i)?$$

更直接地，把 $x=2i$ 与 $x=-2i$ 代入 $f(x)=(x-p)(x-q)(x-r)$：

$$f(2i) = (2i-p)(2i-q)(2i-r) = -(p-2i)(q-2i)(r-2i)$$

$$f(-2i) = (-2i-p)(-2i-q)(-2i-r) = -(p+2i)(q+2i)(r+2i)$$

两式相乘，负号抵消：

$$(p+2i)(q+2i)(r+2i)(p-2i)(q-2i)(r-2i) = f(2i)\,f(-2i)$$

**计算 $f(2i)$ 与 $f(-2i)$：**

$$f(2i) = (2i)^3 + 2(2i)^2 - (2i) + 3
= -8i + 2(-4) - 2i + 3
= -8i - 8 - 2i + 3 = -5 - 10i$$

$$f(-2i) = (-2i)^3 + 2(-2i)^2 - (-2i) + 3
= 8i + 2(-4) + 2i + 3
= 8i - 8 + 2i + 3 = -5 + 10i$$

相乘（共轭相乘）：

$$f(2i)\,f(-2i) = (-5-10i)(-5+10i) = (-5)^2 - (10i)^2 = 25 - (-100) = 25 + 100 = 125$$

所以

$$(p^2+4)(q^2+4)(r^2+4) = \boxed{125}$$

对应选项 **(D)**。

> 纯实数法（韦达定理）：由 $f(x)$ 得 $p+q+r=-2,\; pq+qr+rp=-1,\; pqr=-3$。展开目标式后全部用基本对称式表示，同样得到 $9 + 4(-11) + 16(6) + 64 = 125$。

---

### 常见错误

- **复数运算符号错**：$(2i)^3 = 8i^3 = -8i$，$(2i)^2 = -4$，负号极易漏。
- **配对时忘记负号**：$(2i-p)=-(p-2i)$，三个因子各带一个负号，乘积是 $(-1)^3=-1$，两行相乘后负号正好抵消，不要误以为还剩负号。
- **硬解三次方程求根**：本题无需解出 $p,q,r$ 的具体值，用对称式/代入法才是最短路。

---

### 知识背景

本题是**韦达定理 + 多项式技巧**的经典题。对于一个以 $p,q,r$ 为根的多项式 $f(x)=(x-p)(x-q)(x-r)$，表达式 $(p-c)(q-c)(r-c)$ 恰好等于 $(-1)^3 f(c) = -f(c)$。把 $p^2+4$ 写成 $(p+2i)(p-2i)$ 后，整个乘积就转化为在 $x=\pm 2i$ 处求多项式值——把代数问题巧妙地“搬运”到复数点上求值，避开了直接展开与求根。这是 AMC/AIME 中处理“根的对称式”的常用套路。
