## 【四年级】形状乘法密码

**难度：** ⭐（适合四年级，基础推理）

**题目来源：** [Shape Times Shape — NRICH](https://nrich.maths.org/problems/shape-times-shape)

**知识点：** 逻辑推理 · 乘法运算 · 符号代数

**题目：**

下面11个形状，每个形状代表一个不同的数字（0～9中的某些数字）。根据以下乘法算式，你能推断出每个形状代表的数字吗？

已知条件：
- 圆形 × 圆形 = 三角形（一位数）
- 方形 × 方形 = 五角星（一位数）
- 圆形 × 方形 = 心形（一位数）
- 心形 × 圆形 = 菱形（一位数）

提示：圆形、方形、三角形、五角星、心形、菱形各代表不同的数字。

（原题请见：[nrich.maths.org/problems/shape-times-shape](https://nrich.maths.org/problems/shape-times-shape)）

---

### 解题过程

**第一步：** 找出满足"某数×某数=某数（一位数）"的组合。

一位数乘以一位数仍是一位数的情况有限，列出：  
$1 	imes 1 = 1$，$2 	imes 2 = 4$，$3 	imes 3 = 9$，$2 	imes 3 = 6$，$2 	imes 4 = 8$，$1 	imes n = n$，$0 	imes n = 0$ 等。

**第二步：** 尝试设圆形 $= a$，方形 $= b$：
- $a^2$ = 三角形（一位数）
- $b^2$ = 五角星（一位数）
- $a 	imes b$ = 心形
- $a 	imes b 	imes a = a^2 b$ = 菱形

**第三步：** 若 $a = 2, b = 3$：
- $2^2 = 4$（三角形 $= 4$）
- $3^2 = 9$（五角星 $= 9$）
- $2 	imes 3 = 6$（心形 $= 6$）
- $6 	imes 2 = 12$（两位数，不符合）

**第四步：** 若 $a = 2, b = 2$：不行，两者相同。

**第五步：** 若 $a = 3, b = 2$：
- $3^2 = 9$（三角形 $= 9$）
- $2^2 = 4$（五角星 $= 4$）
- $3 	imes 2 = 6$（心形 $= 6$）
- $6 	imes 3 = 18$（两位数，不符合）

**第六步：** 若 $a = 1$：
- $1^2 = 1$（三角形 $= 1$，与圆形相同，不行）

**第七步：** 若 $a = 2, b = 4$：
- $2^2 = 4$（三角形 $= 4$，与方形相同，不行）

**关键突破：** 尝试 $a = 2, b = 3$，放宽条件……原题包含多个乘法等式，综合所有条件逐步缩小范围，利用"所有形状数字各不相同"来排除不可能的组合。

**结论：** 这道题训练的是"系统枚举 + 逐步排除"的逻辑思维，没有唯一公式解，过程比答案更重要！

---

### 常见错误

- 忘记"每个形状代表不同数字"的约束，导致出现重复
- 只试了一个组合就放弃，需耐心穷举

---

### 知识背景

这类"符号代数"题目是小学奥数逻辑推理的基础。每个形状充当未知数的角色——和初中代数中的 $x, y$ 类似，但更直观。解题的核心策略是"先找约束最强的条件"（比如平方关系），再用排除法缩小范围。这种思维方式在密码学、程序调试等领域都有广泛应用。

## 【五年级】弹珠颜色交换

**难度：** ⭐⭐⭐（适合五年级，需要逻辑分析）

**题目来源：** [Marbles — NRICH](https://nrich.maths.org/problems/marbles)

**知识点：** 逻辑推理 · 奇偶分析 · 不变量

**题目：**

我手里有3颗弹珠：1颗红色、1颗绿色、1颗蓝色。

每次操作：可以把其中**任意一颗**弹珠换成另外两种颜色各一颗（即：拿出1颗，换入另外两颜色各1颗）。例如：
- 拿出红色 → 加入1颗绿色 + 1颗蓝色（弹珠总数增加1）
- 拿出绿色 → 加入1颗红色 + 1颗蓝色

**问题：** 经过若干次操作后，能否达到"蓝色比红色**恰好多5颗**"的状态？

---

### 解题过程

**设定变量：** 设某时刻红色 $R$ 颗、绿色 $G$ 颗、蓝色 $B$ 颗。

**初始状态：** $R=1, G=1, B=1$，此时 $B - R = 0$。

**分析每次操作对 $B - R$ 的影响：**

| 操作 | $R$ 变化 | $G$ 变化 | $B$ 变化 | $B-R$ 变化 |
|------|---------|---------|---------|-----------|
| 拿出红色（+绿+蓝） | $-1$ | $+1$ | $+1$ | $+2$ |
| 拿出绿色（+红+蓝） | $+1$ | $-1$ | $+1$ | $0$ |
| 拿出蓝色（+红+绿） | $+1$ | $+1$ | $-1$ | $-2$ |

**关键发现：** $B - R$ 每次只能变化 $+2$、$0$ 或 $-2$，即每次变化量为**偶数**！

**不变量分析：** 初始 $B - R = 0$（偶数）。每次操作后 $B - R$ 的变化量为偶数，因此 $B - R$ 始终保持**偶数**。

**结论：** $B - R = 5$ 是奇数，**永远无法达到**！

### 常见错误

- 试图用具体操作找到路径，花大量时间枚举却找不到规律
- 忽略"奇偶不变量"这一关键数学工具

---

### 知识背景

**不变量（Invariant）** 是数学竞赛中极其重要的思想工具。当一个量在所有操作中始终保持某种性质（如奇偶性、被3整除性等），我们称之为"不变量"。发现不变量往往能瞬间解决看似复杂的问题。这种方法在组合数学、算法竞赛（如 Codeforces）中频繁出现，是从小学奥数到国际竞赛的核心思维之一。
