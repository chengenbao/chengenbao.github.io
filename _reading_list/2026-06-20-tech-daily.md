## 2. 因果归因剪枝：保留 LLM 推理能力的免训练压缩方法

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2606.19350  
**标签**：模型剪枝 · 因果归因 · 推理能力 · LLM压缩 · 免训练

提出 Causal Attribution Pruning (CAP)，一种免训练的 LLM 剪枝方法，通过因果归因分析识别多步推理链中的关键权重，优先保留参与逻辑推导的神经元，在降低推理计算成本的同时保持 Chain-of-Thought 性能。

**核心要点**：
- 基于因果归因而非梯度/激活幅值识别对推理能力至关重要的权重子集
- 无需重新训练即可对 LLM 进行结构化剪枝，兼容主流模型（LLaMA、Qwen 等）
- 在 GSM8K、MATH 等推理基准上，剪枝后性能损失显著低于传统幅值剪枝方法

## 4. 数字 PIM 架构性能分析：以卷积神经网络为案例

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2305.04122  
**标签**：存内计算 · PIM · 数据移动 · CNN加速 · 硬件架构

以卷积神经网络为基准，系统评估数字 Processing-in-Memory (PIM) 架构的实际性能收益。研究揭示 PIM 在减少数据移动开销方面的潜力：内存密集型卷积层收益显著，计算密集型层仍受限于 in-memory 逻辑低频运行。

**核心要点**：
- 量化 PIM 架构在 CNN 推理中的数据移动减少量，对比传统 CPU/GPU 基线
- 分析不同卷积层（depthwise vs pointwise）在 PIM 上的性能差异与适配性
- 提出混合执行策略：内存密集算子卸载至 PIM，计算密集算子保留在 GPU/NPU

## 5. SPSD：基于边缘 Prompt 压缩的云端 LLM Prefill 节能框架

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.19364  
**标签**：Prompt压缩 · LLM推理 · Prefill优化 · 边缘计算 · 能耗优化

针对云端 LLM 服务中 Prefill 阶段的高能耗问题，提出 SPSD 框架，在边缘侧对用户 Prompt 进行语义保真压缩，减少传输至云端的 Token 数量，从而降低 Prefill 计算负荷，同时保持对话语义连贯性。

**核心要点**：
- 识别 LLM 推理中 Prefill 阶段为云端能耗主要来源，尤其在长对话场景下
- SPSD 在边缘设备进行轻量语义压缩，保留社交语义同时降低 60%+ Token 传输量
- 端云协同推理框架在多个对话基准上验证，质量损失可控、延迟显著下降

## 6. 解耦跨语言迁移中的语言相关性与任务对齐

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2606.19346  
**标签**：跨语言迁移 · 多语言LLM · Zero-shot · 任务对齐 · 微调

通过对 7 个大语言模型（4B-671B 参数）在阿拉伯语上微调后零样本迁移的系统实验，解耦语言亲缘性与任务对齐两个独立因素，揭示大规模模型中任务对齐相比语言相似度的更强主导作用。

**核心要点**：
- 在 4B 到 671B 参数范围内系统研究语言亲缘性与任务对齐对跨语言迁移的独立贡献
- 发现模型规模越大，任务对齐效应越显著，语言相似度的影响相对减弱
- 为多语言 LLM 的微调策略提供实证支撑：大模型可从语言无关的任务数据中充分受益
