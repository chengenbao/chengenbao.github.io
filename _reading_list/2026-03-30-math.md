## 【四年级】数轴上的等距整数

**难度：** ⭐⭐（AMC 8 前段 · 算术数列）

**题目来源：** [2026 AMC 8 Problem 14](https://wiki.randommath.com/amc8/2026/problem-14)（官方答案：**B**）

**题目：** Jami 在数轴上取了三个等距排列的整数。第一个数与第二个数之和为 $40$，第二个数与第三个数之和为 $60$。求这三个数的总和。

（A）70　（B）75　（C）80　（D）85　（E）90

### 解题过程

**设中间数，用"等距"条件：**

三个整数等距排列，设中间的数为 $n$，公差为 $d$，则三数为 $n-d,\ n,\ n+d$。

**翻译两个条件：**

$$(n-d) + n = 40 \implies 2n - d = 40$$
$$n + (n+d) = 60 \implies 2n + d = 60$$

**两式相加：**

$$4n = 100 \implies n = 25$$

代回得 $d = 60 - 2n = 10$，三个数为 $15,\ 25,\ 35$。

**求和：**

$$15 + 25 + 35 = 3 \times 25 = \boxed{75}$$

故选 **（B）**。

**速算技巧：** 等距数列中，首尾之和等于中间数的两倍，因此三数之和就是"中间数 × 3"。而 $40 + 60 = 100$ 恰好等于 $2 \times (n-d) + 2 \times n + 2 \times (n+d)$……不对，$40+60 = (a_1+a_2)+(a_2+a_3) = (a_1+a_2+a_3) + a_2 = S + n$。所以 $S = 100 - n$，再由两条件之差 $2d = 20 \Rightarrow d=10$，$a_2 = 40+d = 25$，$S = 75$。两条路殊途同归。

### 知识背景

等差（等距）数列的核心性质是"对称项之和相等"：$a_{k-1} + a_{k+1} = 2a_k$。AMC 8 前段题常围绕这一性质做文章，设"中间数"往往比设"第一个数"计算量更小。

## 【初二】把 60 写成连续奇数之和

**难度：** ⭐⭐⭐⭐（AMC 8 后段 · 数论与计数综合）

**题目来源：** [2026 AMC 8 Problem 18](https://wiki.randommath.com/amc8/2026/problem-18)（官方答案：**B**）

**题目：** 把 $60$ 写成两个或更多个**连续奇正整数**之和（按从小到大排列），共有多少种写法？

（A）1　（B）2　（C）3　（D）4　（E）5

### 解题过程

**建立通式：**

设从奇数 $2k+1$ 开始，连续 $m$ 个（$m \ge 2$）奇数之和：

$$S = (2k+1) + (2k+3) + \cdots + (2k+2m-1) = m(2k + m)$$

（首项加末项的平均即 $2k+m$，共 $m$ 项。）

**代入 $S = 60$：**

$$m(2k+m) = 60$$

由于 $m$ 与 $2k+m$ 同奇偶（相差 $2k$ 为偶数），且 $2k \ge 0$、$m \ge 2$，枚举 $m \mid 60$：

- $m = 2$：$2k+m = 30 \Rightarrow k = 14$，即 $29 + 31 = 60$ ✓
- $m = 3$：$2k+m = 20 \Rightarrow 2k = 17$ 非偶，舍去
- $m = 4$：$2k+m = 15$，$15 - 4 = 11$ 为奇，舍去（$2k = 11$ 非偶）
- $m = 5$：$2k+m = 12 \Rightarrow k = 3.5$ 舍去
- $m = 6$：$2k+m = 10 \Rightarrow k = 2$，即 $5+7+9+11+13+15 = 60$ ✓
- $m = 10$：$2k+m = 6 < 10 = m$，首项 $2k+1 < 0$，舍去
- 更大的因子同理舍去

**结论：** 恰有 $2$ 种写法（$29+31$ 与 $5+7+9+11+13+15$），故选 **（B）**。

**另解（奇偶长度视角）：** 连续奇数之和的项数为奇数时，和 = 中间项 × 项数，中间项必为奇数；项数为偶数时，和 = (中间两项之和) × (项数/2)，中间两项之和为偶数。对 $60 = 2^2 \times 3 \times 5$，配对"长度 × 平均值"且平均值为整数：$(2,30), (4,15), (6,10), (10,6), (12,5)\ldots$ 再逐一验证首项为正奇数，同样只剩 2 种。

### 知识背景

"连续奇数求和"有优美的图形解释：$1+3+5+\cdots+(2m-1) = m^2$（L 形折叠拼正方形）。一般地 $m$ 个连续奇数之和是一个"平移过的平方数" $m(2k+m)$，所以本题本质上是问 $60$ 有多少种"面积 $60$、边长 $m$ 与 $2k+m$ 同奇偶"的矩形拆分。同类技巧也用于"连续整数/连续偶数拆分"计数。
