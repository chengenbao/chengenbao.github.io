## 【代数】每个整数出现 n 次的中位数

**难度：** ⭐⭐⭐⭐（高中竞赛 / AMC 12 第 16 题）

**题目来源：** [2021 AMC 12A Problem 16](https://live.poshenloh.com/past-contests/amc12/2021A/problem/16)

**知识点：** 三角形数 · 中位数（统计）

**题目：**

在下面的数列中，对每个满足 \(1 \le n \le 200\) 的整数 \(n\)，整数 \(n\) 在数列中出现 \(n\) 次：
\[1,\ 2,\ 2,\ 3,\ 3,\ 3,\ 4,\ 4,\ 4,\ 4,\ \ldots,\ 200,\ 200,\ \ldots,\ 200.\]
求这列数的中位数。

- (A) \(100.5\)
- (B) \(134\)
- (C) \(142\)
- (D) \(150.5\)
- (E) \(167\)

---

### 解题过程

**第 1 步：数清总项数。** 整数 \(n\) 出现 \(n\) 次，总项数为
\[1 + 2 + \cdots + 200 = \dfrac{200\cdot 201}{2} = 20100.\]

**第 2 步：定位中位数。** 项数为偶数 \(20100\)，中位数是第 \(\frac{20100}{2} = 10050\) 项与第 \(10051\) 项的平均数。

**第 3 步：找出第 \(10050\)、\(10051\) 项落在哪个"块"里。** 整数 \(1,2,\dots,n\) 一共占据前
\[\dfrac{n(n+1)}{2}\]
个位置（三角形数）。计算：
\[\dfrac{141\cdot 142}{2} = 10011,\qquad \dfrac{142\cdot 143}{2} = 10153.\]
所以整数 \(141\) 占据第 \(9871\sim 10011\) 位（因为 \(\frac{140\cdot141}{2}=9870\)），整数 \(142\) 占据第 \(10012\sim 10153\) 位。

第 \(10050\) 项和第 \(10051\) 项都落在 \(10012\sim 10153\) 这个区间内，即它们都等于 \(142\)。

**第 4 步：求中位数。**
\[\text{中位数} = \dfrac{142 + 142}{2} = 142.\]

**答案：(C) 142**

---

### 常见错误

- 忘记总项数是偶数时要取第 \(10050\) 与 \(10051\) 两项的**平均**；不过本题两项恰好相等，若它们不同（如 \(141\) 与 \(142\)），就会算出 \(141.5\) 之类的错误值。
- 解不等式 \(\frac{n(n+1)}2 \ge 10050\) 时估算失误（如取 \(n=141\) 就停下）：应检查 \(10050 > 10011\)，确认还没到达 \(141\) 块的末尾，必须继续到 \(n=142\)。

---

### 知识背景

"每个 \(n\) 重复 \(n\) 次"的数列，其位置由三角形数 \(T_n = \frac{n(n+1)}2\) 界定；定位某个位置对应的数值，本质是解"三角形数 ≥ 位置"的最小 \(n\)，常用配方法 \(n \approx \frac{\sqrt{1+8k}-1}{2}\) 估计再微调。中位数则只需"数总项数 → 定中位位置 → 找所属块"三步，是统计量与数列分块思想的简洁结合。

## 【几何】十一线段五边形的双根号面积

**难度：** ⭐⭐⭐⭐⭐（高中竞赛 / AMC 12 第 15 题）

**题目来源：** [2021 AMC 12B Problem 15](https://live.poshenloh.com/past-contests/amc12/2021B/problem/15)

**知识点：** 圆的几何 · 坐标几何 · 鞋带公式

**题目：**

下图由 \(11\) 条线段构成，每条线段的长度都是 \(2\)。五边形 \(ABCDE\) 的面积可以写成 \(\sqrt m+\sqrt n\)，其中 \(m\) 和 \(n\) 是正整数。求 \(m+n\)。

（图示：五边形 \(ABCDE\) 的每条边及从每个顶点连向内部某点的线段都长 \(2\)；两个内部点分别与相邻三个外顶点相连，形成两个等边三角形簇的对称结构。）

- (A) \(20\)
- (B) \(21\)
- (C) \(22\)
- (D) \(23\)
- (E) \(24\)

---

### 解题过程

**第 1 步：读图——内部点是"圆心"。** 图中每个内部点到它相连的三个外顶点的距离都是 \(2\)，即：右侧内部点 \(P\) 满足 \(PA=PB=PC=2\)，所以 \(A,B,C\) 三点在以 \(P\) 为圆心、半径 \(2\) 的圆上。又已知弦 \(AB\) 和 \(BC\) 的长度也等于 \(2\)（边长），而半径也是 \(2\)：**弦长等于半径的弦对圆心角 \(60^\circ\)**。于是 \(\angle APC = \angle APB + \angle BPC = 60^\circ+60^\circ = 120^\circ\)，弦
\[AC = 2\cdot 2\cdot\sin 60^\circ = 2\sqrt3.\]
由对称性，左半部分完全相同：左侧内部点到 \(C,D,E\) 的距离也都是 \(2\)，且 \(CD = DE = 2\)，同样得 \(AC = AD = 2\sqrt3\)，整体关于 \(AC\)（或对称轴）镜像对称。

**第 2 步：建立坐标系。** 取对称轴为 \(y\) 轴，令
\[C = (-1, 0),\qquad D = (1, 0),\qquad A = (0, h).\]
由 \(AD = 2\sqrt3\)：\(h^2 + 1^2 = (2\sqrt3)^2 = 12\)，得 \(h = \sqrt{11}\)，即 \(A = (0, \sqrt{11})\)（\(C, D\) 的中点是 \((0,0)\)，\(A\) 在其正上方）。

**第 3 步：求出 \(B\) 和 \(E\) 的坐标。** \(B\) 是以 \(A\) 为圆心半径 \(2\)、以 \(C\) 为圆心半径 \(2\) 的两圆的另一个交点（一个在圆心连线上方——即内部点方向，另一个交点就是 \(B\)）。解两圆方程可得
\[B=\left(-\tfrac12-\tfrac{\sqrt{11}}{2\sqrt3},\ \tfrac{\sqrt{11}}2+\tfrac{1}{2\sqrt3}\right),\]
而 \(E\) 是 \(B\) 关于 \(y\) 轴的镜像：\(E=\left(\tfrac12+\tfrac{\sqrt{11}}{2\sqrt3},\ \tfrac{\sqrt{11}}2+\tfrac{1}{2\sqrt3}\right)\)。

**第 4 步：鞋带公式求五边形面积。** 依次列出 \(A, B, C, D, E\) 应用鞋带公式（交叉项两两相减后取绝对值、除以 \(2\)），化简得
\[[ABCDE] = \sqrt{11} + 2\sqrt3.\]
把它写成双根号之和：
\[\sqrt{11} + 2\sqrt3 = \sqrt{11} + \sqrt{12},\]
所以 \(m = 11\)，\(n = 12\)。

**第 5 步：求和。**
\[m + n = 11 + 12 = 23.\]

**答案：(D) 23**

---

### 常见错误

- 把"边长 = 内连线段长 = 2"这个条件读错（图中 11 条线段全部等长，包括内部连线）；若漏掉某个等长关系，\(\angle APC = 120^\circ\) 就推不出来。
- 最后化简 \(2\sqrt3 = \sqrt{12}\) 时把 \(m,n\) 取成 \(2\) 和 \(3\)（直接用 \(\sqrt m + \sqrt n\) 对应 \(\sqrt{11}+2\sqrt3\) 的系数），忘记题目要求的是"根号下整数"形式，导致 \(m+n = 14\) 之类的答案。

---

### 知识背景

"多个等长线段交汇"的图形里，等距点就是外接圆圆心——把线段网络翻译成"弦长 = 半径 ⟹ 圆心角 \(60^\circ\)"是本题的破题点。随后进入标准流程：对称选系 → 勾股定坐标 → 鞋带公式算面积。鞋带公式（shoelace formula）对任意多边形都适用：\([\,\cdot\,]=\frac12\left|\sum (x_i y_{i+1} - x_{i+1} y_i)\right|\)，配合坐标对称性可把"看起来要拆成许多三角形"的面积计算压成一次代数化简。
