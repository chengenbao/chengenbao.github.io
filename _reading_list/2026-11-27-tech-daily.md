## 2. MixMoMo：混合精度 GPU-NPU 协同加速移动端超大 MoE 模型推理

**核心要点**：
- 面向移动设备，将 MoE 专家以混合精度在 GPU 与 NPU 上协同执行
- 结合模型压缩与专家卸载，缓解细粒度专家带来的加载与计算压力
- 在端侧有限算力与带宽约束下实现超大 MoE 模型高效推理

## 3. 门控 Delta 网络中的滑动窗口注意力：用单 token 承载多重知识

**核心要点**：
- 从测试时回归视角重塑线性注意力，将循环状态视为在线回归模型
- 在门控 Delta 网络中引入滑动窗口注意力，增强单 token 的历史承载
- 在线性复杂度下改善长序列记忆，降低显存与计算开销

## 4. KiRA：基于 Kronecker 输入门控秩自适应的参数高效微调方法

**来源**：cs.LG  
**链接**：https://arxiv.org/abs/2611.33236  
**标签**：PEFT · LoRA · Kronecker积 · 输入自适应

全量微调大模型成本高昂，低秩自适应（LoRA）等 PEFT 方法成为标准替代，但其更新秩固定且对所有输入一致。KiRA 提出 Kronecker 输入门控秩自适应，利用 Kronecker 积结构并结合输入自适应门控，使模型针对不同输入动态调节适配容量，在更少参数的前提下提升预训练模型的微调效果与表达能力。

**核心要点**：
- 用 Kronecker 积结构构造参数高效的低秩更新，降低存储与训练成本
- 引入输入自适应门控，让适配容量随输入动态变化
- 在更少可训练参数的情况下提升微调效果与表达能力

- 在保持认证精度的同时显著提升神经网络验证效率
