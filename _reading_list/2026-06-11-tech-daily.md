## 1. 时间序列即语言：面向通用时序预测的统一分词器

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.09861  
**标签**：时间序列 · 分词器 · LLM · 统一建模 · 预测

提出将时间序列统一编码为语言 token 的 Universal Tokenizer，使大型语言模型可以直接处理任意粒度和域的时序数据。核心设计通过自适应分段量化将连续信号映射到离散词表，突破了传统时序基础模型对固定采样频率的依赖。在多个公开预测基准上实现 zero-shot 迁移，展示出「时间序列即语言」范式的跨域泛化能力。

**核心要点**：
- 自适应分段量化将连续时序信号映射到离散 token，兼容任意采样频率
- 统一词表设计使单一 LLM 可处理气候、金融、医疗等多领域时序数据
- Zero-shot 场景下超越多个领域专用时序基础模型

## 2. KV Cache 量化导致的对齐崩溃：诊断与修复

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.09864  
**标签**：KV Cache · 量化 · 推理效率 · 对齐崩溃 · LLM

发现并系统分析了对 KV Cache 执行激进量化（INT4/INT2）时引发的对齐行为崩溃现象——模型安全对齐与指令遵循性能骤降，而困惑度几乎不变。通过信息论分析将根因定位为关键注意力头的量化误差累积，并提出混合精度 KV Cache 分配方案，在维持显存压缩比的同时恢复对齐质量。

**核心要点**：
- 首次揭示 KV Cache 量化与对齐行为崩溃之间的直接因果关系
- 定位到少数高影响力注意力头是量化误差的主要来源
- 混合精度方案在 INT4 压缩比下对齐分数恢复至 FP16 基线的 96% 以上

## 3. 对齐算法机制分析：PPO/DPO/GRPO 如何改变模型内部表征

**链接**：https://arxiv.org/abs/2606.09850  
**标签**：对齐算法 · 可解释性 · DPO · GRPO · PPO · 表征分析

对六种主流对齐算法（PPO、DPO、SimPO、ORPO、GRPO、KTO）进行系统性机制分析，综合使用逐层线性探针、稀疏自编码器和跨层解码器定位偏好表征。研究发现不同目标引发截然不同的几何变换：KTO/GRPO 通过特征共享增强线性可分性，DPO/ORPO 则引入非构建性旋转和特征衰减导致可分性下降。

**核心要点**：
- 首个系统比较六种对齐方法在三大开源模型族上的内部表征变化
- KTO 和 GRPO 通过稀疏高显著性特征招募提升线性可分性
- DPO/ORPO 的几何旋转机制揭示了其在某些任务上不稳定的根本原因

## 4. EstRTL：函数估计引导的 RTL 代码自动生成

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2606.09867  
**标签**：RTL · 代码生成 · LLM · 硬件设计 · 电路综合

提出 EstRTL 框架，利用功能估计模型引导 LLM 生成 RTL 硬件描述代码。核心思路是在 LLM 采样过程中引入轻量级电路功能验证器，对候选 RTL 片段进行即时反馈，从而将硬件设计自动化中的错误率显著降低。实验在多个标准电路生成基准上超越先前 LLM 直接生成方案。

**核心要点**：
- 将功能估计反馈嵌入 LLM 解码循环，实现 RTL 生成的实时纠错
- 无需大规模 RTL 训练数据，通过合成功能样本进行轻量估计器训练
- 在 VerilogEval 等标准基准上将功能正确率提升 20%+

## 5. SPARX：边缘 RISC-V 上隐私感知的近似 CNN 加速

**链接**：https://arxiv.org/abs/2606.09946  
**标签**：CNN加速 · RISC-V · 近似计算 · 隐私保护 · 边缘推理

设计 SPARX 系统，在边缘 RISC-V SoC 上实现安全且隐私感知的近似 CNN 推理加速。通过将近似计算策略与可信执行环境（TEE）协同设计，在功耗和延迟受限的边缘场景下保障推理数据机密性。系统在 ResNet/MobileNet 等模型上验证，精度损失可控（<1%）的前提下实现 3x+ 能效提升。

**核心要点**：
- 近似计算与 TEE 协同设计，首次在 RISC-V 边缘 SoC 上实现安全近似推理
- 自适应近似策略根据层敏感度动态调整计算精度，最小化精度损失
- 在 ImageNet 基准上能效比提升 3.2 倍，精度下降低于 1%

## 6. GRAU：面向神经网络加速器的通用可重配激活单元

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2602.22352  
**标签**：神经网络加速器 · 激活函数 · 可重配硬件 · FPGA · 推理加速

提出 GRAU（Generic Reconfigurable Activation Unit），一种可在单一硬件单元上支持任意激活函数（ReLU、GELU、SiLU、Swish 等）的可重配设计。通过分段线性近似结合可编程查找表，GRAU 无需为每种激活函数单独设计电路，极大降低神经网络加速器的设计复杂度和面积开销。

**核心要点**：
- 分段线性近似 + 可编程 LUT 实现任意激活函数的统一硬件支持
- 相比专用激活单元节省约 40% 面积，同时支持运行时重配置
- 在 FPGA 上验证，支持 Transformer 中 GELU/SiLU 等复杂激活的高效执行
