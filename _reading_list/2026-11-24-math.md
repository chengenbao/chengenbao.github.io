## 【组合】彩色立方塔的排列计数

**难度：** ⭐⭐⭐（高中竞赛难度 · 多重集排列 / 分类讨论）

**题目来源：** [2019 AMC 10A Problem 17](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_17)

**知识点：** 排列组合 · 多重集排列数（多项式系数）· 分类讨论

**题目：**

一个小孩用形状相同但颜色不同的立方体积木搭塔。他手上有 $2$ 个红色方块、$3$ 个蓝色方块和 $4$ 个绿色方块。他要搭一座高度为 $8$ 个方块的塔（因此会有 $1$ 个方块剩下不用）。问他一共可以搭出多少座**不同**的塔？

$\textbf{(A) } 24 \qquad\textbf{(B) } 288 \qquad\textbf{(C) } 312 \qquad\textbf{(D) } 1,260 \qquad\textbf{(E) } 40,320$

---

### 解题过程

高度固定为 $8$，总共有 $2+3+4=9$ 个方块，必须**恰好剩下 $1$ 个**。按"剩下哪种颜色的方块"分类：

**情况 1：剩下 $1$ 个红色方块**
使用的方块为：红 $1$、蓝 $3$、绿 $4$，共 $8$ 个。
不同排列数（多重集排列）：
$$ \frac{8!}{1!\,3!\,4!} = \frac{40320}{1\cdot 6\cdot 24} = \frac{40320}{144} = 280 $$

**情况 2：剩下 $1$ 个蓝色方块**
使用的方块为：红 $2$、蓝 $2$、绿 $4$，共 $8$ 个。
$$ \frac{8!}{2!\,2!\,4!} = \frac{40320}{2\cdot 2\cdot 24} = \frac{40320}{96} = 420 $$

**情况 3：剩下 $1$ 个绿色方块**
使用的方块为：红 $2$、蓝 $3$、绿 $3$，共 $8$ 个。
$$ \frac{8!}{2!\,3!\,3!} = \frac{40320}{2\cdot 6\cdot 6} = \frac{40320}{72} = 560 $$

三类互不重叠，总数相加：
$$ 280 + 420 + 560 = 1260 $$

因此答案为 **$\textbf{(D) } 1{,}260$**。

---

### 常见错误

- **只算一种剩余情况**：忘记"剩下 $1$ 个方块"有三种可能，直接算 $8!/(2!3!4!)$ 会漏掉大部分。
- **误用全排列**：把 $9$ 个方块全排列再除以重复度，得到 $9!/(2!3!4!)=1260$ 只是巧合数值相同，但逻辑错误（塔高只有 $8$）。
- **重复计数**：三类剩余情况互不相交，不必再乘组合数。

---

### 知识背景

多重集排列是组合数学中的基本工具：若共有 $n$ 个物品，其中第 $i$ 类有 $n_i$ 个相同物品（$\sum n_i = n$），则不同排列数为 $\frac{n!}{n_1!n_2!\cdots n_k!}$。本题中由于总数比塔高多 $1$，需先按"被排除的颜色"分类，再对每种情况套用公式，是 AMC 10 中典型的"先分类、后计数"题型。

## 【概率】抛硬币直到出现连续相同面的概率

**难度：** ⭐⭐⭐（高中竞赛难度 · 停时问题 / 条件与绝对概率）

**题目来源：** [2019 AMC 10B Problem 21](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10B_Problems/Problem_21)

**知识点：** 概率 · 停时（stopping time）· 序列枚举与权重

**题目：**

Debra 反复抛一枚均匀硬币，记录到目前为止看到的正面（H）和反面（T）的总数，直到她**连续看到两个正面或两个反面**时才停止。求：她以"连续两个正面"结束，并且在看到第二个正面**之前**已经看到过第二个反面的概率是多少？

$\textbf{(A) } \frac{1}{36} \qquad \textbf{(B) } \frac{1}{24} \qquad \textbf{(C) } \frac{1}{18} \qquad \textbf{(D) } \frac{1}{12} \qquad \textbf{(E) } \frac{1}{6}$

---

### 解题过程

因为她以"连续两个正面（HH）"结束，序列的最后两位必为 `HH`。为避免在这之前就已经停止，序列在此之前必须是**严格交替**的。由于结尾是 `HH`，倒数第三位必须是 `T`（否则会出现更早的 `HH`），即序列形如：

$$ \cdots T\,H\,H $$

"在看到第二个正面之前已经看到第二个反面"，等价于：整个序列中第 $2$ 个 `T` 出现的位置，早于第 $2$ 个 `H` 出现的位置。

由于结尾 `HH` 提供了两个 `H`，而前缀交替，我们按交替前缀的长度枚举（前缀以 `T` 结尾，紧跟 `THH`）：

- 前缀为空（即序列就是 `THH`，长度 $3$）：出现 $1$ 个 T、$2$ 个 H → 没有第二个 T，**不满足**。
- 前缀 `HT`（序列 `HTHH`，长度 $4$）：T 出现 $1$ 次，仍无第二个 T，**不满足**。
- 前缀 `THT`（序列 `THTHH`，长度 $5$）：T 出现 $2$ 次（位置 1、3），H 出现 $2$ 次（位置 2 为第 1 个 H，位置 4 为第 2 个 H）。第 $2$ 个 T（位置 3）早于第 $2$ 个 H（位置 4）✓。概率权重 $(1/2)^5 = 1/32$。
- 前缀 `HTHT`（序列 `HTHTHH`，长度 $6$）：T 出现 $2$ 次（位置 2、4），H 出现 $3$ 次（位置 1、3、5）。第 $2$ 个 T（位置 4）早于第 $2$ 个 H（位置 3）？否（位置 3 < 4），**不满足**。
- 前缀 `THTHT`（序列 `THTHTHH`，长度 $7$）：T 位置 1、3、5；H 位置 2、4、6。第 $2$ 个 T（位置 3）早于第 $2$ 个 H（位置 4）✓。权重 $(1/2)^7 = 1/128$。
- 一般地，满足条件的前缀长度为奇数个交替字符（以 T 结尾），即前缀 `THT…T`（共 $2k+1$ 个字符，含 $k+1$ 个 T 和 $k$ 个 H），后面接 `HH`。

满足序列长度依次为 $5, 7, 9, \dots$，对应概率：
$$ \frac{1}{2^5} + \frac{1}{2^7} + \frac{1}{2^9} + \cdots = \frac{1/32}{1 - 1/4} = \frac{1/32}{3/4} = \frac{1}{32}\cdot\frac{4}{3} = \frac{1}{24} $$

因此答案为 **$\textbf{(B) } \frac{1}{24}$**。

> 注：若问"在已知以 HH 结束的条件下"的概率，则为 $2/3$；但本题问的是**绝对概率**，即 $1/24$。

---

### 常见错误

- **混淆条件概率与绝对概率**：算出"以 HH 结束的条件下，满足第二个 T 先到"占 $2/3$，却忘了乘以"以 HH 结束"本身的概率 $1/4$（或等价地，直接对无限序列加权求和），从而误选 (E) $1/6$。
- **漏掉"第二个 T 先于第二个 H"约束**：仅枚举以 HH 结束的序列，忘记筛选 T 的时序条件。
- **序列长度无界**：停止时间可能任意长，必须用无穷等比级数求和，不能只算前几项。

---

### 知识背景

这是一道经典的"停时（stopping time）"概率题。核心思想是：先刻画所有"合法停止序列"的结构（交替前缀 + 末尾连续相同），再对每个序列按其长度赋予正确权重 $(1/2)^L$ 并求和。把组合结构与概率权重结合，是 AMC 10/12 概率压轴题的常见套路。
