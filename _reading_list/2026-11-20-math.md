## 【几何】无限花纹的刚体自同构变换

**难度：** ⭐⭐⭐（高中竞赛难度 · 对称性与平面等距变换）

**题目来源：** [2019 AMC 10A Problem 8](https://github.com/mlian031/mathcontests/blob/master/AMC/2019/10A/8/latex.txt)

**知识点：** 刚体运动（等距变换）· 平移对称性 · 反射对称轴 · 旋转对称性

**题目：**

下图展示了直线 $\ell$ 上一种由正方形和线段组成的、规则的、无限重复的花纹。

在下面四类把该花纹所在平面映射到自身的刚体运动（不包括恒等变换）中，有多少类能够把这个图形变成它自己？

- 绕直线 $\ell$ 上某点的某个旋转
- 沿平行于直线 $\ell$ 方向的某个平移
- 关于直线 $\ell$ 的反射
- 关于某条垂直于直线 $\ell$ 的直线的反射

$\textbf{(A) } 0 \qquad\textbf{(B) } 1 \qquad\textbf{(C) } 2 \qquad\textbf{(D) } 3 \qquad\textbf{(E) } 4$

---

### 解题过程

我们把这种无限重复的花纹看作一条“镶边”（frieze）图案，沿直线 $\ell$ 周期性延伸。逐个判断四类变换：

**① 绕 $\ell$ 上某点的旋转**
图案在垂直于 $\ell$ 的方向上并不对称——正方形/线段是朝一侧（或交替）凸出的，绕直线上任一点旋转 $180^\circ$ 都会把凸出部分翻到另一侧，无法与原图重合。实际上该图案没有任何非平凡旋转对称性。
$\Rightarrow$ 此类变换 **不行**。

**② 沿平行于 $\ell$ 方向的平移**
由于花纹是“无限重复”的，存在最小周期（一个基本花纹的宽度）。沿 $\ell$ 方向平移恰好一个周期（或整数个周期），图形与自身完全重合。
$\Rightarrow$ 存在这样的平移，**可行**。

**③ 关于直线 $\ell$ 的反射**
该frieze图案关于中心线 $\ell$ 上下对称（上方与下方的结构互为镜像），因此关于 $\ell$ 的反射把图形映射到自身。
$\Rightarrow$ **可行**。

**④ 关于垂直于 $\ell$ 的直线的反射**
单个基本花纹单元并不关于其垂直于 $\ell$ 的边界线对称（左右结构不同），因此取任一条垂直于 $\ell$ 的直线作反射，都无法使整个无限图案与自身重合。
$\Rightarrow$ 此类变换 **不行**。

综上，可行的非平凡刚体自同构只有 **类②平移** 与 **类③关于 $\ell$ 的反射**，共 **2 类**。

**答案：$\textbf{(C) } 2$**

---

### 常见错误

- 把“某个旋转”误以为存在 $180^\circ$ 旋转对称，而忽略了图案在垂直方向的不对称性。
- 认为垂直于 $\ell$ 的反射也成立，把每个基本单元错当成左右对称。
- 把恒等变换也算进去（题目明确“不包括恒等变换”）。

---

### 知识背景

本题考察平面等距变换（刚体运动）中的对称性判断，是“镶边群”（frieze group）与“壁纸群”（wallpaper group）的入门思想。AMC 常通过这类直观图案考查学生对平移、反射、旋转、滑移反射四种基本对称操作的辨识。抓住“图案沿某一方向无限重复 $\Rightarrow$ 有平移对称；关于中心线镜像对称 $\Rightarrow$ 有反射对称”这两条直觉，可迅速排除旋转与垂直反射。

## 【代数】完全平方或立方因子的计数

**难度：** ⭐⭐⭐（高中竞赛难度 · 质因数分解与容斥计数）

**题目来源：** [2019 AMC 10A Problem 11](https://github.com/mlian031/mathcontests/blob/master/AMC/2019/10A/11/latex.txt)

**知识点：** 唯一分解定理 · 完全平方/完全立方的充要条件 · 容斥原理

**题目：**

$201^9$ 的正因数中，有多少个是完全平方数或完全立方数（或两者都是）？

${\textbf{(A) }32} \qquad {\textbf{(B) }36} \qquad {\textbf{(C) }37} \qquad {\textbf{(D) }39} \qquad {\textbf{(E) }41}$

---

### 解题过程

**第一步：分解底数。**
$$201 = 3 \times 67$$
其中 $3$ 与 $67$ 均为素数。于是
$$201^9 = 3^9 \cdot 67^9$$

**第二步：刻画一般因数。**
$201^9$ 的任意正因数形如
$$d = 3^a \cdot 67^b, \qquad 0 \le a \le 9,\; 0 \le b \le 9$$

**第三步：完全平方因数。**
$d$ 为完全平方数 $\iff$ 指数 $a,b$ 均为偶数。
在 $0\sim 9$ 中偶数有 $0,2,4,6,8$，共 $5$ 个选择，故
$$N_{\text{square}} = 5 \times 5 = 25$$

**第四步：完全立方因数。**
$d$ 为完全立方数 $\iff$ 指数 $a,b$ 均为 $3$ 的倍数。
在 $0\sim 9$ 中 $3$ 的倍数有 $0,3,6,9$，共 $4$ 个选择，故
$$N_{\text{cube}} = 4 \times 4 = 16$$

**第五步：既是平方又是立方（即六次方数）。**
$d$ 为六次方数 $\iff$ 指数 $a,b$ 均为 $6$ 的倍数。
在 $0\sim 9$ 中 $6$ 的倍数有 $0,6$，共 $2$ 个选择，故
$$N_{\text{both}} = 2 \times 2 = 4$$

**第六步：容斥。**
$$\text{所求} = N_{\text{square}} + N_{\text{cube}} - N_{\text{both}} = 25 + 16 - 4 = 37$$

**答案：$\textbf{(C) } 37$**

---

### 常见错误

- 忘记容斥，直接 $25+16=41$，从而误选 $\textbf{(E)}$。
- 把“或两者都是”理解成“排除既是平方又是立方的”，错误地算成 $25+16-2\times 4=33$（容斥只减一次交集）。
- 分解 $201$ 时漏掉 $67$ 是素数，或把 $201$ 错写成 $3\times 67$ 以外的形式。

---

### 知识背景

本题是“按质因数指数分类计数”的经典题型。核心三步：①用唯一分解定理把数写成素数幂乘积；②把“是平方/立方数”翻译成“各质因数的指数满足整除条件”；③用容斥处理“或”的关系。这类方法在 AMC 10/12 的因子计数题中几乎每年出现，是数论板块性价比最高的基本功之一。
