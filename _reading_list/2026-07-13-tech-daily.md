## 1. 无需训练的宽松投机解码：实用性深度研究

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2607.08690v1  
**标签**：投机解码 · LLM推理加速 · 采样效率 · 无需训练

投机解码通过小草稿模型并行预测 token、大模型批量验证来加速 LLM 采样。标准投机解码完全无损地保留原始分布，但吞吐量受接受率制约。本文对训练无关的宽松接受准则进行了系统实验，允许小幅分布偏移以换取更高吞吐量，并量化了质量与速度之间的实际权衡。

**核心要点**：
- 宽松接受准则无需重新训练草稿模型，即可提升 token 接受率和吞吐量
- 实验量化了不同宽松程度下的输出质量损失（KL 散度与下游任务精度）
- 为工业部署提供了实践指导：在低延迟场景下宽松程度可超出传统阈值

---## 2. BiSCo-LLM：极低比特大模型压缩的无查找二进制球面编码

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2607.08643v1  
**标签**：模型量化 · 二进制编码 · 极低比特 · LLM压缩 · 内存效率

LLM 部署受内存带宽与存储瓶颈制约，极低比特压缩是突破之道。BiSCo-LLM 提出无查找表的二进制球面编码方案，将权重映射到高维球面上的二进制码字，绕开传统向量量化的查找表瓶颈，在保持模型精度的同时实现极致压缩比。

**核心要点**：
- 无查找表设计避免了 VQ 方案的内存访问开销，硬件友好度显著优于传统 VQ
- 球面编码约束使权重分布更均匀，压缩后困惑度损失小于同比特标量量化
- 支持与现有低精度 CUDA kernel 融合，端到端推理速度超越 GPTQ/AWQ 等基线

---## 3. DominoTree：面向投机解码的条件树结构草稿生成

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2607.08642v1  
**标签**：投机解码 · 树形草稿 · 扩散模型 · LLM推理 · 并行解码

现有投机解码的草稿策略或忽略 token 间依赖（块扩散），或扩展代价高昂（贪心树）。DominoTree 结合块扩散的单次生成效率与树结构的依赖建模优势，通过 Domino 条件机制在树节点间传递上下文，生成质量更高的候选树，提升大模型侧的 token 接受率。

**核心要点**：
- Domino 条件机制在树节点间建模 token 依赖，超越纯边缘概率的独立草稿假设
- 单次前向即可生成条件树结构草稿，草稿延迟与块扩散持平
- 在多个基准上验证接受率和端到端吞吐量均优于 DFlash 和 DDTree

---## 4. MAESTRO：MoE 大模型的专家剪枝方法

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2607.08601v1  
**标签**：MoE剪枝 · 混合专家 · 模型压缩 · 部署效率 · 结构化剪枝

稀疏激活的 MoE 大模型推理时仅激活少量专家，但全量专家参数始终驻留显存，造成严重部署瓶颈。MAESTRO 针对专家异质重要性设计细粒度剪枝策略，通过多粒度重要性评估精准识别并移除冗余专家，在保持模型能力的同时大幅削减内存占用。

**核心要点**：
- 专家重要性具有高度异质性，MAESTRO 采用多粒度评估（激活频率+输出贡献）
- 结构化剪枝后无需微调即可恢复大部分精度，在 Mixtral 系列上验证效果
- 显存占用可降低 30-40%，为消费级 GPU 部署 MoE 模型提供可行路径

---## 5. UltraX：自适应程序化编辑的大规模预训练数据精炼

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2607.08646v1  
**标签**：预训练数据 · 数据质量 · 程序化编辑 · 缩放定律 · 数据工程

随着可用训练数据接近物理上限，Scaling Law 收益递减，数据质量已超越数据量成为 LLM 进步的核心杠杆。UltraX 提出自适应程序化编辑框架，对大规模语料进行可控质量提升：通过分析文本缺陷模式生成编辑规则，批量精炼语料的同时保留多样性，在预训练实验中持续提升下游任务性能。

**核心要点**：
- 程序化编辑规则由模型自动发现，可扩展至万亿 token 级语料无需人工标注
- 自适应策略根据文本类型动态调整编辑强度，避免过度修改导致多样性损失
- 相同算力预算下，经 UltraX 精炼的数据训出的模型超越原始数据基线 2-4 点

---## 6. 通过激活聚合实现 Prompt 压缩

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2607.08399v1  
**标签**：Prompt压缩 · KV Cache · 激活向量 · 上下文效率 · 推理优化

LLM 处理长 Prompt 时逐层传播激活，消耗大量 KV Cache 与计算资源。本文提出将指令 Prompt 的任务相关信息压缩为单个激活向量并重新注入模型，从而替换原始 token 序列。该方法大幅降低长上下文推理的 prefill 开销，并在多任务评测中保持与完整 Prompt 相当的性能。

**核心要点**：
- 激活聚合将任意长度指令压缩为单向量，prefill 计算量降低与 Prompt 长度成正比
- 压缩向量可预计算并缓存复用，特别适合系统 Prompt 固定的 API 服务场景
- 在 MMLU、GSM8K 等标准基准上压缩后精度损失低于 1%
