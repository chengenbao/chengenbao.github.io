## 【概率】蜜蜂三维飞行路径

**难度：** ⭐⭐⭐⭐⭐（高中竞赛 / AMC 10 第 24 题）

**题目来源：** [2024 AMC 10A Problem 24](https://live.poshenloh.com/past-contests/amc10/2024A/problem/24)

**知识点：** 基础概率 · 立体几何（单位正方体）· 分类讨论

**题目：**

一只蜜蜂在三维空间中移动。掷一枚六个面分别标有 \(A^+,\) \(A^-,\) \(B^+,\) \(B^-,\) \(C^+,\) \(C^-\) 的公平骰子。设蜜蜂当前位于点 \((a, b, c)\)：若掷出 \(A^+\)，蜜蜂移动到 \((a + 1, b, c)\)；若掷出 \(A^-\)，则移动到 \((a - 1, b, c)\)；其余四种结果作类似的移动。

设蜜蜂从点 \((0, 0, 0)\) 出发，骰子掷了四次。求蜜蜂恰好走过**某个**单位正方体的四条不同棱的概率。

- (A) \(\dfrac{1}{54}\)
- (B) \(\dfrac{7}{54}\)
- (C) \(\dfrac{1}{6}\)
- (D) \(\dfrac{5}{18}\)
- (E) \(\dfrac{2}{5}\)

---

### 解题过程

**第 1 步：建立样本空间。** 每次掷骰有 \(6\) 种等可能结果，四次共 \(6^4 = 1296\) 条等可能的移动序列。"走过某个单位正方体的四条不同棱"意味着：四步的方向向量是四个**不同**的 \(\pm e_i\)（\(e_i\) 为坐标轴单位向量），且它们恰好是同一个单位正方体的四条棱。特别地，若序列中同轴的两步相邻（如 \(+x\) 后紧跟 \(-x\)，或同向重复 \(+x,+x\)），路径要么折返、要么沿直线延长，都不可能构成正方体的四条棱。

**第 2 步：分类一——只用两个坐标方向（绕正方形一圈）。** 若四步只涉及两个坐标轴（例如 \(x\) 和 \(y\)），四个方向 \(\pm e_x,\pm e_y\) 必须各用一次，路径绕一个单位正方形一圈。

- 选坐标平面：\(3\) 种（\(xy, yz, zx\)）；
- 两个轴各自方向的符号：\(2\times 2 = 4\) 种；
- 两个轴的先后顺序（第一个坐标轴是谁）：\(2\) 种（之后"绕圈"结构唯一确定：若开头两步是 \(+x,+y\)，后两步必为 \(-x,-y\)）。

共 \(3\cdot 4\cdot 2 = 24\) 条。

**第 3 步：分类二——用到全部三个坐标方向。** 四步、三个轴，必有一个轴出现两次，另两个轴各一次。要构成正方体的四条棱，重复轴的两次必须取**相反方向**，且处在**不相邻**的两步（第 \(1\)&\(3\) 步，或第 \(2\)&\(4\) 步）；否则相邻的同向重复沿直线延长、相邻的反向重复原路折返，都不合法。

- 选重复的轴：\(3\) 种；
- 它两次出现的位置（不相邻）：\(\{1,3\}\) 或 \(\{2,4\}\)，共 \(3\) 种；
- 另外两个轴的排列顺序：\(2\) 种；
- 三个自由步（重复轴的第一次 + 两个单次轴）的方向符号：\(2^3 = 8\) 种（重复轴第二次的符号由"相反方向"唯一确定）。

共 \(3\cdot 3\cdot 2\cdot 8 = 144\) 条。

**第 4 步：合计并求概率。** 两种分类互斥（按用到几个坐标方向划分）且覆盖所有合法路径：
\[\text{有利序列数} = 24 + 144 = 168,\qquad P = \dfrac{168}{1296} = \dfrac{7}{54}.\]

**答案：(B) \(\dfrac{7}{54}\)**

---

### 常见错误

- 漏掉"重复轴出现在不相邻位置"的约束：相邻的同向重复（如 \(+x,+x\)）走的是棱的延长线，相邻的反向重复（\( +x,-x\)）原路返回，都必须排除。
- 只数"绕正方形一圈"的 \(24\) 条，漏掉用到三个方向的 \(144\) 条折线，得到 \(\frac{24}{1296} = \frac{1}{54}\) 而误选 (A)。

---

### 知识背景

这是三维随机游走与立体几何结合的计数概率题。核心是把"走过单位正方体的四条不同棱"翻译成方向序列的组合结构：要么是单面正方形回路（两轴），要么是"三面角"折线（三轴、一轴重复且不相邻）。计数按"选轴 → 选位置 → 定符号"的独立自由度分层相乘，与正方体的旋转对称性遥相呼应；这类"结构分类 + 分层计数"是高难度计数概率题的通用框架。

## 【几何】矩形内的直角三角形面积

**难度：** ⭐⭐⭐（高中竞赛 / AMC 12 第 7 题）

**题目来源：** [2024 AMC 12B Problem 7](https://live.poshenloh.com/past-contests/amc12/2024B/problem/7)

**知识点：** 坐标几何 · 三角形面积

**题目：**

如图，\(WXYZ\) 是一个矩形，\(WX = 4\)，\(WZ = 8\)。点 \(M\) 在 \(\overline{XY}\) 上，点 \(A\) 在 \(\overline{YZ}\) 上，且 \(\angle WMA\) 是直角。\(\triangle WXM\) 与 \(\triangle WAZ\) 的面积相等。求 \(\triangle WMA\) 的面积。

（图示：\(W,X,Y,Z\) 按逆时针排列，短边 \(WX=YZ=4\)，长边 \(XY=ZW=8\)；\(M\) 在下边 \(XY\) 上，\(A\) 在右边 \(YZ\) 上，\(W\) 在左上角。）

- (A) \(13\)
- (B) \(14\)
- (C) \(15\)
- (D) \(16\)
- (E) \(17\)

---

### 解题过程

**第 1 步：建立坐标系。** 取 \(X = (0,0)\)，\(W = (0,4)\)，\(Y = (8,0)\)，\(Z = (8,4)\)（于是 \(WX=4\) 为宽、\(XY=8\) 为长）。设
\[M = (m, 0)\ \text{在}\ \overline{XY}\ \text{上},\qquad A = (8, a)\ \text{在}\ \overline{YZ}\ \text{上}.\]

**第 2 步：把"直角"写成点积方程。** \(\angle WMA = 90^\circ\) 即 \(\overrightarrow{MW} \perp \overrightarrow{MA}\)：
\[\overrightarrow{MW} = (0-m,\ 4-0) = (-m,\,4),\qquad \overrightarrow{MA} = (8-m,\ a-0) = (8-m,\,a).\]
点积为零：
\[(-m)(8-m) + 4a = 0 \ \Longrightarrow\ 4a = m(8-m).\qquad (\ast)\]

**第 3 步：把"面积相等"写成第二个方程。**
\[[\triangle WXM] = \tfrac12\cdot WX\cdot XM = \tfrac12\cdot 4\cdot m = 2m,\]
\[[\triangle WAZ] = \tfrac12\cdot ZA\cdot WZ = \tfrac12\cdot (4-a)\cdot 8 = 4(4-a).\]
令二者相等：\(2m = 4(4-a)\)，即
\[m = 8 - 2a.\qquad (\ast\ast)\]

**第 4 步：联立求解。** 由 \((\ast\ast)\) 得 \(a = \dfrac{8-m}{2}\)，代入 \((\ast)\)：
\[4\cdot\dfrac{8-m}{2} = m(8-m) \ \Longrightarrow\ 2(8-m) = m(8-m).\]
移项：\((8-m)(2-m) = 0\)，所以 \(m = 8\) 或 \(m = 2\)。其中 \(m=8\) 时 \(M\) 与 \(Y\) 重合且 \(A\) 也退到 \(Y\)，\(\angle WMA\) 无定义，舍去。故
\[m = 2,\qquad a = \dfrac{8-2}{2} = 3.\]

**第 5 步：鞋带公式求 \(\triangle WMA\) 面积。** 用 \(W=(0,4),\ M=(2,0),\ A=(8,3)\)：
\[[\triangle WMA] = \tfrac12\,\bigl|\,0(0-3) + 2(3-4) + 8(4-0)\,\bigr| = \tfrac12\,|0 - 2 + 32| = \tfrac12\cdot 30 = 15.\]

**答案：(C) 15**

---

### 常见错误

- 解二次方程时接受 \(m=8\) 这个根而不加检验：此时 \(M=Y\)、\(A\) 退到 \(Y\)，"\(\angle WMA\)"退化，必须舍去。
- 坐标摆放混乱（例如把 \(WZ\) 当宽、\(WX\) 当长）：先画图确认哪条边是 \(4\)、哪条是 \(8\)，再统一坐标，否则两个面积方程都会写错。

---

### 知识背景

本题是"解析几何两条件定两点"的标准范式：一个**垂直条件**（点积为零，得到二次方程）加一个**面积条件**（线性方程），联立求解，再对退化根做几何检验。最后的鞋带公式 \([\triangle]=\frac12|x_1(y_2-y_3)+x_2(y_3-y_1)+x_3(y_1-y_2)|\) 免去了画高线的麻烦，是坐标几何中计算三角形面积的必备工具。
