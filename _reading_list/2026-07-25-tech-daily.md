## 1. Codec-Gauge：为 Transformer KV Cache 学习压缩友好的坐标系

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2607.20538
**标签**：KV Cache · 长上下文推理 · 量化 · 变换编码

长上下文 Transformer 推理越来越依赖 KV Cache 压缩与量化，而先前的旋转变换和变换编码研究表明，key/value 向量所处的通道基（channel basis）直接影响固定压缩后端保留模型行为的保真度。本文提出 Codec-Gauge，一个训练后（post-training）的缓存坐标层，通过学习小型正交变换把 KV 向量旋转到对压缩更友好的坐标系中，使现有压缩/量化后端在相同码率下更好地保持模型输出。

**核心要点**：
- 提出"压缩友好坐标系"视角：KV 向量的通道基选择决定压缩保真度上限
- 训练后即插即用，学习小型正交变换，无需重训模型或修改压缩后端
- 对接现有 KV Cache 量化/压缩方案，在相同压缩率下降低模型行为偏移

## 2. 突破压缩瓶颈：从理论到实践

**核心要点**：
- 系统刻画低秩分解与量化在高压缩率下性能骤降的理论根源
- 提出理论指导下的组合压缩策略，突破单一方法的压缩率-性能权衡
- 面向大参数量 LLM 的部署场景，直接服务于显存与算力受限环境

## 3. MoE 路由是 Huffman 编码吗？揭示思维链中的频率-多样性法则

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2607.20427
**标签**：MoE · 路由机制 · Huffman 编码 · 可解释性

Mixture-of-Experts 架构革新了模型扩展方式，但其路由逻辑一直是黑盒。本文提出一个根本性的解释框架：MoE 路由不仅是专家选择，更是一种 Huffman 编码的体现。作者提出"频率-多样性法则"（Frequency-Diversity Law），揭示前沿 MoE 模型在思维链推理中，高频 token 被路由到少数专家（短码），低频/高信息量 token 则调用更多样的专家组合（长码），从信息论角度打开了 MoE 路由的黑盒。

**核心要点**：
- 首次将 MoE 路由与 Huffman 编码建立形式化类比，给出信息论解释
- 发现频率-多样性法则：token 频率与其激活专家的多样性呈反比
- 为 MoE 模型的专家负载均衡、路由设计与压缩提供新的理论依据

## 4. 当 RLVR 收缩推理边界：诊断 Pass@k 反转现象

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2607.20543
**标签**：RLVR · 强化学习 · Pass@k · 推理能力 · 训练诊断

可验证奖励强化学习（RLVR）能提升单次采样准确率，却可能让模型在重复采样下变得更差。本文系统研究这一"pass@k 反转"现象：训练后的策略在大 k 值下能解出的不同问题数反而少于基座模型。失效集中在"边界提示"上——即基座模型仅含稀有正确解的难题，RLVR 训练把这些低概率的正确推理路径挤出了分布，从而收缩了模型的推理边界。

**核心要点**：
- 定义并诊断 pass@k 反转：RLVR 后模型在大 k 采样下可解题集合缩小
- 定位失效根源在边界提示：基座模型中稀有正确解被 RL 训练抹除
- 对 RLVR 训练配方提出警示：单样本准确率提升可能以探索多样性为代价

- 面向单核资源受限设备，验证软硬件协同设计在边缘训练场景的价值
