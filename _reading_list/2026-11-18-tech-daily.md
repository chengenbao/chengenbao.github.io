## 1. CertiSum：跨平台与并行布局比特级一致的 MXFP4 训练

**来源**：arXiv cs.LG  
**链接**：http://arxiv.org/abs/2611.21370v1  
**标签**：MXFP4 · 4-bit量化 · 训练确定性 · GPU · 数值对齐

MXFP4 是一种 4-bit 微缩放浮点格式，但在不同并行布局与 GPU 厂商上训练存在非确定性——相同输入可能产生不同结果，给调试、训练审计以及训练/推理引擎一致性带来麻烦。CertiSum 通过证明"MXFP4 乘积的原生 FP32 累加在多数求和顺序下本就精确"这一关键洞察，使 MXFP4 训练在不同运行、并行布局与 GPU 厂商间保持比特级不变。

**核心要点**：
- 量化时收集统计量以"认证"原生矩阵乘法结果，未通过认证的输出用精确内核重算
- 保持量化块在各布局间不变，并在注意力与权重梯度计算中无舍入地合并部分和
- 在 200 步 Qwen3-8B-Base 训练中验证跨平台/跨布局的比特级一致性

## 2. GNoF：面向数据密集型 GPU 负载的低 SM 开销 GPU 原生 NVMe-oF 完成路径

**来源**：arXiv cs.AR  
**链接**：http://arxiv.org/abs/2611.21288v1  
**标签**：GPU · NVMe-oF · 存储I/O · SM开销 · 数据搬运

数据密集型负载的数据集常超过显存并驻留在远程闪存，传统方案由主机 CPU 编排每次 NVMe-oF 事务并经由主机内存中转，带来高 CPU 占用、频繁的 CPU-GPU 同步与冗余数据搬运。GPU 发起存储虽可将 CPU 移出 I/O 路径，但现有设计存在同步锁步完成会"钉死"流式多处理器（SM）的问题。

**核心要点**：
- 提出 GPU 原生 NVMe-oF 完成路径，显著降低 SM 被 I/O 完成阻塞的开销
- 将存储完成处理从 CPU/SM 同步锁步中解耦，减少冗余数据搬运
- 面向超过显存容量的远程闪存场景，提升 GPU 直接访问远端数据的效率

## 3. SURMA：面向 SuperPOD 的高效细粒度通信卸载

**来源**：arXiv cs.AR  
**链接**：http://arxiv.org/abs/2611.21274v1  
**标签**：SuperPOD · 分布式训练 · NVLink · 通信卸载 · KV缓存

GPU SuperPOD 支撑着大模型（LLM）推理服务，但不断增长的带宽与往返时延使跨 GPU 通信消耗越来越多的计算资源。由 SM 驱动的远程内存访问会占用共享内存或寄存器来缓存在途数据，并与 SM-to-NoC 带宽竞争；专用引擎虽能释放这些资源，却需处理低至 576B KV 缓存条目的细粒度传输（NVIDIA CopyEngine 在 7KB 粒度下仅用到 NVLink 带宽的不到 1%）。

**核心要点**：
- 针对 SuperPOD 中 SM 驱动的通信瓶颈，提出细粒度通信卸载方案
- 支持低至 576 字节 KV 缓存条目的细粒度传输，匹配推理服务真实访问粒度
- 通过专用引擎释放 SM 资源，缓解与计算对 NoC 带宽的竞争

## 4. Balanced Twin Weight Factorization：面向高效多模态大模型（MLLM）的权重分解

**来源**：arXiv cs.CL  
**链接**：http://arxiv.org/abs/2611.21459v1  
**标签**：权重分解 · MLLM · 推理加速 · 延迟优化 · 模型压缩

权重分解（WF）方法通过将预训练模型拆为多个低参数量、低 FLOPs 的因子来降低延迟与显存。但实际中，用多个小矩阵替换单个大权重矩阵会引入额外开销，使"更少 FLOPs"难以转化为"更低延迟"。本文提出 Balanced Twin Weight Factorization 以解决该落地难题。

**核心要点**：
- 指出现有 WF 方法在真实延迟上的主要瓶颈：多小矩阵替代大矩阵的开销
- 提出"平衡双子"分解结构，在逼近原权重的同时优化实际推理延迟
- 面向多模态大模型的延迟与显存联合压缩，而非仅追求理论 FLOPs 下降

## 6. SCOPE：以物理执行时延为导向的量子电路编译框架

**来源**：arXiv cs.AR  
**链接**：http://arxiv.org/abs/2611.21270v1  
**标签**：量子编译 · 电路优化 · 执行时延 · 门融合 · QOC

量子计算需要编译器将量子电路模型描述的算法翻译为物理设备支持的酉操作。有限的相干时间使"物理执行时延"成为关键编译目标：门融合可缩短脉冲，但门数与时深并不能刻画融合目标的控制需求；而用量子最优控制（QOC）逐个评估候选会将脉冲优化嵌入结构搜索，代价高昂。本文提出 Schmidt 引导的编译框架 SCOPE。

**核心要点**：
- 将"物理执行时延"作为量子电路编译的一等优化目标，而非仅看门数/深度
- 用 Schmidt 引导在结构搜索中高效近似 QOC 评估，避免逐候选脉冲优化
- 在相干时间约束下更贴近真实设备的可执行性
