FedACT 针对多 FL 任务共享设备池的场景，提出基于对齐评分的异构感知调度策略，同时引入参与公平性机制以均衡设备贡献。实验表明，相比 SOTA 基线，FedACT 将平均任务完成时间缩短最高 8.3×，模型精度提升最高 44.5%。

## 3. RSAT：结构化归因让小模型成为可信的表格推理器

**链接**：https://arxiv.org/abs/2605.00199  
**标签**：小语言模型 · 表格推理 · GRPO · 可信AI · 细粒度归因

RSAT 训练 1-8B 参数的小模型输出带单元格级引用的逐步推理，分两阶段：SFT 学习结构化 JSON 输出格式，GRPO 以 NLI 可信度为核心奖励进行强化。在 Qwen 2.5 和 Llama 3 六个模型上，可信度相比纯 SFT 提升 3.7×（0.224→0.826），引用有效率近乎完美（0.992）。

**核心要点**：
- SFT 阶段从经过验证的推理轨迹学习结构化 JSON 输出格式
- GRPO 阶段以 NLI 可信度为核心奖励，辅以引用有效性与简洁性
- 可信度相比纯 SFT 提升 3.7×，达到 0.826；引用有效率 0.992
- 验证归因必须集成到推理过程中，事后补充归因成功率不足 13%

## 4. 为何大模型在策略博弈中频繁失败：观察、信念与行动的断裂

**来源**：cs.CL (arXiv)  
**链接**：https://arxiv.org/abs/2605.00226  
**标签**：LLM · 策略推理 · 信念建模 · 不完全信息 · 机制分析

研究揭示 LLM 在不完全信息博弈中存在两个根本性断层：观察-信念断层（内部表示的信念比口头报告更准确，但随多跳推理退化）和信念-行动断层（即使信念准确，行动选择仍偏离最优）。实验覆盖 Llama 3.1、Qwen3 和 GPT-oss。

**核心要点**：
- LLM 内部信念准确性显著高于其口头报告，存在内外一致性缺口
- 信念准确性随多跳推理步数增加而退化，呈现首因和近因偏差
- 即使信念准确，行动选择仍与贝叶斯最优策略存在系统性偏差
- 对谈判、决策等智能体应用场景具有重要的安全性和可靠性含义
