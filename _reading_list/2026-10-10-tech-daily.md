## 1. Mole：基于层级热度画像的异构内存分层系统

**来源**：arXiv (cs.OS)  
**链接**：https://arxiv.org/abs/2610.12164  
**标签**：异构内存 · 内存分层 · OS内核 · 页迁移

多层异构内存将高速小容量上层与低速大容量下层结合以兼顾性能与成本。现有方案（AutoTiering、MTM）依赖贪心提升与逐级降级，会加剧快速层的容量争用。Mole 基于「提升直接改善性能、降级主要回收空间」的不对称性，将提升与降级的去向分离：采用分级降级把冷页直接下沉到最底层、绕过中间层，目标提升则把热页放到匹配其当前热度的层级。配合分层专属画像（底层高频、上层低频）以低开销检测被降级后重新激活的热页。实验表明其显著减少迁移失败并提升动态负载下的性能。

**核心要点**：
- 揭示提升与降级在性能收益上的不对称性，据此解耦二者的目的地
- 分级降级 + 目标提升，保留中间层容量用于提升，减少迁移失败
- 分层专属热度画像，以低开销及时发现降级后被重新激活的热页

## 2. 用路由稀疏自编码器解耦语音中的语言与副语言信息

**来源**：arXiv (cs.CL)  
**链接**：https://arxiv.org/abs/2610.10865  
**标签**：稀疏自编码器 · 语音表征 · 解耦 · 路由

自监督语音编码器把语言信息与副语言信息（说话人、情感、韵律）纠缠在同一表征空间。本文结合 TopK 稀疏自编码器、路由专属监督与跨因子对抗训练，在冻结的 SPEAR 与 WavLM 编码器上用独立探针验证：语言路由保留语言信息，副语言路由保留说话人/情感/韵律并显著抑制其在语言路由中的表达。该路由结构在 LibriSpeech 上学会后可零表示层重训练迁移到 MSP-Podcast，特征空间路由干预还能迁移被交换的因子。

**核心要点**：
- 用 TopK 稀疏自编码器 + 路由监督 + 跨因子对抗实现语言/副语言解耦
- 独立探针与特征级干预双重验证，跨编码器、跨语料一致可迁移
- 为零样本语音属性编辑、可控语音合成提供可干预的表征基础

## 3. DynaTE：面向扩散式 LLM 的软硬件协同动态令牌执行加速

**来源**：arXiv (cs.AR)  
**链接**：https://arxiv.org/abs/2610.11284  
**标签**：扩散LLM · 推理加速 · 软硬件协同 · 令牌执行

扩散式 LLM（dLLM）通过双向并行细化缓解自回归的顺序解码瓶颈，但其并行迭代细化与面向顺序解码的 AR 加速器不匹配，且离散令牌生成不同于 DiT 的连续去噪。DynaTE 提出软硬件协同架构，随解码过程中令牌状态动态适配执行：自适应令牌执行跳过低效用令牌、维度可重构 PE 阵列维持高利用率；借助 FLDD 动态令牌依赖在当前轮细化少量局部依赖令牌以减少去噪轮数；流式词表引擎交错多令牌流应对不规则输出。在两款 dLLM 上较 SOTA dLLM 加速器取得 2.05–2.78× 加速与 2.99–3.93× 能效提升。

**核心要点**：
- 自适应令牌执行 + 维度可重构 PE 阵列，按效用跳过计算维持利用率
- FLDD 动态依赖 + Merge-Split-Merge 数据流，减少去噪迭代轮数
- 流式词表引擎应对选择性令牌计算带来的不规则输出，2×+ 加速与 3×+ 能效

## 4. Mooncake：以 KV 缓存为中心的 LLM 服务分离式架构

**来源**：arXiv (cs.AR)  
**链接**：https://arxiv.org/abs/2407.00079  
**标签**：LLM服务 · KV缓存 · 分离式架构 · 分布式推理

Mooncake 是 Kimi（Moonshot AI）的 LLM 服务系统，提出以 KV 缓存为中心的分离式架构：将预填充与解码实例分离，以 KV 缓存搬运而非传统流水线并行作为核心。其全局调度器（Conductor）按 KV 块复用与热点感知在实例间调度，并引入以 KV 为中心的多级缓存，显著提升 GPU 集群利用率与吞吐。论文系统阐述了分离式架构下面临的 KV 缓存弹性、负载均衡与调度挑战及工程取舍。

**核心要点**：
- 以 KV 缓存搬运为核心的预填充/解码分离式架构，打破传统流水并行
- 全局 Conductor 调度 + KV 块复用/热点感知，提升集群利用率与吞吐
- 剖析分离式架构下缓存弹性、均衡与调度的工程取舍

## 5. 5000 万 Token 真实长期记忆：比 RAG 更快更省的上下文窗口

**来源**：arXiv (cs.CL)  
**链接**：https://arxiv.org/abs/2610.10845  
**标签**：长期记忆 · 长上下文 · 推理加速 · RAG替代

LLM 只能利用上下文窗口内的文本，且每次扩展窗口都要重算内部键，长上下文既慢又贵。本文提出一种真实长期记忆方案：用可外部存储、按需检索的 5000 万 token 级记忆，相比 RAG 既更快又更省——它不是把检索片段拼回提示，而是以更高效的机制让模型在超大窗口下保持低开销访问。文章论证该窗口在成本与延迟上优于重算式长上下文，并讨论其对长期 agent 应用的启示。

**核心要点**：
- 以 5000 万 token 级外部记忆替代「重算式」长上下文，避免每次扩展重算键
- 相比 RAG 更快更省：非简单拼接检索片段，而是高效按需检索访问
- 为长期运行的自主 agent 提供可负担的超长记忆基础

## 6. 用 TLX 优化 Jagged Flash Attention：迈向 Blackwell 上的 SOTA FA4

**核心要点**：
- Jagged Flash Attention 针对变长序列注意力，支撑 Meta GEM 广告模型
- 基于 TLX 内核原语 + 自动调优，在 Blackwell B200 上逼近 FA4 性能
- 展示新一代硬件（Blackwell）+ 高层 DSL 协同优化变长注意力的路径
