## 1. Redwood：由 AI 端到端设计、验证并部署的前沿 AI 加速器

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2608.26418  
**标签**：AI 加速器 · 软硬件协同设计 · RTL 自动生成 · 形式化验证 · 低功耗推理

Redwood 是一个由 AI 系统端到端设计的前沿 AI 加速器，面向物理 AI 场景下的单批次、低功耗、超低延迟推理。其核心理念是把"软件到硅"的整条技术栈压缩进单一优化回路，让硬件与软件在同一目标下协同设计并统一验证。从两位人类架构师给出的高层规格出发，系统在两周内自主生成性能模型、RTL 设计、UVM 验证环境、形式化证明、固件与算子内核，全程无需人工干预。

**核心要点**：
- 软硬件协同设计闭环：硬件与软件在统一目标下联合优化，规格变更后可在 48 小时内重新验证并部署到硬件，设计周期与工作负载演进节奏对齐。
- 全流程自动化与高覆盖：每个模块均达到 95% 覆盖率（商业 EDA 工具 + 自研形式化引擎 + 硬件在环验证），Redwood Nano FPGA 变体可运行 Llama、Qwen 等数十亿参数模型。
- 实测能效优势：映射到三星 8nm（Jetson Orin Nano 同级工艺）后，相较实测 Jetson 基线在同等模型上实现 1.75x 吞吐、1.9x 更低功耗，性能/功耗提升 3.4x，并出现用 Qwen 反哺设计下一代 Redwood 的自我改进苗头。

## 2. SILK：弥合 RoT 保护 AI 系统中检查-使用时间差（TOCTOU）完整性缺口

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2608.26402  
**标签**：模型完整性 · Root-of-Trust · 权重保护 · 流式校验 · TOCTOU

RoT（信任根）认证在加载时校验 DNN 模型，但权重随后需经过 DRAM、DMA、互连与预取路径才抵达计算引擎，这条路径上的篡改不会改变已认证镜像，从而形成"检查-使用时间差"（TOCTOU）完整性缺口。SILK（Streaming Inline Lightweight Keying）提出一种在最终预计算边界对权重流进行原地校验的机制，直接堵住这一缺口。

**核心要点**：
- 复用权重 LSB 作密钥完整性位：将量化权重的低位重用作密钥化完整性位，并在权重字节间链式依赖，使局部篡改会扰动多处校验，伪造概率在 PRF 保护下随受影响校验数指数下降。
- 轻量流式校验 + 提交门控：轻量流式校验器无需独立认证标签即可重算校验，并用 commit gating 阻止未校验权重进入计算；在 Xilinx ZCU102 上以 Caliptra 2.x RoT 1% 的面积代价实现 756 MB/s 吞吐。
- 精度-安全可调：INT8 下质量损失最多 0.76pp（CNN）/0.17 困惑度（8 个 LLM），INT4、MXFP4 通过校验稀疏度提供可配置的安全-质量权衡。

## 3. M-HySMap：面向脉冲神经网络在 Mesh NoC 上的活跃度加权多播超图映射

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2608.26223  
**标签**：脉冲神经网络 · 片上网络 · 超图映射 · 布局布线 · 增量优化

将 SNN 映射到神经形态众核平台通常被建模为图划分与成对放置代价，但这与真实通信事件不符：一个源神经元的一次脉冲会投递到一组突触后目标，且到多个目标的路由可共享 mesh 链路。M-HySMap 提出一种路由感知、活跃度加权的多播超图映射框架，以更贴合物理通信的方式优化放置。

**核心要点**：
- 多播超图建模：每个源神经元对其突触后扇出诱导一条带活跃度权重的定向超边，映射器从强活跃度感知的图/QAP 种子出发，优化不同目标核扇出、确定性 mesh 路由并集与链路拥塞。
- 局部性驱动的增量增益评估：移动一个神经元只会改变其自身源根超边与前驱超边，从而可对未受影响路由贡献做缓存、实现精确增量增益评估。
- 显著收益：在 4x4 至 6x6 mesh NoC 的 115 项证据套件上，路由多播跳数比 Activity+QAP 降低 10.6–19.6%、比 Edge+QAP 降低 19.7–41.1%；增量更新加速细化 4.7–12.7x 且数值精度与全重算一致。

## 4. ACache：扩散式大语言模型的词缀缓存复用机制

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2608.26140  
**标签**：扩散式 LLM · 推理加速 · KV Cache · 双向注意力 · 缓存复用

扩散式大语言模型（DLLM）支持非自回归解码与双向上下文建模，但高效推理仍具挑战。与自回归系统的 KV 缓存可复用共享前缀不同，DLLM 通过双向注意力把共享上下文 token 的 KV 状态与演化中的生成 token 耦合，朴素缓存复用会失效、全量重算又成本高昂。ACache 提出一种面向"词缀"（affix）而非仅前缀的缓存复用机制。

**核心要点**：
- 锚点 token 选取：通过度量共享文本段中 token 对掩码生成 token 的影响，识别少量请求相关关键词缀 token（Anchor Tokens），仅重算这些 token 的 KV 状态、其余词缀缓存复用。
- 精度恢复：基于 Fast-dLLM，重算约 20% 词缀 token 即可弥补直接词缀缓存复用导致的精度损失，跨多种设置恢复精度。
- 端到端加速：在 Nano-vLLM 引擎上构建共享前缀原型，重算延迟最高降低 55.7%，端到端吞吐最高提升 1.68x。

## 5. 通过采样引导与缩放 LLM 的系统方法

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2608.26120  
**标签**：LLM 采样 · 序列蒙特卡洛 · 副本交换 · 分布引导 · 无监督缩放

LLM 是概率模型，通常以自回归分解定义。尽管近期研究开始探索基模型之外更丰富的目标分布，但采样策略仍非常低效。本文给出一个灵活且有理论支撑的框架，用采样来引导与缩放自回归 LLM。

**核心要点**：
- 两种核心算法：框架内含基于序列蒙特卡洛（SMC）与副本交换（RE）的两种算法，可将生成引导向基模型分布的幂次、乘积或倾斜（tilting）。
- 无监督质量缩放：通过缩放生成质量而无需外部监督或奖励模型，展示框架的实用性。
- 更优的扩展曲线：实验表明方法比 Best-of-N 与标准 MCMC 基线扩展更有利，为基于采样的 LLM 概率推断提供系统化"配方"。

## 6. Diff Mining：用 Logit 差异揭示微调目标

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2608.26462  
**标签**：模型审计 · 微调可解释性 · Logit 差异 · NMF · 行为指纹

微调是提炼与诱导语言模型行为的黄金标准，但究竟哪些行为在此过程中涌现往往不清晰，且 unwanted 行为也可能在微调中产生。Diff Mining 提出一个简单有效的框架，通过比较微调模型与其基模型的 logit 来识别它学到了什么。

**核心要点**：
- 仅需输出 logit：不同于许多需要模型内部状态的 diffing 方法，Diff Mining 只需访问输出 logit，可扩展到大型模型，并能浮现被放大的显著 token 作为训练"指纹"（即便在与微调域无关的文本上）。
- 两阶段模块化流程：先在参考语料上抽取逐上下文 logit 差异，再聚合信号构造可解释的 token 集合表示微调；聚合同时探索 Top-K 频率法与基于非负矩阵分解（NMF）的解耦多目标聚类法。
- 审计价值：在微调域检测上显著超越 SOTA diffing 方法；在注入偏置的模型上无需定向探测即可识别超过三分之一的偏置，展现出作为微调目标审计工具的潜力。

## 7. AdaThinking-E：用单 token 熵调节实现自适应思考

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2608.26141  
**标签**：自适应推理 · 强化学习 · 熵调节 · 思考预算 · 多模态 LLM

多模态大语言模型通过引入显式思考过程展现出强文档推理能力，但当前模型对所有问题一视同仁地施加深度推理，给简单任务带来不必要的计算开销，既损害体验也影响基准精度。AdaThinking-E 提出一种通过单 token 熵调节学习自适应思考的强化学习框架。

**核心要点**：
- 熵量化决策置信度：关键洞察是用关键决策 token 处预测概率分布的熵，来量化模型"是否思考"的决策置信度。
- 熵驱动的奖励机制：训练从高熵探索（尝试不同思考策略）自然过渡到低熵收敛（形成自信、可泛化的决策策略），使模型无需人工干预或外部难度标签即内在学会"何时该思考"。
- 复杂准、简单快：在多样文档任务上，模型对复杂问题保持准确、对简单问题高效，兼顾准确率与推理开销。
