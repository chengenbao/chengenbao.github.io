## 1. Ankhdjet：开放 PDK 上将三元量化权重固化进 ROM 计算阵列的开源编译器

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2608.26206
**标签**：编译器 · 三元量化 · BitNet · 存算一体 · 开源PDK

LLM 推理的性能瓶颈在于权重搬运——每生成一个 token 都要重读全部权重。三元量化（BitNet b1.58）将每个权重压缩到 1.58 比特，小到足以把权重硬连进只读掩膜。本文提出 Ankhdjet：首个开源编译器，将 HuggingFace 三元检查点编译为 SKY130 开放 PDK 上固定 compute-in-ROM 宏的 via-mask 程序，并用全开源工具链端到端验证。

**核心要点**：
- 首个在可流片开放 PDK 上实现「权重到掩膜」的存算一体开源编译器
- 基于 SKY130 开放工艺将权重硬连只读掩膜，从根源上消除推理时的权重搬运
- 全开源工具链端到端验证，打破闭源商业芯片（Taalas HC1）在该方向的垄断

## 2. 剖析多 GPU LLM 推理中由 CPU 引发的性能衰减

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2603.22774
**标签**：多GPU · LLM推理 · CPU瓶颈 · 推理服务 · GPU利用率

大规模 ML 负载越来越依赖多 GPU 系统，但性能常被忽视的 CPU 所限制。本文通过细致研究现代 LLM serving 负载发现：多 GPU 性能下降往往不是因为 GPU 饱和，而是 CPU 无法让 GPU 保持忙碌。在受限 CPU 分配下，系统出现内核启动延迟、通信停滞、分词延迟上升，导致严重 GPU 欠利用。

**核心要点**：
- 揭示多 GPU LLM 推理中 CPU（而非 GPU）是隐藏的关键瓶颈
- 智能体式 serving 中长上下文累积加剧 CPU 分词负担，进一步恶化 GPU 利用率
- 即便采用进程级分离与适度优化，瓶颈依旧存在，需系统性调度改进

## 3. TreeGraft：面向树状投机解码的自适应多草稿器嫁接框架

**来源**：arXiv cs.CL
**链接**：https://arxiv.org/abs/2608.26112
**标签**：投机解码 · 推理加速 · 树结构 · 草稿模型 · LLM推理

投机解码通过「先起草再验证」加速 LLM 推理，树状方法将候选组织成多条路径以提升接受长度。现有树状方法对所有起草步使用单一草稿器，陷入「小草稿器快但质量低、大草稿器质量高但延迟大」的两难。本文提出 TreeGraft 多草稿器框架，由不同代价的草稿器共同构建共享草稿树。

**核心要点**：
- 多草稿器协同构建共享草稿树，兼顾生成速度与树质量
- 用强草稿器对弱草稿器打分重估、重选嫁接位置、恢复被遗漏的优路径
- 强草稿器扩展以非破坏方式融入，保留已有候选结构

## 4. 让网络成为分布式训练的主动参与者：智能网络方案

**链接**：https://arxiv.org/abs/2608.26453
**标签**：分布式训练 · WAN · 组播 · FPGA · 同步调度

跨广域网（WAN）分布式训练受限于带宽、高延迟和不均衡拓扑。本文主张让网络成为训练的主动参与方：系统侧利用组播复制出向流量、在线 FPGA 聚合入向流量，缓解 egress/ingress 瓶颈；算法侧提出优化框架，生成围绕网络拓扑的丰富同步调度（旋转孤岛团），并在模拟 DoubleZero 的九城拓扑上验证。

**核心要点**：
- 将数据中心内组播 + 在线 FPGA 聚合技术扩展到跨 WAN 分布式训练
- 算法侧给出围绕拓扑生成同步调度（旋转孤岛团）的优化框架
- 在九城拓扑上演示，缓解跨地域训练的带宽与时延瓶颈

## 5. 二值化神经网络的剪枝：专用框架与全局加权算法

**链接**：https://arxiv.org/abs/2608.26233
**标签**：模型压缩 · 二值化 · 剪枝 · 边缘部署 · PyTorch

将深度网络极端压缩到全二值化，可大幅降低内存与计算复杂度，便于部署到 FPGA/微控制器等受限边缘硬件。但现有剪枝策略不适合二值化表示，难以转化为真实硬件收益。本文提出基于 PyTorch 的科研框架，整合冻结与剪枝机制，并给出跨抽象层级考量参数相对重要性的新剪枝法。

**核心要点**：
- 首个面向二值化网络的 PyTorch 剪枝/冻结研究框架，支持快速复现与原型
- 新剪枝法考虑不同抽象层级学习参数的相对重要性
- 二值化 + 剪枝协同，进一步压缩边缘设备上的模型体积与算力

## 6. MeshReduce-U：面向不规则归约的编译器引导通信压缩与路由

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2608.26220
**标签**：编译优化 · 片上网络 · 空间加速器 · 通信压缩 · 路由

许多不规则神经负载会产生倾斜的「多对一」归约与重复邻域、非局部通信。传统 NoC 映射器针对固定通信图优化布局与路由，但结合（associative）归约本可在路由前消除流量。本文提出 MeshReduce-U，一个面向 mesh-NoC 空间加速器的编译器引导通信压缩与路由框架。

**核心要点**：
- 编译器在路由前合并同位源、组建局部聚合岛，直接消除冗余流量
- 以融合「使用感知」代价路由剩余定宽载波，并给出确定性重放模型评估时延
- 在 20 个负载的神经网络 zoo 上显著降低总链路使用（TLU）与融合链路使用

## 7. 有限 Newton-Schulz 的 Muon：非光滑非凸优化中的平滑收益

**来源**：arXiv cs.LG
**链接**：https://arxiv.org/abs/2608.26288
**标签**：优化器 · Muon · LLM预训练 · Newton-Schulz · 收敛理论

Muon 已成为 LLM 预训练中矩阵参数强有力的优化器，用少量 Newton-Schulz 迭代近似正交化动量。既有理论把有限迭代当作近似误差，认为只会损害保证。本文证明有限 Newton-Schulz 对非光滑非凸优化反而有益：通过 online-to-nonconvex 转换，有限迭代将不连续的 polar 映射平滑为奇异值的 Lipschitz 映射。

**核心要点**：
- 首次证明有限 Newton-Schulz 迭代在理论上可带来正面收益而非误差
- 用 online-to-nonconvex 转换得到驻点保证，平滑化奇异值映射
- 为 Muon 在大规模 LLM 预训练的收敛性提供新的理论解释
