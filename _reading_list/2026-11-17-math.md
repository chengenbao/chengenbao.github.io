## 【几何】三角形周长与面积的几何约束

**难度：** ⭐⭐⭐（高中竞赛难度 · 解析几何 / 椭圆定义 / 几何存在性）

**题目来源：** [2019 AMC 10B Problem 10](https://wiki.randommath.com/amc10/2019/part-b/problem-10)

**知识点：** 三角形面积公式 · 椭圆的定义（焦点与准线）· 几何存在性分析

**题目：**

在平面内，点 $A$ 与点 $B$ 相距 $10$ 个单位。平面上有多少个点 $C$，使得 $\triangle ABC$ 的周长为 $50$ 且面积为 $100$？

---

### 解题过程

**思路：将条件分别转化为几何轨迹，再看两轨迹是否相交。**

1. **面积条件 → 两条平行线。**
   以 $AB$ 为底，底边长 $|AB| = 10$。三角形面积
   $$S = \frac12 \cdot |AB| \cdot h = \frac12 \cdot 10 \cdot h = 100$$
   解得高 $h = 20$。因此点 $C$ 必须落在与 $AB$ 平行、且距离 $AB$ 为 $20$ 的**两条直线**之一上。

2. **周长条件 → 一个椭圆。**
   周长 $50$，已知一边 $AB = 10$，故另外两边之和
   $$CA + CB = 50 - 10 = 40$$
   到两定点 $A, B$ 距离之和为常数 $40$（且 $40 > |AB| = 10$），由椭圆定义，点 $C$ 落在以 $A, B$ 为焦点、长轴 $2a = 40$（即 $a = 20$）的椭圆上。
   焦距 $2c = |AB| = 10$，故 $c = 5$，短半轴
   $$b = \sqrt{a^2 - c^2} = \sqrt{20^2 - 5^2} = \sqrt{400 - 25} = \sqrt{375} \approx 19.36$$

3. **判断相交。**
   椭圆中心在 $AB$ 中点，短半轴长度 $\sqrt{375} \approx 19.36 < 20$，说明椭圆上任意一点到 $AB$ 所在直线的距离都**不超过** $\sqrt{375} < 20$。
   而面积条件要求 $C$ 到 $AB$ 的距离恰为 $20$。两条轨迹不可能相交。

   **更简洁的论证：** 若 $C$ 到 $AB$ 的距离为 $20$，则在直角 $\triangle$ 中有 $CA \ge 20,\ CB \ge 20$，于是 $CA + CB \ge 40$，等号仅在 $C$ 的垂足恰为 $A$ 或 $B$ 时取得（退化为线段，非三角形）。实际三角形中至少一边严格大于 $20$，故 $CA + CB > 40$，与周长条件 $CA + CB = 40$ 矛盾。

**结论：不存在满足条件的点 $C$，答案为 $0$ 个（选项 $\textbf{(A)}\ 0$）。**

---

### 常见错误

- 误以为「给定两边和面积就能画出很多三角形」，忽略了周长固定带来的强约束。
- 忘记椭圆短半轴 $\sqrt{375} < 20$，从而漏判相交性。
- 把「点到直线距离」与「椭圆上点到轴的最大距离」混淆。

---

### 知识背景

本题综合了三角形面积、椭圆定义与轨迹相交的存在性判断。椭圆的核心定义是「到两焦点距离之和为常数」，当该常数略大于焦距时椭圆很扁。将代数条件（周长、面积）转化为几何轨迹（直线、椭圆）再判相交，是处理「满足条件的点有多少个」类问题的标准思路。

## 【数论】互补因子之差的数论构造

**难度：** ⭐⭐⭐⭐（高中竞赛难度 · 整除 · 因式分解 · 配方）

**题目来源：** [2023 AMC 10A Problem 23](https://wiki.randommath.com/amc10/2023/part-a/problem-23)

**知识点：** 因数分解 · 配方法 · 平方差公式 · 因数枚举

**题目：**

若正整数 $c$ 有正整数因数 $a, b$ 满足 $c = ab$，则称 $a, b$ 为 $c$ 的一对**互补因子**。设 $N$ 是一个正整数，它有一对互补因子相差 $20$，另有另一对互补因子相差 $23$。求 $N$ 的各位数字之和。

---

### 解题过程

设两对互补因子分别为 $(a, a+20)$ 与 $(b, b+23)$，则
$$a(a+20) = b(b+23) = N$$
显然 $b < a$（因为对同一个 $N$，因子差越大，较小的因子越小）。

**方法一：配方 + 平方差**

将两式乘以 $4$ 并配方：
$$(2a+20)^2 = 4a(a+20) + 400 = 4N + 400$$
$$(2b+23)^2 = 4b(b+23) + 529 = 4N + 529$$
两式相减得
$$(2b+23)^2 - (2a+20)^2 = 129$$
利用平方差公式：
$$(2b+2a+43)(2b-2a+3) = 129 = 3 \times 43$$
其中 $2b+2a+43 > 43$，而 $129$ 的大于 $43$ 的正因数只有 $129$ 本身，故
$$2b+2a+43 = 129,\qquad 2b-2a+3 = 1$$
解得 $a = 22,\ b = 21$。于是
$$N = 22 \times 42 = 924 = 2^2 \cdot 3 \cdot 7 \cdot 11$$
各位数字之和：$9 + 2 + 4 = \boxed{15}$（选项 $\textbf{(C)}$）。

**方法二：利用差值范围**

由 $a(a+20) = b(b+23)$ 且 $b < a$，有 $a+20 > b+23 \Rightarrow a < b+3$，即 $b < a < b+3$。
因 $a, b$ 为整数，只能 $a = b+1$ 或 $a = b+2$。

- 若 $a = b+1$：$(b+1)(b+21) = b(b+23) \Rightarrow b^2+22b+21 = b^2+23b \Rightarrow b = 21$，得 $N = 21\times44 = 924$。
- 若 $a = b+2$：$(b+2)(b+22) = b(b+23) \Rightarrow b^2+24b+44 = b^2+23b \Rightarrow b = -44$（负，舍去）。

同样得到 $N = 924$，数字和为 $15$。

---

### 常见错误

- 没有先判断 $b < a$ 或 $a < b+3$，导致因数分解时出现多余解。
- 平方差分解后忽略「大因数必须 $> 43$」这一限制，盲目枚举。
- 算错 $129$ 的因数分解（$129 = 3 \times 43$，不是平方数）。

---

### 知识背景

「互补因子」即一对乘积为 $N$ 的因数。本题关键在于把「差固定」转化为方程 $x(x+d)=N$，再通过配方或差值放缩求解。配方法与平方差是数论中处理「两因数差」问题的经典工具，常配合目标数的因数分解来锁定唯一解。
