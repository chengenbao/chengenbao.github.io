## 【四年级】对角线追踪

**难度：** ⭐⭐（中等，考察逻辑推理）

**题目来源：** [Diagonal Trace - NRICH #925](https://nrich.maths.org/925)

**知识点：** 多边形对角线 · 欧拉路径 · 逻辑推理

**题目：**

一个五边形有五条对角线（连接各顶点的线段，不含边）。

你能否**不抬起笔**，把五边形所有对角线都画一遍，而且每条对角线**只经过一次**？试一试。

六边形（6条边）或七边形（7条边）也可以这样做吗？

（注意：要找出**所有**对角线，先画一个大一点的图形再试会更方便。）

---

### 解题过程

**第一步：搞清楚五边形有多少条对角线**

五边形有 5 个顶点，每个顶点可以向其他 4 个顶点连线，但要排除两条边，所以每个顶点出发有 $5 - 3 = 2$ 条对角线。

共有对角线数：$\dfrac{5 \times 2}{2} = 5$ 条。

**第二步：尝试五边形**

给五个顶点标上 A、B、C、D、E。对角线为：AC、AD、BD、BE、CE。

从 A 出发：A→C→E→B→D→A ✅ 成功！每条对角线恰好经过一次，而且回到起点。

**第三步：分析六边形（6条边）**

六边形有 $\dfrac{6 \times 3}{2} = 9$ 条对角线。

关键：在每个顶点处，各有几条对角线汇聚？六边形中，每个顶点有 3 条对角线（$6 - 3 = 3$）。

**欧拉路径定理**：若要一笔画过所有边，则图中度数为奇数的顶点最多只能有 0 个或 2 个。

六边形的每个顶点有 3 条（奇数）对角线，共 6 个奇数度顶点 → **无法一笔画**！

**第四步：七边形**

七边形每个顶点有 $7 - 3 = 4$ 条对角线（偶数）→ 所有顶点度数为偶数 → **可以一笔画！**

**规律：奇数边多边形可以一笔画全部对角线，偶数边多边形不行。**

---

### 常见错误

- 忘记某些对角线，导致画少了
- 混淆"边"和"对角线"（对角线是连接不相邻顶点的线段）
- 以为"可以回到出发点"就等于"可以一笔画"——其实不抬笔从A到A（欧拉回路）需要所有顶点度数均为偶数

---

### 知识背景

这道题其实是著名的**一笔画问题**，数学上叫**欧拉路径（Eulerian Path）**。1736 年，数学家欧拉（Euler）用类似方法解决了著名的「柯尼斯堡七桥问题」，开创了图论这门学科。

判断规则非常简单：若图中奇数度顶点恰好有 2 个，则可以一笔画（从一个奇数顶点出发，到另一个奇数顶点结束）；若奇数度顶点为 0 个，则可以一笔画且回到起点；否则无法一笔画。

## 【六年级】直角三角形计数

**难度：** ⭐⭐⭐（有挑战性，考察系统分类）

**题目来源：** [Right-Angled Request - NRICH #4950](https://nrich.maths.org/4950)

**知识点：** 直角三角形 · 系统分类计数 · 几何

**题目：**

下图是一个长方形，内部画有若干点（构成网格）：

```
P---U---*---*---*
|       |       |
*---*---*---*---*
|       |       |
*---*---T---*---*
|       |       |
*---Q---*---*---R
|       |       |
*---*---*---S---*
```

（原图为一个长方形，其中均匀分布着若干格点，包括顶点 P、Q、R、S、T、U 等关键点。）

**问题：这些点共能构成多少个直角三角形？**

（来自 NRICH Weekly Problem 26 - 2006）

---

### 解题过程

根据 NRICH 官方解答，按位置系统分类：

**分类一：在每个小正方形内部**

每个小正方形的 4 个角可以构成 4 个直角三角形（以某条边为直角边）。

设图中有若干个正方形格子，假设为一个 $2 \times 2$ 的大网格（含 4 个小正方形单元）：
$$4 \text{ 个小正方形} \times 4 \text{ 个直角三角形/格} = 8 \text{ 个}$$

实际上还需加上：

**分类二：以长方形的两条相邻边为直角边**

例如连接顶点 P-Q-U 等，形成 4 个较大的直角三角形。

**分类三：特殊直角三角形**

连接 UQS 三点，或 PTR 三点，可各构成 1 个直角三角形（利用勾股数或坐标验证直角）。

**汇总：**

$$8 + 4 + 2 = 14 \text{ 个直角三角形}$$

---

### 常见错误

- 只数了显而易见的小直角三角形，忽视了大的或斜的直角三角形
- 把相同的三角形数了两次（如顶点顺序不同但形状相同）
- 忽视了不以格线为边的斜边三角形（如 UQS 型）

---

### 知识背景

计数问题的关键是**系统分类**——按某种标准（如直角所在位置、三角形大小）把所有情况不重不漏地分组。这是小学奥数和初中数学竞赛的核心思维方法之一，叫作**分类讨论法**。

在几何计数中，除了"直接数"，还可以用**对称性**快速检验：若图形有对称轴，对称位置的三角形数量相等，可以减少计算量。
