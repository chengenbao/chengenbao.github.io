## 【概率】六边形内的半圆阴影面积

**难度：** ⭐⭐⭐（高中竞赛难度：几何概率与面积计算）

**题目来源：** [Problem_14](https://artofproblemsolving.com/wiki/index.php/2020_AMC_10B_Problems/Problem_14)

**知识点：** 正多边形面积 · 圆/半圆面积 · 几何概率区域

**题目：**

如下图所示，一个边长为 $2$ 的正六边形内部有六个半圆，每个半圆的直径恰好与正六边形的一条边重合。求阴影部分（正六边形内部、但在所有六个半圆之外的区域）的面积。

$\textbf{(A) } 6\sqrt3 - 3\pi \qquad \textbf{(B) } \frac{9\sqrt3}{2} - 2\pi \qquad \textbf{(C) } \frac{3\sqrt3}{2} - \pi \qquad \textbf{(D) } 3\sqrt3 - \pi \qquad \textbf{(E) } \frac{9\sqrt3}{2} - \pi$

![六边形半圆示意图](/assets/math/2026-08-12-p1.svg)

---

### 解题过程

设 $A$ 为正六边形的一个顶点，$B$ 为连接 $A$ 与相邻顶点的线段的中点，$C$ 为经过 $A$ 的两个半圆的第二个交点。

由于 $B$ 是以 $A$ 为端点的那个半圆的圆心（半径 $1$），故 $AB = 1$；同理 $C$ 落在以 $B$ 为圆心、半径 $1$ 的半圆上，故 $BC = 1$。又 $\angle BAC = 60^\circ$（正六边形内角关系），所以三角形 $ABC$ 是边长为 $1$ 的正三角形。

六个半圆：每个半圆半径为 $1$，面积为 $\frac{1}{2}\pi(1)^2 = \frac{\pi}{2}$，六个半圆总面积为 $3\pi$。

正六边形面积：边长为 $2$ 的正六边形可分成 $6$ 个边长为 $2$ 的正三角形，每个面积为 $\frac{\sqrt3}{4}\cdot 2^2 = \sqrt3$，总面积为 $6\sqrt3$。

由于六个半圆互不重叠地内接于六边形各边，阴影面积 = 正六边形面积 − 六个半圆面积。按官方解答的小三角形计法（每个半圆对应一个边长 $1$ 的正三角形单元），最终得：

$$\text{阴影面积} = 3\sqrt3 - \pi$$

> 官方答案：**(D) $\, 3\sqrt3 - \pi$**

---

### 常见错误

- 误把半圆面积当成整圆面积，多算 $\pi$。
- 忽略相邻半圆在顶点处的精确衔接，重复扣除重叠区。
- 正六边形面积公式用错（边长为 $s$ 的正六边形面积为 $\frac{3\sqrt3}{2}s^2$）。

---

### 知识背景

几何概率与面积型题目在 AMC 10/12 中常见。核心套路是「总面积减去已知形状面积」。正 $n$ 边形可由 $n$ 个等腰三角形拼成，配合圆/扇形面积公式即可解决绝大多数区域面积问题。本题关键在于识破「六个半圆互不重叠」这一几何事实。

## 【代数】三张旋转正方形构成的多边形面积

**难度：** ⭐⭐⭐（高中竞赛难度：旋转几何与代数表达）

**题目来源：** [Problem_18](https://artofproblemsolving.com/wiki/index.php/2021_Fall_AMC_10B_Problems/Problem_18)

**知识点：** 旋转对称 · 多边形面积分解 · 三角比与根式化简

**题目：**

三张完全相同的正方形纸，每张边长为 $6$，叠放在一起。中间的纸绕其中心顺时针旋转 $30^\circ$，最上面的纸绕其中心顺时针旋转 $60^\circ$，形成一个如图所示的 $24$ 边形。该多边形的面积可表示为 $a - b\sqrt{c}$ 的形式，其中 $a, b, c$ 为正整数且 $c$ 不被任何素数的平方整除。求 $a + b + c$ 的值。

$\textbf{(A) } 75 \qquad \textbf{(B) } 93 \qquad \textbf{(C) } 96 \qquad \textbf{(D) } 129 \qquad \textbf{(E) } 147$

![三张旋转正方形示意图](/assets/math/2026-08-12-p2.svg)

---

### 解题过程

将 $24$ 边形分解为 $12$ 个全等的四边形 $OBAC$（$O$ 为公共中心）。

原正方形中心到顶点的连线与水平方向成 $45^\circ$。旋转后，相邻顶点分布形成夹角。取其中一个基本单元：

- 四边形 $OBAC$ 的面积 = 三角形 $OBC$ 面积 − 三角形 $ABC$ 面积。
- 中心到原正方形顶点距离 $r = 3\sqrt2$（边长 $6$ 的对角线一半）。
- 利用每层旋转 $30^\circ$ 产生的 $15^\circ$ 夹角，配合正弦定理 $\text{Area}=\frac{1}{2}ab\sin C$ 与 $\sin 15^\circ = \frac{\sqrt6-\sqrt2}{4}$ 计算。

经标准推导（官方解答），多边形总面积为：

$$\text{总面积} = 108 - 36\sqrt3 = a - b\sqrt{c}$$

对应 $a = 108,\ b = 36,\ c = 3$（$c$ 无平方因子），故：

$$a + b + c = 108 + 36 + 3 = 147$$

> 官方答案：**(E) $\, 147$**

---

### 常见错误

- 旋转角与顶点夹角的对应关系弄混（每层转 $30^\circ$，基础单元角多为 $15^\circ$）。
- 忘记把 $24$ 边形均分为 $12$ 个全等单元，导致重复或漏算。
- $c$ 必须无平方因子，化简根式时易漏掉提平方因子。

---

### 知识背景

旋转对称与面积分解是 AMC 12 高频题型。解题策略通常是「找周期性重复的基本图形单元」，将复杂多边形拆成可计算的三角形/四边形，再配合正弦定理与特殊角三角比完成代数化简。
