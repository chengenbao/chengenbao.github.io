## 1. Agent libOS：面向长驻 LLM Agent 的类库 OS 运行时架构

**来源**：cs.OS  
**链接**：https://arxiv.org/abs/2606.03895  
**标签**：LLM Agent · 系统架构 · Library OS · 长驻进程 · 能力隔离

随着大模型 Agent 从单次对话演进为持续运行的软件进程，传统进程模型已不再适配。Agent libOS 借鉴操作系统中库 OS 的思路，为 LLM Agent 提供进程级别的生命周期管理、资源隔离和能力访问控制，使 Agent 能够稳定长期运行于真实系统环境中。该工作将 OS 抽象引入 AI 运行时，是系统软件与大模型交汇的重要探索。

**核心要点**：
- 将 OS library 思想迁移到 LLM Agent 运行时，解决长驻 Agent 的生命周期管理问题
- 提供细粒度的能力访问控制（Capability Control），限制 Agent 可访问的系统资源
- 支持持久化状态与跨任务连续性，区别于传统请求-响应模式的无状态架构
- 为构建可信、可审计的 Agent 基础设施提供系统级方案

## 2. ALAR：自适应潜空间 Agent 推理

**来源**：cs.CL  
**链接**：https://arxiv.org/abs/2606.02871  
**标签**：Chain-of-Thought · 推理加速 · 潜空间推理 · 自适应计算 · LLM 推理优化

扩展链式思维（CoT）显著提升了大模型在复杂任务上的表现，但也带来巨大的 token 开销。ALAR 在潜空间中执行自适应 Agent 推理，根据任务难度动态调整推理深度，在保持准确率的同时大幅降低生成 token 数量。该方法为推理效率与能力之间的权衡提供了新思路。

**核心要点**：
- 在潜空间（Latent Space）中执行推理，绕开显式 token 生成的开销
- 自适应调整推理步数，简单任务快速收敛，复杂任务深度展开
- 在多个推理基准上保持与 full CoT 可比的精度，token 开销显著降低
- 为 inference-time scaling 提供更高效的计算路径

## 3. Fast-dLLM++：基于 Fréchet 轮廓解码的扩散语言模型加速推理

**来源**：cs.CL  
**链接**：https://arxiv.org/abs/2606.02955  
**标签**：扩散语言模型 · 推理加速 · 并行解码 · Fréchet 距离 · Token 生成

扩散语言模型（Diffusion LLM）以并行 token 生成为卖点，但多轮去噪迭代使推理速度受限。Fast-dLLM++ 提出 Fréchet 轮廓解码（Fréchet Profile Decoding），通过监测 token 分布的收敛曲线跳过冗余去噪步骤，在保证输出质量的前提下实现显著加速。这是扩散式语言生成迈向实用化的关键一步。

**核心要点**：
- 引入 Fréchet 距离对 token 分布收敛状态进行实时监测
- 自适应跳过已收敛 token 的后续去噪步骤，减少无效计算
- 相比基线扩散 LLM 实现多倍推理加速，同时维持生成质量
- 为扩散式文本生成模型的工程落地提供实用的优化方案

**标签**：LoRA · 持续学习 · 模型适配 · 增量微调 · LLM 服务

**核心要点**：
- 将旧版本 LoRA adapter 权重用于新版本适配的热启动，减少从头训练的计算量
- 提出知识对齐机制，处理新旧版本模型架构或任务分布变化带来的迁移偏差
- 在多个模型迭代场景下验证收敛速度和最终性能均优于冷启动 LoRA
- 为持续演进的 LLM 服务提供低成本高效的适配更新流程

## 5. 量化 LLM 中间层隐状态可线性解码幻觉信号

**来源**：cs.LG  
**链接**：https://arxiv.org/abs/2606.02628  
**标签**：幻觉检测 · 量化 LLM · 中间层激活 · 线性探针 · 可信 AI

幻觉是大模型可信部署的核心挑战之一。本文在量化 LLM 的中间层隐状态中发现了可线性分离的真实性信号，即通过简单的线性探针便可在解码前预测模型是否会产生幻觉。研究进一步表明量化本身不会破坏这一内部信号，为低成本幻觉检测与干预提供了新的实用路径。

**核心要点**：
- 量化 LLM（INT4/INT8）的中间层激活中保留了可线性分离的 truthfulness 信号
- 轻量级线性探针在解码前即可以高准确率预测幻觉输出
- 量化操作不显著降低幻觉信号的线性可分性，部署友好
- 为推理阶段幻觉干预（如引导解码、拒绝采样）提供可靠的早期信号

## 6. 多段注意力：面向高效 KV Cache 管理的 LLM 加速推理

**来源**：cs.AR  
**链接**：https://arxiv.org/abs/2606.02964  
**标签**：KV Cache · 注意力加速 · LLM 推理 · 内存管理 · 硬件优化

KV Cache 是大模型推理中避免重复注意力计算的核心机制，但其内存占用和带宽需求随序列长度急剧增加。多段注意力（Multi-Segment Attention）将 KV Cache 按访问热度划分为多个段，针对各段采用差异化的驱逐与预取策略，在现代加速器上显著降低内存带宽压力并提升推理吞吐量。

**核心要点**：
- 将 KV Cache 按访问频率分段，冷热数据采用不同的内存管理策略
- 设计硬件友好的段级预取与驱逐算法，减少 HBM 带宽瓶颈
- 在长上下文推理场景下实现可观的吞吐提升，与现有 PagedAttention 正交可组合
- 在主流 GPU 架构上验证了方案的实际加速效果

**核心要点**：
- 提出统一的 MX 微缩放格式，同时支持低精度推理量化与训练量化
- 集成在线（On-the-fly）故障检测机制，无需离线校验开销
- 在主流矩阵运算加速器上验证了故障检测的准确性与性能开销
- 为下一代 AI 芯片的可靠量化计算提供标准化参考方案
