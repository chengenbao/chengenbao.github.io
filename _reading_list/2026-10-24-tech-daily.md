## 2. FIGFLEX：与低比特 LLM 量化协同设计的混合精度 FP-INT GEMM 加速器

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2610.30480
**标签**：硬件加速器 · 低比特量化 · GEMM · FP-INT · 存算协同

权重-only 量化将激活保留为浮点、权重存为低比特整数，使主导计算变为浮点-整数（FP-INT）矩阵乘。现有 GPU 在张量核前需把权重反量化为 FP16，且位并行 FP-INT 加速器只支持单一权重精度，难以匹配 2-3bit 混合精度量化器。FIGFLEX 提出与低比特混合精度量化协同设计的 FP-INT GEMM 加速器，直接以混合精度整数权重参与计算，提升硬件利用率与能效。

**核心要点**：
- 揭示现有 GPU 对低比特权重仍需反量化到 FP16 的算力浪费
- 设计支持多精度权重并行的 FP-INT 矩阵乘硬件
- 与量化算法协同设计，让 2-3bit 混合精度真正落地到硬件

- 设计持久化感知的块淘汰与 DRAM-SSD 协同重载
- 在有限 SSD 带宽下显著降低多轮 Agent 预填充延迟

## 6. SnakeCharmer：编排效用、时效与放置的 GPU 预取

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2610.30990
**标签**：GPU · 预取 · 内存墙 · Warp · 放置策略

GPU 依赖海量线程级并行掩盖内存延迟，但大量 warp 同时等待内存仍会造成严重停顿。基于地址预测的 GPU 预取器能缓解停顿，但「预测准」不等于「收益高」：预取只有在值得发起、时机正确、且不被有害置换驱逐时才有效。SnakeCharmer 从效用、时效、放置三个维度统一编排 GPU 预取，让预测真正转化为性能提升。

**核心要点**：
- 区分预取「预测准确」与「实际受益」的差距
- 从效用、时效、缓存放置三方面协同决策预取
- 在内存受限 GPU 负载上缓解 warp 停顿、提升吞吐
