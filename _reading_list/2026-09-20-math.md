## 【代数】三数和与绝对值

**难度：** ⭐⭐⭐（高中竞赛基础代数）

**题目来源：** [2022 AMC 10A Problem 3](https://artofproblemsolving.com/wiki/index.php/2022_AMC_10A_Problems/Problem_3)

**知识点：** 一元一次方程 · 绝对值 · 列方程解应用题

**题目：**

三个数的和为 $96$。第一个数是第三个数的 $6$ 倍，第三个数比第二个数小 $40$。求第一个数与第二个数之差的绝对值。

$\textbf{(A) } 1 \qquad \textbf{(B) } 2 \qquad \textbf{(C) } 3 \qquad \textbf{(D) } 4 \qquad \textbf{(E) } 5$

---

### 解题过程

设第三个数为 $x$。

根据题意：
- 第一个数 $= 6x$；
- 第三个数比第二个数小 $40$，即第二个数 $= x + 40$。

三个数之和为 $96$，列出方程：

$$6x + (x + 40) + x = 96$$

合并同类项：

$$8x + 40 = 96$$

$$8x = 56 \quad\Rightarrow\quad x = 7$$

因此：
- 第一个数 $= 6 \times 7 = 42$；
- 第二个数 $= 7 + 40 = 47$。

它们之差的绝对值为：

$$|42 - 47| = |-5| = \boxed{5}$$

故选 **(E) 5**。

---

### 常见错误

- 把"第三个数比第二个数小 $40$"误列成 $x = (x+40) - 40$ 后写成第二个数 $= x - 40$，导致符号反掉，最终算出 $-5$ 而错选绝对值对应的负数选项。
- 列方程时漏加某个数，例如写成 $6x + x = 96$，得到错误答案。
- 求出差 $-5$ 后忘记取绝对值，直接选了带负号的选项（本题没有负选项，但仍需注意）。

---

### 知识背景

本题属于"设未知数—列方程—求解"的基础代数建模题，是 AMC 10 中典型的低难度题（通常出现在第 1–5 题）。其核心考点只有一个：**把文字关系准确翻译成代数式，并小心处理"谁比谁大/小"的方向**。这类题看似简单，但每年都有大量考生因为设错变量或搞反大小关系而失分。训练时建议先把"较大量"明确写出来，再反向表示"较小量"，能有效避免符号错误。

## 【组合】数据集平均数的可能取值

**难度：** ⭐⭐⭐（高中竞赛计数与数据分析）

**题目来源：** [2022 AMC 10A Problem 8](https://artofproblemsolving.com/wiki/index.php/2022_AMC_10A_Problems/Problem_8)

**知识点：** 算术平均数 · 分类讨论 · 计数求和

**题目：**

一个数据组由 $6$ 个（可重复的）正整数组成：$1,\ 7,\ 5,\ 2,\ 5$ 以及 $X$。这 $6$ 个数的算术平均数恰好等于数据组中的某一个数值。求 $X$ 的所有可能取值之和。

$\textbf{(A) } 10 \qquad \textbf{(B) } 26 \qquad \textbf{(C) } 32 \qquad \textbf{(D) } 36 \qquad \textbf{(E) } 40$

---

### 解题过程

先算已知五个数的和：

$$1 + 7 + 5 + 2 + 5 = 20$$

六个数的总和为 $20 + X$，平均数为 $\dfrac{20 + X}{6}$。

题目说"平均数等于数据组中的某一个数值"，而数据组中的数值只能是已知集合 $\{1, 7, 5, 2, 5\}$ 中的某个，或者就是 $X$ 本身。因此分情况讨论：

**情形 1：平均数是 $5$**

$$\frac{20 + X}{6} = 5 \quad\Rightarrow\quad 20 + X = 30 \quad\Rightarrow\quad X = 10$$

验证：$X=10$ 时数据组为 $\{1,7,5,2,5,10\}$，平均数 $=\frac{30}{6}=5$，确实在数据组中。✅

**情形 2：平均数是 $7$**

$$\frac{20 + X}{6} = 7 \quad\Rightarrow\quad 20 + X = 42 \quad\Rightarrow\quad X = 22$$

验证：$X=22$ 时平均数 $=\frac{42}{6}=7$，在数据组中。✅

**情形 3：平均数是 $X$ 本身**

$$\frac{20 + X}{6} = X \quad\Rightarrow\quad 20 + X = 6X \quad\Rightarrow\quad 5X = 20 \quad\Rightarrow\quad X = 4$$

验证：$X=4$ 时平均数 $=\frac{24}{6}=4$，等于 $X$，满足条件。✅

（可以检查平均数等于 $1$ 或 $2$ 的情形：$\frac{20+X}{6}=1\Rightarrow X=-14$ 非正整数，舍去；$=2\Rightarrow X=-8$ 同样舍去。）

所以 $X$ 的所有可能取值为 $10,\ 22,\ 4$，其和为：

$$10 + 22 + 4 = \boxed{36}$$

故选 **(D) 36**。

---

### 常见错误

- 只考虑平均数等于已知数（$5$ 或 $7$），漏掉"平均数等于 $X$ 本身"这一情形，从而只得到 $10+22=32$，错选 **(C)**。
- 忘记平均数也可能等于 $X$，或反过来把 $X$ 当成只能取已知值之一。
- 验证环节疏漏，没有排除平均数等于 $1$ 或 $2$ 时产生负 $X$ 的情况（本题正整数条件已自动排除，但养成验证习惯很重要）。

---

### 知识背景

本题融合了"算术平均数"与"分类讨论"两个考点，是 AMC 10 中常见的组合/数据分析类题目。关键思路是：**平均数必须等于数据组中的某个实际出现的值**，因此把"可能的值"逐一枚举并解方程即可。这类题考验的是不重不漏的分类能力——尤其要记得 $X$ 加入后，它本身也可能成为那个"等于平均数的数值"。在竞赛中，凡是出现"某统计量与自身集合元素相关"的描述，都应第一时间想到"未知数本身也是候选值"这一陷阱。
