## 1. mzCache：多任务场景下的端侧 LLM 内存管理

**来源**：cs.OS（arXiv）
**链接**：https://arxiv.org/abs/2609.01338
**标签**：边缘推理 · 内存管理 · KV Cache · 移动OS · 多任务

端侧大模型推理正受到广泛关注，但移动设备处于高度动态的多任务环境，用户频繁切换应用会触发操作系统将 LLM 的权重与 KV Cache 驱逐出内存。新请求到来时需通过慢速存储读取恢复，造成明显延迟。mzCache 提出了面向多任务端侧场景的 LLM 内存管理体系，降低恢复开销、提升切换后的推理响应速度。

**核心要点**：
- 针对移动端多任务导致的权重/KV Cache 被 OS 驱逐问题建模并优化
- 减少从慢速存储恢复被驱逐内存的延迟，提升推理首 token 响应
- 为端侧 LLM 在真实多应用环境下的稳定部署提供系统级方案

## 2. DynaNDE：面向批处理 MoE 推理的动态近数据专家调度

**来源**：cs.AR（arXiv）
**链接**：https://arxiv.org/abs/2609.00407
**标签**：MoE推理 · 近数据处理 · NPU-NDP · 专家调度 · 数据搬运

MoE 模型可高效扩展 LLM 推理，但在 NPU 系统上因专家权重数据搬运开销大而受限。近数据处理（NDP）通过 NPU-NDP 协同缓解带宽瓶颈，但现有方案忽略了硬件异构、专家级动态并发等。DynaNDE 提出动态近数据专家调度，在协同执行中按硬件特性与运行时负载分配专家计算，降低数据搬运并提升批处理吞吐。

**核心要点**：
- 揭示 NPU-NDP 协同 MoE 推理中数据搬运是核心瓶颈
- 提出考虑硬件异构与专家动态并发的运行时调度策略
- 在批处理场景下同时降低数据搬运开销并提升吞吐

## 3. LLM-PRISM：刻画 GPU 永久故障引发的大模型训练静默数据损坏

**来源**：cs.AR（arXiv）
**链接**：https://arxiv.org/abs/2604.10390
**标签**：GPU故障 · 静默数据损坏 · 大模型训练 · 容错 · RTL仿真

大规模 LLM 训练日益受制造逃逸与硅老化带来的硬件缺陷影响，这些缺陷表现为静默数据损坏（SDC），会在训练过程中扰动梯度与参数。LLM-PRISM 将 RTL 级 GPU 故障仿真与嵌入训练循环的随机注入引擎结合，系统性刻画预训练对硬件故障的弹性，为容错训练与可靠性评估提供方法论。

**核心要点**：
- 指出大模型训练中的 SDC 来自 GPU 永久故障且难以察觉
- RTL 级故障仿真 + 随机注入引擎量化训练容错弹性
- 为大规模训练可靠性评估与容错机制设计提供基础

## 4. REAL-Q：基于动态梯度下降的端到端 LLM 量化

**来源**：cs.LG（arXiv）
**链接**：https://arxiv.org/abs/2609.00049
**标签**：LLM量化 · PTQ · 端到端优化 · 梯度下降 · 低比特

训练后量化（PTQ）对资源受限部署至关重要。现有最优方法用闭式二阶求解器逐层量化，为可解析而大量近似全局损失并冻结 Hessian，无法刷新。REAL-Q 提出端到端量化框架，通过动态梯度下降联合优化各层量化参数，缓解跨通道耦合等近似误差，在严格约束下获得更优低比特精度。

**核心要点**：
- 指出现有 PTQ 闭式求解对全局损失的过度近似问题
- 用动态梯度下降实现跨层端到端量化参数联合优化
- 在同等低比特约束下取得优于单层冻结方法的精度

## 5. CUDA-Harness：从自然语言生成并优化智能体 CUDA 内核

**来源**：cs.CL（arXiv）
**链接**：https://arxiv.org/abs/2609.00058
**标签**：CUDA内核 · Text2CUDA · LLM代码生成 · 算子优化 · Agent

高性能 CUDA 内核开发需要算法实现、正确性验证与硬件感知并行的专业知识，门槛高。Text2CUDA 希望直接从自然语言生成内核。CUDA-Harness 构建智能体化流程，自动完成 CUDA 内核的生成、正确性校验与硬件感知优化，降低专家壁垒并提升生成内核的实际性能。

**核心要点**：
- 将 CUDA 内核开发拆解为生成、验证、硬件优化闭环
- 以智能体方式自动化 Text2CUDA 全流程
- 面向实际硬件性能而非仅语法正确，降低开发门槛

## 6. RW-LoRA：基于随机游走的高效通信去中心化 LoRA 微调

**来源**：cs.LG（arXiv）
**链接**：https://arxiv.org/abs/2609.00078
**标签**：分布式微调 · LoRA · 去中心化 · 通信压缩 · 随机游走

LoRA 已成基础模型适配标准，但分布式微调面临挑战：集中式聚合与基于 gossip 的去中心化 LoRA 都需要大量同步，通信开销大且引入同步错误。RW-LoRA 提出基于随机游走的去中心化 LoRA 微调，减少模型副本间重复同步，降低通信开销与同步误差，更适合大规模分布式场景。

**核心要点**：
- 指出现有分布式 LoRA 的集中聚合与 gossip 同步开销痛点
- 用随机游走策略减少副本间重复同步
- 在降低通信成本的同时抑制同步引入的误差

## 7. Faster Than Flash：利用注意力稀疏性的高效长上下文解码

长上下文 LLM 受解码阶段注意力机制的内存带宽瓶颈与二次复杂度制约。现有方法在元数据指标的内存开销与自适应选择的低效间难以兼顾。Faster Flash Decoding（FFD）提出软硬件协同设计框架，利用注意力稀疏性打破内存-计算权衡，在长上下文解码中实现更低开销与更高效率。

**核心要点**：
- 指出长上下文解码受注意力内存带宽与二次复杂度限制
- 利用注意力稀疏性进行软硬件协同（co-design）
- 在元数据开销与计算效率之间取得更优平衡
