## 【代数】递归数列求第 2019 项

**难度：** ⭐⭐⭐（高中竞赛难度 · 递推关系与代数变形）

**题目来源：** [2019 AMC 10A Problem 15](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_15)

**知识点：** 递推数列 · 取倒数构造等差数列 · 分式代数化简

**题目：**

数列按如下方式递归定义：$a_1 = 1$，$a_2 = \dfrac{3}{7}$，且对一切 $n \ge 3$，

$$a_n=\frac{a_{n-2} \cdot a_{n-1}}{2a_{n-2} - a_{n-1}}$$

则 $a_{2019}$ 可以写成 $\dfrac{p}{q}$ 的形式，其中 $p$、$q$ 为互素的正整数。求 $p+q$ 的值。

$\textbf{(A) } 2020 \qquad\textbf{(B) } 4039 \qquad\textbf{(C) } 6057 \qquad\textbf{(D) } 6061 \qquad\textbf{(E) } 8078$

---

### 解题过程

**思路：对递推式取倒数，转化为线性关系。**

原式：
$$a_n=\frac{a_{n-2}\, a_{n-1}}{2a_{n-2} - a_{n-1}}$$

两边取倒数（各项均非零，显然成立）：
$$\frac{1}{a_n}=\frac{2a_{n-2} - a_{n-1}}{a_{n-2}\, a_{n-1}} = \frac{2}{a_{n-1}} - \frac{1}{a_{n-2}}$$

令 $b_n = \dfrac{1}{a_n}$，则递推式变为：
$$b_n = 2b_{n-1} - b_{n-2}$$

即 $b_n - b_{n-1} = b_{n-1} - b_{n-2}$，说明数列 $\{b_n\}$ 是**等差数列**。

已知：
$$b_1 = \frac{1}{a_1} = 1, \qquad b_2 = \frac{1}{a_2} = \frac{7}{3}$$

公差：
$$d = b_2 - b_1 = \frac{7}{3} - 1 = \frac{4}{3}$$

通项：
$$b_n = b_1 + (n-1)d = 1 + (n-1)\cdot\frac{4}{3} = \frac{4n - 1}{3}$$

于是：
$$a_n = \frac{1}{b_n} = \frac{3}{4n - 1}$$

代入 $n = 2019$：
$$a_{2019} = \frac{3}{4\cdot 2019 - 1} = \frac{3}{8076 - 1} = \frac{3}{8075}$$

检查互素：$\gcd(3, 8075) = \gcd(3, 8075\bmod 3)$。因 $8075 = 3\times 2691 + 2$，故 $\gcd = 1$，已互素。

所以 $p = 3$，$q = 8075$，
$$p + q = 3 + 8075 = 8078$$

**答案：$\textbf{(E) } 8078$**

---

### 常见错误

- 直接逐项计算试图找 $a_{2019}$，量太大且易错；必须先做代数变形。
- 取倒数后写成 $b_n = 2b_{n-1} + b_{n-2}$（符号弄反），导致不是等差而是其他递推。
- 忘记验算 $p, q$ 互素，或把分母算成 $4\times 2019 = 8076$ 而漏减 1。

---

### 知识背景

递推数列是高中竞赛代数板块的核心内容之一。当递推式呈分式且分子为相邻两项乘积时，"取倒数"往往能把非线性递推线性化。本题进阶技巧是识别 $b_n - b_{n-1}$ 为常数，从而判定等差数列——这类"差分恒定即等差"的观察在 AMC 12 与 AIME 中频繁出现。掌握倒数代换、待定系数与差分法，能快速破解大量分式递推题。

## 【组合】异色立方体搭塔计数

**难度：** ⭐⭐⭐（高中竞赛难度 · 多重集排列与容斥）

**题目来源：** [2019 AMC 10A Problem 17](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_17)

**知识点：** 多重集排列 · 组合计数 · 乘法原理

**题目：**

一个孩子用形状相同但颜色不同的立方体搭塔。他手上有 $2$ 个红色立方体、$3$ 个蓝色立方体、$4$ 个绿色立方体。要搭一座高为 $8$ 个立方体的塔（即会有 $1$ 个立方体剩下不用），可以搭出多少种不同的塔？

$\textbf{(A) } 24 \qquad\textbf{(B) } 288 \qquad\textbf{(C) } 312 \qquad\textbf{(D) } 1{,}260 \qquad\textbf{(E) } 40{,}320$

---

### 解题过程

**思路：分两步——先决定剩下哪种颜色，再对选出的 8 个立方体做多重集排列。**

共有 $2 + 3 + 4 = 9$ 个立方体，要选 $8$ 个排成一列（塔有顺序，从上到下不同即不同塔）。

**情形一：剩下 1 个红色立方体。**
则使用的颜色数量为：红 $1$、蓝 $3$、绿 $4$（共 $8$ 个）。
排列数为多重集排列：
$$\frac{8!}{1!\,3!\,4!} = \frac{40320}{1 \times 6 \times 24} = \frac{40320}{144} = 280$$

**情形二：剩下 1 个蓝色立方体。**
使用的数量：红 $2$、蓝 $2$、绿 $4$。
$$\frac{8!}{2!\,2!\,4!} = \frac{40320}{2 \times 2 \times 24} = \frac{40320}{96} = 420$$

**情形三：剩下 1 个绿色立方体。**
使用的数量：红 $2$、蓝 $3$、绿 $3$。
$$\frac{8!}{2!\,3!\,3!} = \frac{40320}{2 \times 6 \times 6} = \frac{40320}{72} = 560$$

三种情形互斥，总数相加：
$$280 + 420 + 560 = 1260$$

**答案：$\textbf{(D) } 1{,}260$**

---

### 常见错误

- 直接用 $9!$ 或 $8!$ 当全排列，忽略同色立方体不可区分（会算出 $40320$，正好对应选项 E 的陷阱）。
- 漏掉"剩下哪种颜色"的分类讨论，只算其中一种情形。
- 把"塔"当成无顺序的集合，忘记排列（除以重复阶乘）这一步。

---

### 知识背景

多重集排列（multiset permutation）是组合计数的基本功：若共有 $n$ 个物品，分为若干类，各类分别有 $n_1, n_2, \dots$ 个相同物品，则不同排列数为 $\dfrac{n!}{n_1!\,n_2!\cdots}$。本题结合了"先选后排"的两步计数（乘法原理与分类加法原理），是 AMC 10/12 组合题的典型套路。熟练运用阶乘约分可大幅提速，避免逐项相乘。
