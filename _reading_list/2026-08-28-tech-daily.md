## 1. ExFold：面向 MoE 训练无关推理的预填充-解码统一专家折叠加速

**来源**：arXiv cs.LG
**链接**：https://arxiv.org/abs/2608.24938
**标签**：MoE · 推理加速 · 预填充-解码 · 训练无关 · 专家折叠

MoE 模型通过稀疏专家激活在保持每 token 算力受限的同时扩展容量，但低延迟 MoE 服务面临预填充与解码两个阶段截然不同的瓶颈：预填充受限于 token 级专家计算，解码受限于批量激活专家集合的内存流量。现有无训练加速方法只优化单一资源代理，无法同时满足两阶段需求。ExFold 提出统一的“专家折叠”方法，从单一视角联合优化预填充与解码，实现无需重训练的 MoE 推理加速。

**核心要点**：
- MoE 推理的预填充与解码存在本质不同的瓶颈（计算密集 vs 内存带宽密集）
- 现有无训练加速方案只优化单一资源代理，顾此失彼
- ExFold 以统一专家折叠联合优化两阶段，免重训练即可加速

## 2. FLINT：利用高带宽闪存实现容量可扩展的 LLM 推理加速

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2608.25062
**标签**：高带宽闪存 · LLM 推理 · 容量扩展 · 权重卸载 · 近加速器存储

LLM 推理正日益受限于加速器内存容量而非算力吞吐，尤其在单卡与小规模节点上，有限的封装内存容量限制了可部署模型规模。高带宽闪存（HBF）是一种新兴 3D 堆叠 NAND 技术，可提供多 TB 近加速器容量，是存放 LLM 权重的理想容量层。FLINT 针对现有 HBF 方案依赖粗粒度调度、带宽利用不足等落地难题，提出精细化的权重放置与加载策略，实现容量可扩展的推理加速。

**核心要点**：
- LLM 推理瓶颈从算力转向加速器内存容量，单卡场景尤甚
- HBF 高带宽闪存可提供多 TB 近加速器权重存储层
- FLINT 解决粗粒度调度与带宽利用问题，实现容量可扩展推理

## 3. APT：基于注意力概率引导剪枝与量化的扩散 Transformer 加速

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2608.25380
**标签**：Diffusion Transformer · 注意力剪枝 · 量化 · 生成加速 · 高分辨率

高分辨率图像与视频生成需求激增，使扩散模型成为核心技术，其中 Diffusion Transformers（DiTs）因可扩展性与质量成为 SOTA，但自注意力计算开销随分辨率四次方增长导致延迟过高。APT 提出注意力概率引导的剪枝与量化方法，依据注意力概率识别冗余的注意力头与通道，在保持生成质量的同时显著降低计算量。

**核心要点**：
- DiT 自注意力开销随分辨率四次方增长，高分辨率下延迟过长
- 注意力概率可指示冗余的注意力头与通道
- APT 结合概率引导剪枝与量化，在保质量下大幅加速

## 4. FAMPWQ：基于 Fisher 信息的自适应混合精度权重量化

**来源**：arXiv cs.LG
**链接**：https://arxiv.org/abs/2608.24945
**标签**：混合精度 · 权重量化 · Fisher 信息 · LLM 压缩 · 敏感度评估

LLM 资源消耗过高阻碍其在受限设备部署，量化是有效手段，但传统方法因统一位宽或简单启发式敏感度评估带来严重精度损失。FAMPWQ 提出基于 Fisher 信息的自适应混合精度权重量化，用 Fisher 信息度量各层敏感度，对敏感层分配高位宽、非敏感层低位宽，在整体低位宽预算下最小化精度退化。

**核心要点**：
- 传统量化统一位宽或简单启发式，导致明显精度退化
- Fisher 信息可量化各层/权重对损失的敏感度
- 自适应混合精度按敏感度分配位宽，低位宽预算下保精度

- 传统 MRR 链路热光调谐易受工作负载热波动干扰
- 横跨层分析热开销并提出铁电缓解方案
