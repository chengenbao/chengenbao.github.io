**核心要点**：

- 设计了配套的硬件加速路径，确保商用 GPU 上的实际推理吞吐提升

**核心要点**：
- 首次系统梳理 GPU 集群 SDC 错误的分布规律与触发场景
- 揭示 SDC 在 LLM 训练中的传播路径及对精度的潜在影响
- 提供高层 SDC 建模框架，帮助系统设计者量化可靠性风险
- 为检测策略与容错设计提供实测数据支撑

## 6. RetentiveKV：基于状态空间记忆的多模态 KV Cache 不确定性感知淘汰

**来源**：arXiv · cs.LG  
**链接**：https://arxiv.org/abs/2605.04075  
**标签**：KV Cache · 多模态LLM · 状态空间模型 · 内存压缩 · 推理效率

多模态大语言模型在处理长视觉上下文时，视觉 KV Cache 急剧膨胀导致内存瓶颈与推理效率下降。RetentiveKV 引入状态空间记忆机制，结合不确定性感知策略，动态决策哪些 KV Cache 条目应被保留或淘汰，在大幅压缩 KV Cache 占用的同时，保持多模态推理质量。

**核心要点**：
- 状态空间模型替代传统注意力记分方案，降低 KV Cache 淘汰决策开销
- 不确定性感知机制优先保留信息熵高的视觉 token，减少关键信息丢失
- 支持百万 token 长上下文场景，内存压缩率高且推理质量下降可控
- 在多模态 LLM 基准上相比 StreamingLLM 等方案表现更优
