## 1. NVIDIA B200 与 B300 功耗级基准评测：为不同负载匹配 Blackwell GPU

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2610.41919
**标签**：GPU基准 · Blackwell · B200 · B300 · HPC

作者在两套独立八卡集群上对 NVIDIA B200 与 B300（Blackwell Ultra）进行了细粒度功耗拆解基准测试，覆盖计算机视觉推理/训练、基于 Llama-3 8B/70B 的 LLM 推理以及六款生产级 HPC 代码。结果显示 B300 并非 B200 的均匀升级：在卷积推理上落后至多 5.6×、在部分科学计算上落后 8×，而在大模型训练与高带宽显存敏感型负载上才体现优势，揭示了选型时按负载画像匹配芯片的重要性。

**核心要点**：
- 首次对 B200/B300 做功耗分解级（power-resolved）横向基准，而非只看吞吐
- B300 在卷积推理、部分 HPC 代码上反而显著慢于 B200（最高 8×）
- 为 Blackwell 机型的采购与负载调度提供实测依据

## 2. AMMA：面向百万级上下文低延迟注意力服务的多芯粒存算一体架构

**来源**：arXiv cs.AR
**链接**：https://arxiv.org/abs/2604.26103
**标签**：注意力服务 · 存算一体 · Chiplet · KV-Cache · 低延迟

现有 LLM 服务系统（包括 NVIDIA Rubin 的 GPU-LPU 异构方案）均以 GPU 为中心，但其计算密集架构与注意力所需的内存带宽/容量并不匹配。AMMA 提出以内存为中心、多芯粒（multi-chiplet）互联的注意力专用架构，将 KV-Cache 与注意力计算下沉到近内存单元，目标是在 1M 上下文下提供低延迟注意力服务，缓解 GPU 中心范式的内存墙瓶颈。

**核心要点**：
- 指出 GPU 中心架构与注意力内存密集型特征的结构性错配
- 多芯粒近内存设计把注意力计算从 GPU 卸载到存储侧
- 面向 1M 长上下文推理的低延迟服务，降低显存与互联压力

## 3. 投机草稿模型与连续扩散语言模型的生成鸿沟

**核心要点**：
- 统一对比 CDLM 与投机草稿两类加速生成范式
- 揭示'无校验'设定下二者的质量与效率差异（生成鸿沟）
- 为混合/统一加速生成方案提供评测框架

## 4. TraceSpec：面向 LLM Agent 的投机解码理解与改进框架

**来源**：arXiv cs.CL
**链接**：https://arxiv.org/abs/2610.41177
**标签**：投机解码 · LLM Agent · 轨迹评估 · 自适应草稿

LLM Agent 通过推理、动作与工具反馈的多轮模型调用完成任务，而现有的聚合式投机解码指标把这些异质决策混为一谈，无法定位草稿监督该加强何处。TraceSpec 把轨迹级（trajectory）评估与自适应草稿训练打通，沿 Agent 执行轨迹定位高价值草稿监督点，从而针对性提升 Agent 场景下的投机解码接受率与加速比。

**核心要点**：
- 指出聚合指标掩盖了 Agent 多轮决策对草稿的不同需求
- 轨迹级评估定位需要加强草稿监督的具体环节
- 自适应草稿训练提升 Agent 推理的投机解码收益

**核心要点**：
- 用核插值法重新定义注意力上下文/KV-Cache 压缩问题
- 将压缩建模为函数空间插值逼近，提供理论准则
- 在长上下文下降低显存与计算开销同时保持注意力保真
