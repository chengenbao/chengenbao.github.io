## 【四年级】数轴上的三个等距整数

**难度：** ⭐⭐（AMC 8 前段 · 算术数列）

**题目来源：** [2026 AMC 8 Problem 14](https://wiki.randommath.com/amc8/2026/problem-14)（官方答案：**B**）

**题目：** Jami 在数轴上取了三个等距排列的整数。第一个数与第二个数之和为 $40$，第二个数与第三个数之和为 $60$。求这三个数的总和。

（A）70　（B）75　（C）80　（D）85　（E）90

### 解题过程

**方法一：设中间数。**

三数等距，设为 $n-d,\ n,\ n+d$。条件翻译为：

$$2n - d = 40, \qquad 2n + d = 60$$

两式相加得 $4n = 100$，故 $n = 25$，$d = 10$。三数为 $15, 25, 35$，总和 $= 3 \times 25 = 75$。

**方法二：整体法（更快）。**

两条件相加：$(a_1 + a_2) + (a_2 + a_3) = (a_1+a_2+a_3) + a_2 = 100$。

条件相减：$(a_2+a_3) - (a_1+a_2) = a_3 - a_1 = 2d = 20 \Rightarrow d = 10$。

中间数 $a_2 = a_1 + d = 40 - a_2 + 10 \Rightarrow a_2 = 25$。故总和 $= 100 - 25 = 75$。

**答案：** $\boxed{75}$，选 **（B）**。注意 $15+25+35=75$ 满足"三个等距整数"且 $15+25=40$、$25+35=60$，回代验证通过。

### 知识背景

等差数列的对称性质 $a_{k-1} + a_{k+1} = 2a_k$ 让"中间项"成为天然的计算枢纽。AMC 8 前段题的标准提速套路：优先设中间项、优先做"条件相加/相减"的整体操作，避免逐个解方程。

## 【初三】蜘蛛网随机游走：从 3 步到一般步数

**难度：** ⭐⭐⭐⭐（AMC 8 后段 · 马尔可夫链进阶）

**题目来源：** [2026 AMC 8 Problem 21](https://wiki.randommath.com/amc8/2026/problem-21)（官方答案：**B**）及其变式

**题目（原题）：** 蜘蛛 Charlotte 在五角星网（$5$ 个外点 + $5$ 个内点）上随机行走，每次随机走向一个相邻顶点。从外点出发走 $3$ 步，求终点为外点的概率。

（A）$\dfrac15$　（B）$\dfrac14$　（C）$\dfrac25$　（D）$\dfrac12$　（E）$\dfrac35$

**进阶变式（今日加练）：** 从外点出发走 $k$ 步后位于外点的概率 $E_k$ 是多少？当 $k \to \infty$ 时 $E_k$ 趋于多少？

### 解题过程

**图结构（同 04-12 精讲）：** 五角星线图中，外点度数为 $2$（两个邻居均为内点），内点度数为 $4$（两个外点邻居 + 两个内点邻居）。

**基础解（原题）：** 递推 $E_{k+1} = \frac12 I_k = \frac12(1 - E_k)$：

$$E_0 = 1,\quad E_1 = 0,\quad E_2 = \frac12,\quad E_3 = \frac14$$

故原题答案为 $\boxed{\dfrac14}$，选 **（B）**。

**进阶解：求通项。**

递推 $E_{k+1} = \frac12 - \frac12 E_k$ 是一阶线性递推，设不动点 $E^*$：

$$E^* = \frac12 - \frac12 E^* \implies E^* = \frac13$$

令 $F_k = E_k - \frac13$，则：

$$F_{k+1} = E_{k+1} - \frac13 = \frac12 - \frac12 E_k - \frac13 = \frac16 - \frac12 E_k = -\frac12\left(E_k - \frac13\right) = -\frac12 F_k$$

所以 $F_k = F_0 \left(-\frac12\right)^k$，而 $F_0 = 1 - \frac13 = \frac23$。通项：

$$E_k = \frac13 + \frac23 \left(-\frac12\right)^k$$

**验证：** $E_0 = \frac13 + \frac23 = 1$ ✓，$E_1 = \frac13 - \frac13 = 0$ ✓，$E_2 = \frac13 + \frac23 \cdot \frac14 = \frac13 + \frac16 = \frac12$ ✓，$E_3 = \frac13 - \frac23 \cdot \frac18 = \frac{8-2}{24} = \frac14$ ✓。

**极限：** 当 $k \to \infty$，$E_k \to \dfrac13$。即蜘蛛最终有 $\frac13$ 的时间在外点——这恰好等于 $\dfrac{\sum \text{外点度数}}{\sum \text{全部点度数}} = \dfrac{5 \times 2}{5 \times 2 + 5 \times 4} = \dfrac{10}{30} = \dfrac13$，与**平稳分布正比于度数**的理论完全吻合（随机游走在无向图上的平稳分布 $\pi_v \propto \deg(v)$）。

### 知识背景

这道题串起了马尔可夫链的三个层次：① 有限步递推（原题）；② 一阶线性递推求通项（不动点法）；③ 平稳分布（极限行为）。第三层的结论——**无向图随机游走的平稳分布正比于度数**——是 PageRank 算法的原始思想之一，也是竞赛与 CS 课程的经典交汇点。
