## 【几何】同心圆弧中的半径求解

**难度：** ⭐⭐⭐（高中竞赛 · AMC 12 中档几何）

**题目来源：** [2025 AMC 12A Problem 10](https://artofproblemsolving.com/wiki/index.php/2025_AMC_12A_Problems/Problem_10)

**知识点：** 弧长公式 · 圆与同心圆 · 一元二次方程

**题目：**

如下图所示，优弧 $\widehat{AD}$ 与劣弧 $\widehat{BC}$ 具有相同的圆心 $O$。且 $A$ 位于 $O$ 与 $B$ 之间，$D$ 位于 $O$ 与 $C$ 之间。优弧 $\widehat{AD}$、劣弧 $\widehat{BC}$，以及两条线段 $\overline{AB}$ 和 $\overline{CD}$ 的长度都等于 $2\pi$。求点 $O$ 到点 $A$ 的距离。

![几何示意图](/reading-list/2026-11-09-math-fig-p10.svg)

选项：
- $\textbf{(A)}~1$
- $\textbf{(B)}~1 - \pi + \sqrt{\pi^{2} + 1}$
- $\textbf{(C)}~\dfrac{\pi}{2}$
- $\textbf{(D)}~\dfrac{\sqrt{\pi^{2} + 1}}{2}$
- $\textbf{(E)}~2$

---

### 解题过程

设小圆（内圆）半径为 $r$，即 $OA = r$。由于线段 $AB = 2\pi$ 且沿同一射线方向，$OB = r + 2\pi$，即大圆（外圆）的半径为 $r + 2\pi$。

设圆心角 $\angle COB = \theta$（弧度制）。根据弧长公式 $l = \text{半径} \times \text{圆心角}$：

- 优弧 $\widehat{AD}$ 对应小圆上"未被小弧覆盖"的部分，其圆心角为 $2\pi - \theta$，故
  $$2\pi = (2\pi - \theta) \cdot r$$
- 劣弧 $\widehat{BC}$ 对应大圆上的弧，圆心角为 $\theta$，故
  $$2\pi = \theta \cdot (r + 2\pi)$$

将第二式展开：$\theta r + 2\pi\theta = 2\pi$；第一式展开：$2\pi r - \theta r = 2\pi$。两式相加得：

$$2\pi\theta + 2\pi r = 4\pi \quad\Rightarrow\quad \theta + r = 2 \quad\Rightarrow\quad \theta = 2 - r$$

代回第一式：

$$(2\pi - (2 - r)) \cdot r = 2\pi \quad\Rightarrow\quad (2\pi - 2 + r)r = 2\pi$$

$$r^2 + (2\pi - 2)r - 2\pi = 0$$

对 $r$ 使用求根公式：

$$r = \frac{-(2\pi - 2) \pm \sqrt{(2\pi - 2)^2 + 8\pi}}{2}
= \frac{2 - 2\pi \pm \sqrt{4\pi^2 - 8\pi + 4 + 8\pi}}{2}
= \frac{2 - 2\pi \pm 2\sqrt{1 + \pi^2}}{2}$$

$$r = 1 - \pi \pm \sqrt{1 + \pi^2}$$

取正值（半径必须为正）：因为 $1 - \pi + \sqrt{1+\pi^2} > 0$，而 $1 - \pi - \sqrt{1+\pi^2} < 0$，所以

$$r = 1 - \pi + \sqrt{\pi^2 + 1}$$

对应选项 $\textbf{(B)}$。

---

### 常见错误

- 误把优弧当成整圆周长，得到 $2\pi = 2\pi r$，从而得出 $r = 1$（错选 A）。注意 $\widehat{AD}$ 是"优弧"而非整圆。
- 混淆内外圆半径：容易把 $AB$ 当成半径差之外的独立量，忘记 $OB = OA + AB = r + 2\pi$。
- 求根时未舍去负根，得到错误表达式。

---

### 知识背景

弧长公式 $l = r\theta$（$\theta$ 用弧度）是圆相关问题的核心。优弧（major arc）指大于半圆的弧，劣弧（minor arc）指小于半圆的弧，二者圆心角为互补关系（和为 $2\pi$）。本题通过"半径—弧长比例恒定"或"设圆心角联立方程"两种思路都能求解，是 AMC 12 中典型的代数与几何结合题。

## 【代数】直线平分梯形区域求参数

**难度：** ⭐⭐⭐（高中竞赛 · AMC 10 中档代数）

**题目来源：** [2025 AMC 10B Problem 6](https://artofproblemsolving.com/wiki/index.php/2025_AMC_10B_Problems/Problem_6)

**知识点：** 梯形面积 · 一元二次方程 · 区域面积平分

**题目：**

直线 $y = \dfrac{1}{3}x + 1$ 将正方形区域 $0 \le x \le 2,\; 0 \le y \le 2$ 分成上方区域与下方区域。直线 $x = a$ 将"下方区域"分成两个面积相等的部分。已知 $a$ 可以写成 $\sqrt{s} - t$ 的形式，其中 $s$ 与 $t$ 为正整数。求 $s + t$ 的值。

选项：
- $\textbf{(A)}~18$
- $\textbf{(B)}~19$
- $\textbf{(C)}~20$
- $\textbf{(D)}~21$
- $\textbf{(E)}~22$

---

### 解题过程

"下方区域"是指正方形中位于直线 $y = \dfrac{1}{3}x + 1$ 以下的区域，从 $x = 0$ 到 $x = 2$ 构成一个梯形。

该直线在两端的高度：
- $x = 0$ 时，$y = 1$
- $x = 2$ 时，$y = \dfrac{1}{3}\cdot 2 + 1 = \dfrac{5}{3}$

**总下方区域面积（梯形）：**

$$A_{\text{total}} = \frac{1}{2}\big(y(0) + y(2)\big)\cdot (2 - 0)
= \frac{1}{2}\left(1 + \frac{5}{3}\right)\cdot 2 = \frac{8}{3}$$

**一半面积：**

$$A_{\text{half}} = \frac{1}{2} \cdot \frac{8}{3} = \frac{4}{3}$$

直线 $x = a$ 把下方区域从 $x = 0$ 到 $x = a$ 的部分再切成梯形，其面积应等于 $\dfrac{4}{3}$：

$$A_{\text{half}} = \frac{1}{2}\big(y(0) + y(a)\big)\cdot a = \frac{4}{3}$$

代入 $y(0) = 1,\; y(a) = \dfrac{1}{3}a + 1$：

$$\frac{1}{2}\left(1 + \frac{1}{3}a + 1\right)a = \frac{4}{3}$$

$$\frac{1}{2}\left(2 + \frac{a}{3}\right)a = \frac{4}{3}$$

$$a + \frac{a^2}{6} = \frac{4}{3}$$

两边乘 $6$：

$$a^2 + 6a - 8 = 0$$

解一元二次方程：

$$a = \frac{-6 \pm \sqrt{36 + 32}}{2} = \frac{-6 \pm \sqrt{68}}{2}
= \frac{-6 \pm 2\sqrt{17}}{2} = -3 \pm \sqrt{17}$$

因为 $a > 0$，取

$$a = \sqrt{17} - 3$$

于是 $s = 17,\; t = 3$，所以

$$s + t = 17 + 3 = 20$$

对应选项 $\textbf{(C)}$。

---

### 常见错误

- 误把整正方形面积 $4$ 当作下方区域面积，得到错误的一半面积。
- 忘记 $a$ 必须为正，错误地保留负根 $-3 - \sqrt{17}$。
- 把梯形面积公式记错（应是两个平行边平均值乘高，而非底乘高）。

---

### 知识背景

本题将"面积平分"转化为代数方程，是 AMC 10 中经典的代数—几何综合题。核心技巧：用梯形面积公式（或不定积分）表示曲线下面积，再令其等于总面积的一半，转化为一元二次方程求解。注意到 $a = \sqrt{s} - t$ 的形式提示答案需通过求根公式得到含根号的表达式，是竞赛题中常见的"伪装"手法。
