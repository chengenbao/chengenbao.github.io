## 【代数】立方差连加求和

**难度：** ⭐⭐⭐（高中竞赛难度 · 代数式变形与求和公式）

**题目来源：** [2023 AMC 12A Problem 12](https://artofproblemsolving.com/wiki/index.php/2023_AMC_12A_Problems/Problem_12)

**知识点：** 立方和/差公式 · 平方和公式 · 代数换元与数列求和

**题目：**

求下式的值：

$$2^3 - 1^3 + 4^3 - 3^3 + 6^3 - 5^3 + \dots + 18^3 - 17^3$$

$\textbf{(A) } 2023 \qquad\textbf{(B) } 2679 \qquad\textbf{(C) } 2941 \qquad\textbf{(D) } 3159 \qquad\textbf{(E) } 3235$

---

### 解题过程

观察到共有 $9$ 组相邻奇偶立方之差，设第 $k$ 组为 $(2k)^3-(2k-1)^3$。先用立方差公式展开：

$$(2k)^3-(2k-1)^3 = [8k^3] - [8k^3 - 12k^2 + 6k - 1] = 12k^2 - 6k + 1$$

于是原式化为：

$$\sum_{k=1}^{9}\big[(2k)^3-(2k-1)^3\big]
= \sum_{k=1}^{9}(12k^2 - 6k + 1)
= 12\sum_{k=1}^{9}k^2 - 6\sum_{k=1}^{9}k + \sum_{k=1}^{9}1$$

代入求和公式 $\sum_{k=1}^{n}k^2=\frac{n(n+1)(2n+1)}{6}$ 与 $\sum_{k=1}^{n}k=\frac{n(n+1)}{2}$：

$$12\cdot\frac{9\cdot10\cdot19}{6} - 6\cdot\frac{9\cdot10}{2} + 9
= 12\cdot 285 - 6\cdot 45 + 9
= 3420 - 270 + 9 = 3159$$

故答案是 $\boxed{\textbf{(D) } 3159}$。

---

### 常见错误

- 误以为 $2^3-1^3+4^3-3^3+\dots$ 可以随意重组为 $(2^3+4^3+\dots)-(1^3+3^3+\dots)$ —— 这其实可行（首尾配对），但容易在「奇数方和 = 总方和 − 偶数方和」时漏掉项数，建议用本题的逐项展开法更稳妥。
- 代入求和公式时把 $2n+1$ 记错成 $n+1$，导致平方和计算偏差。

---

### 知识背景

本题核心是**数列求和与代数恒等式变形**。立方和公式 $\left(\frac{n(n+1)}{2}\right)^2$ 与平方和公式 $\frac{n(n+1)(2n+1)}{6}$ 是 AMC 高频工具。把「相邻奇偶立方差」视作一个通项 $12k^2-6k+1$，即可将看似复杂的连加拆成三个标准求和，是处理「规律型多项式求和」的通法。

## 【组合】有序三元组计数

**难度：** ⭐⭐⭐⭐（高中竞赛难度 · 分类讨论与计数）

**题目来源：** [2024 AMC 12B Problem 10](https://artofproblemsolving.com/wiki/index.php/2024_AMC_12B_Problems/Problem_10)（等价于 2024 AMC 10B #15）

**知识点：** 中位数 · 极差 · 均值约束 · 分类讨论计数

**题目：**

一个由 $9$ 个实数组成的列表包含 $1,\ 2.2,\ 3.2,\ 5.2,\ 6.2,\ 7$，以及 $x,\ y,\ z$（其中 $x\le y\le z$）。该列表的**极差**为 $7$，且**均值**与**中位数**都是正整数。问有多少组有序三元组 $(x,y,z)$ 可能？

$\textbf{(A) } 1 \qquad \textbf{(B) } 2 \qquad \textbf{(C) } 3 \qquad \textbf{(D) } 4 \qquad \textbf{(E) } \text{infinitely many}$

---

### 解题过程

已知六个固定数之和为 $1+2.2+3.2+5.2+6.2+7 = 24.8$。

设加入 $x,y,z$ 后总和为 $S=24.8+x+y+z$，要求均值 $S/9$ 为整数，即 $S$ 是 $9$ 的倍数。又因中位数（第 $5$ 小的数）必须是整数，而原列表中 $3.2,5.2,6.2$ 均非整数，所以中位数必落在 $x,y,z$ 之中。

对「最小值 $x$ 与最大值 $z$ 相对已知数的位置」做分类讨论（覆盖所有情形）：

**Case 1：$x<1,\ z<7$**
此时最小值为 $x$，最大值为 $7$，极差 $=7-x=7 \Rightarrow x=0$。要让中位数为整数，需把 $y$ 或 $z$ 插到 $3.2$ 与 $5.2$ 之间。取 $y=5$，则当前和为 $24.8+0+5=29.8$，要凑到 $36$（下一个 $9$ 的倍数）得 $z=6.2$，满足 $z<7$ 与各序关系。得一组：$(0,5,6.2)$。

**Case 2：$x>1,\ z<7$**
最小值=$1$，最大值=$7$，极差恒为 $6\neq7$，无解。

**Case 3：$x<1,\ z>7$**
最小值=$x$，最大值=$z$，极差 $z-x=7$。中位数仍需落在 $5.2$ 处，故 $y$ 取 $4$ 或 $5$。
- $y=4$：和为 $28.8+x+z$，取 $36 \Rightarrow x+z=7.2$，联立 $z-x=7$ 得 $z=7.1,\ x=0.1$，满足。
- $y=5$：和为 $29.8+x+z$，取 $36 \Rightarrow x+z=6.2$，联立得 $z=6.6<7$，与 $z>7$ 矛盾。
得一组：$(0.1,4,7.1)$。

**Case 4：$x>1,\ z>7$**
最小值=$1$，最大值=$z$，极差 $z-1=7 \Rightarrow z=8$。中位数落在 $5.2$ 与 $6.2$ 之间，需 $x$ 或 $y$ 取 $6$。取 $x=6$，和为 $24.8+6+8=38.8$，凑到 $45$ 得最后一个数 $y=6.2$。得一组：$(6,6.2,8)$。

综上共 $3$ 组有序三元组，答案是 $\boxed{\textbf{(C) } 3}$。

---

### 常见错误

- 忽略「中位数必须是 $x,y,z$ 之一」，从而漏掉对 $y$ 取值（4、5、6）的约束。
- 只设 $x=0$ 而忘记 $z$ 也可能做最大值（$z=8$）的情况，会少算一组。
- 把「极差为 7」误当成「最大值 − 最小值 = 7 且两端都是已知数」，实际上两端往往由 $x$ 或 $z$ 充当。

---

### 知识背景

这是一道典型的**带约束计数**题：把「统计量条件」（极差、均值、中位数）逐条翻译成代数不等式与整除条件，再用分类讨论穷举所有位置情形。关键技巧是：固定数之和为小数 $24.8$，为让均值整数化，$x+y+z$ 的末位小数必须是 $.2$，这极大缩小了搜索空间。此类「统计量 + 有序变量」是 AMC 10/12 中组合与代数交叉的经典题型。
