## 【数论】$201^9$ 的完全平方数或完全立方数因数计数

**难度：** ⭐⭐⭐（高中竞赛难度 · 整除与因数分解）

**题目来源：** [2019 AMC 10A Problem 11](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_11)

**知识点：** 质因数分解 · 因数个数公式 · 容斥原理

**题目：**

$201^9$ 的正因数中，有多少个是完全平方数或完全立方数（或两者皆是）？

$${\textbf{(A) }32} \qquad {\textbf{(B) }36} \qquad {\textbf{(C) }37} \qquad {\textbf{(D) }39} \qquad {\textbf{(E) }41}$$

---

### 解题过程

1. 先对底数做质因数分解：
   $$201 = 3 \times 67$$
   因此
   $$201^9 = 3^9 \times 67^9$$

2. 一般正因数形如 $3^a \cdot 67^b$，其中 $0 \le a \le 9,\; 0 \le b \le 9$。

3. **完全平方数**：要求指数均为偶数，即 $a,b \in \{0,2,4,6,8\}$，各有 $5$ 个取值，共
   $$5 \times 5 = 25 \text{ 个}$$

4. **完全立方数**：要求指数均为 $3$ 的倍数，即 $a,b \in \{0,3,6,9\}$，各有 $4$ 个取值，共
   $$4 \times 4 = 16 \text{ 个}$$

5. **既是平方又是立方（即六次方数）**：要求指数为 $6$ 的倍数，即 $a,b \in \{0,6\}$，各有 $2$ 个取值，共
   $$2 \times 2 = 4 \text{ 个}$$

6. 由容斥原理：
   $$25 + 16 - 4 = 37$$

**答案：$\textbf{(C) } 37$**

---

### 常见错误

- 忘记减去交集（六次方数）导致 $25+16=41$，误选 (E)。
- 把 $201$ 当质数处理，漏掉 $67$ 这个质因子。
- 指数范围数错：平方数指数可取 $0,2,4,6,8$ 共 $5$ 个而非 $4$ 个。

---

### 知识背景

本题核心是「因数个数公式」与「容斥原理」的结合。若 $n = p_1^{e_1}\cdots p_k^{e_k}$，则其正因数个数为 $\prod (e_i+1)$。判断一个数是否为完全平方数，只需各质因子的指数均为偶数；完全立方数则指数均为 $3$ 的倍数；两者皆是为 $6$ 的倍数（取 LCM）。AMC 中此类「计数 + 数论」是高频题型。

## 【几何】等腰三角与圆内接四边形的对角

**难度：** ⭐⭐⭐（高中竞赛难度 · 圆与三角形角度）

**题目来源：** [2019 AMC 10A Problem 13](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_13)

**知识点：** 圆周角定理 · 直径所对圆周角为直角 · 圆内接四边形对角互补

**题目：**

设 $\triangle ABC$ 为等腰三角形，满足 $BC = AC$，且 $\angle ACB = 40^{\circ}$。作以 $\overline{BC}$ 为直径的圆，设 $D$、$E$ 分别为该圆与边 $\overline{AC}$、$\overline{AB}$ 的另一个交点。令 $F$ 为四边形 $BCDE$ 两条对角线的交点。求 $\angle BFC$ 的度数。

$$\textbf{(A) } 90 \qquad\textbf{(B) } 100 \qquad\textbf{(C) } 105 \qquad\textbf{(D) } 110 \qquad\textbf{(E) } 120$$

---

### 解题过程

1. 由 $BC=AC$ 且 $\angle ACB = 40^\circ$，等腰三角形底角：
   $$\angle A = \angle B = \frac{180^\circ - 40^\circ}{2} = 70^\circ$$

2. $BC$ 为直径，故由「直径所对圆周角为直角」：
   - $D$ 在圆上且 $BC$ 为直径 $\Rightarrow \angle BDC = 90^\circ$
   - $E$ 在圆上且 $BC$ 为直径 $\Rightarrow \angle BEC = 90^\circ$

3. 四边形 $BCDE$ 内接于以 $BC$ 为直径的圆，故为**圆内接四边形**，对角互补：
   $$\angle BFC + \angle BEC = 180^\circ$$
   由于 $\angle BEC = 90^\circ$，得
   $$\angle BFC = 90^\circ$$
   
   > 注：更直接的观察是 $F$ 处两对角线 $BD$ 与 $CE$ 相交，而 $BD \perp AC$、$CE \perp AB$（因 $\angle BDC=\angle BEC=90^\circ$）。在交点 $F$，$\angle BFC$ 与 $\angle DFE$ 对顶，$\angle DFE$ 由两垂线夹角决定。由 $\angle A = 70^\circ$，两垂线夹角等于 $180^\circ - 70^\circ = 110^\circ$？需仔细核对——实际上四边形 $BCDE$ 对角互补给出 $\angle BFC = 180^\circ - \angle BEC = 90^\circ$ 有误，因为 $F$ 不是顶点而是对角线交点。正确做法见下。

4. **正确做法**：在 $\triangle ABC$ 中，$BD \perp AC$（因 $\angle BDC=90^\circ$），所以 $BD$ 是从 $B$ 到 $AC$ 的高；$同理 $CE \perp AB$。$F$ 是两条高 $BD$、$CE$ 的交点，即 $\triangle ABC$ 的**垂心**。
   - 垂心性质：在 $\triangle ABC$ 中，$\angle BFC = 180^\circ - \angle A = 180^\circ - 70^\circ = 110^\circ$。

**答案：$\textbf{(D) } 110$**

---

### 常见错误

- 误用圆内接四边形对角互补直接套 $\angle BFC=90^\circ$，忽略 $F$ 是对角线交点而非顶点。
- 算错底角：$180-40$ 除以 $2$ 应为 $70^\circ$ 而非 $60^\circ$ 或 $80^\circ$。
- 忘记 $F$ 是垂心，从而找不到与 $\angle A$ 的关系。

---

### 知识背景

本题考查圆的两大核心定理：①「直径所对圆周角是直角」；②圆内接四边形的构造。进一步，点 $D$、$E$ 分别使 $BD\perp AC$、$CE\perp AB$，故对角线交点 $F$ 恰为 $\triangle ABC$ 的垂心。垂心的基本角度关系为 $\angle BFC = 180^\circ - \angle A$，是平面几何中常用结论。
