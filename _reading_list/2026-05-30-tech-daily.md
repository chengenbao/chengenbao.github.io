## 1. RTP-LLM：阿里巴巴高性能大语言模型推理引擎

**标签**：LLM推理 · KV Cache · 连续批处理 · CUDA优化 · 推理系统

阿里巴巴提出 RTP-LLM，一个面向生产环境的高性能 LLM 推理引擎。系统通过连续批处理（Continuous Batching）、精细化 KV Cache 管理与 CUDA 核函数优化，实现了推理吞吐与延迟的显著提升。论文详细介绍了推理系统与模型部署的协同设计思路，以及大规模部署下的工程挑战与解决方案。

**核心要点**：

- 创新 KV Cache 调度机制，降低内存碎片
- 针对主流模型结构进行 CUDA 核函数级别优化
- 在 Alibaba 内部多个产品规模验证，吞吐量达 SOTA

## 2. Rotary GPU：受限显存下大规模 MoE 模型的本地执行路径探索

**来源**：cs.AR  
**链接**：https://arxiv.org/abs/2605.29135  
**标签**：MoE模型 · 显存受限 · 专家卸载 · CPU-GPU协同 · 推理优化

在 GPU 显存不足时如何高效运行大规模 MoE（混合专家）模型？本文提出 Rotary GPU 系统，通过将专家权重动态卸载到 CPU 内存，并结合预取策略和调度算法，在有限显存约束下实现高吞吐推理。该工作对部署如 Mixtral、DeepSeek-MoE 等大型 MoE 模型具有重要实践意义。

**核心要点**：
- 提出专家权重的 CPU 卸载与 GPU 执行的协同调度框架
- 通过预取机制隐藏 CPU→GPU 传输延迟
- 在消费级 GPU 上运行超出显存容量的 MoE 模型
- 与 offloading 基线相比吞吐提升显著

为什么强化学习微调（RLHF）比监督微调（SFT）更少出现灾难性遗忘？本文从电路机理分析角度探究这一现象的根本原因，发现 RL 训练目标倾向于保留 transformer 内部的功能电路，而 SFT 更容易破坏原有计算路径。该发现对设计更稳定的大模型微调策略有重要指导意义。

**核心要点**：
- 从 transformer 内部计算电路视角分析两类微调方法
- 发现 RL 目标函数天然具有保留功能电路的归纳偏置
- SFT 对 MLP 权重的直接修改更易破坏已有知识回路
- 为设计低遗忘微调策略提供了机理层面的理论依据
