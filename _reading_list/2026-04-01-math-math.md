## 【代数】直角三角形上的向量求和

**难度：** ⭐⭐⭐（高中竞赛 / AMC 12 第 7 题）

**题目来源：** [2024 AMC 12A Problem 7](https://live.poshenloh.com/past-contests/amc12/2024A/problem/7)

**知识点：** 向量 · 几何中位线（中点）· 对称性

**题目：**

在 \(\triangle ABC\) 中，\(\angle ABC=90^\circ\) 且 \(BA=BC=\sqrt2\)。点 \(P_1,\) \(P_2,\) \(\ldots,\) \(P_{2024}\) 位于斜边 \(AC\) 上，满足
\[AP_1=P_1P_2 =P_2P_3 =\cdots =P_{2023}P_{2024} =P_{2024}C.\]
问向量和
\[\vec{BP_1}+\vec{BP_2}+\vec{BP_3} +\cdots+\vec{BP_{2024}}\]
的长度是多少？

- (A) \(1011\)
- (B) \(1012\)
- (C) \(2023\)
- (D) \(2024\)
- (E) \(2025\)

---

### 解题过程

**第 1 步：利用对称性配对。** \(2025\) 等分点把斜边均分，这些点关于斜边中点 \(M\) 对称：\(P_k\) 与 \(P_{2025-k}\) 到 \(M\) 的距离相等、方向相反。因此
\[\vec{BP_k} + \vec{BP_{2025-k}} = 2\,\vec{BM}.\]
（以 \(B\) 为起点看，两个对称点的位置向量之和等于中点位置向量的两倍。）\(2024\) 个点恰好配成 \(1012\) 对，于是
\[\sum_{k=1}^{2024}\vec{BP_k} = 1012 \cdot 2\,\vec{BM} = 2024\,\vec{BM}.\]

**第 2 步：用"直角三角形斜边中线"求 \(BM\)。** 直角三角形斜边上的中线等于斜边的一半。先算斜边：
\[AC = \sqrt{BA^2 + BC^2} = \sqrt{2+2} = 2,\]
所以
\[BM = \tfrac12\,AC = 1.\]

**第 3 步：求和的长度。**
\[\left|\,2024\,\vec{BM}\,\right| = 2024 \times 1 = 2024.\]

**答案：(D) 2024**

---

### 常见错误

- 被 \(2024\) 个点的具体位置吓住，试图逐个坐标化求和；实际上对称配对一步就把 \(2024\) 个向量压缩成一个。
- 忘记直角三角形"斜边中线 = 斜边一半"这一性质，反而去算 \(M\) 的坐标；或者把 \(BM\) 误算成 \(\sqrt2\)（误用腰长）。

---

### 知识背景

"等距点组关于中点对称"是处理大规模求和的利器：先把和化为对称中心的倍数，再集中算一个量。直角三角形斜边中线等于斜边的一半（外接圆半径即半斜边）则是 AMC 几何最常用的事实之一。本题把向量、对称、圆性质三个工具串在一道看似"超大计算量"的题里，实际手算不超过五行。

## 【几何】双线性方程围出的矩形

**难度：** ⭐⭐⭐⭐（高中竞赛 / AMC 10 第 24 题）

**题目来源：** [2021 AMC 10A Problem 24](https://live.poshenloh.com/past-contests/amc10/2021A/problem/24)

**知识点：** 平行线 · 距离公式 · 矩形

**题目：**

一个四边形的内部由曲线
\[(x+ay)^2=4a^2 \quad\text{和}\quad (ax-y)^2=a^2\]
的图形所围成，其中 \(a\) 是正实数。用 \(a\) 表示，这个区域的面积是多少（对所有 \(a > 0\) 成立）？

- (A) \(\dfrac{8a^2}{(a+1)^2}\)
- (B) \(\dfrac{4a}{a+1}\)
- (C) \(\dfrac{8a}{a+1}\)
- (D) \(\dfrac{8a^2}{a^2+1}\)
- (E) \(\dfrac{8a}{a^2+1}\)

---

### 解题过程

**第 1 步：拆开平方，得到两组平行线。** 形如 \(U^2 = k^2\) 的方程等价于 \(U = k\) 或 \(U = -k\)，各代表一条直线。

第一条：\[(x+ay)^2 = 4a^2 \ \Longrightarrow\ x + ay - 2a = 0 \quad\text{或}\quad x + ay + 2a = 0.\]
这两条直线斜率都是 \(-\dfrac1a\)，互相平行。

第二条：\[(ax-y)^2 = a^2 \ \Longrightarrow\ ax - y - a = 0 \quad\text{或}\quad ax - y + a = 0.\]
这两条直线斜率都是 \(a\)，互相平行。

**第 2 步：确认两组直线互相垂直。** 斜率 \(-\frac1a\) 与 \(a\) 的乘积为 \(-1\)，所以两两垂直。两条平行线段与另两条平行线段相交，围出一个**矩形**。

**第 3 步：用平行线间距离公式求边长。** 两条平行线 \(Ax+By+C_1=0\) 与 \(Ax+By+C_2=0\) 的距离为
\[d = \dfrac{|C_2 - C_1|}{\sqrt{A^2 + B^2}}.\]
- 第一组（\(x+ay\pm 2a=0\)，常数项相差 \(4a\)）：
  \[d_1 = \dfrac{4a}{\sqrt{1+a^2}};\]
- 第二组（\(ax-y\pm a=0\)，常数项相差 \(2a\)）：
  \[d_2 = \dfrac{2a}{\sqrt{a^2+1}}.\]

这两段距离就是矩形的两条邻边长。

**第 4 步：相乘得面积。**
\[\text{面积} = d_1\cdot d_2 = \dfrac{4a}{\sqrt{a^2+1}}\cdot\dfrac{2a}{\sqrt{a^2+1}} = \dfrac{8a^2}{a^2+1}.\]

**答案：(D) \(\dfrac{8a^2}{a^2+1}\)**

---

### 常见错误

- 忘记 \((\cdot)^2 = k^2\) 要拆成**两条**直线（正、负各一条），只取一条就把"四边形"变成了"无界区域"或算错边数。
- 距离公式里常数项之差算错：第一组是 \((2a)-(-2a) = 4a\)，第二组是 \(a-(-a)=2a\)；差一倍就会选到 (A)/(C) 等错误选项。
- 不验证垂直性直接当平行四边形处理；这里恰好垂直，面积才等于两边之积。

---

### 知识背景

形如 \((\ell)^2 = k^2\) 的方程总是"一对平行线 \(\ell = \pm k\)"，这是处理二次曲线退化情形的基本功。本题的两个线性组合 \(x+ay\) 与 \(ax-y\) 还暗藏正交设计：它们的系数向量 \((1,a)\) 与 \((a,-1)\) 点积为 \(0\)，所以两组平行线天然垂直——围出的区域是矩形，面积就是"两条间距的乘积"。识别这种"正交线性型"结构（类似旋转伸缩坐标），能避免大量计算。
