## 【代数】代数式的最值（不等式优化）

**难度：** ⭐⭐⭐（AMC 10 中等题，考查分式变形与区间内最值分析）

**题目来源：** [2004 AMC 10A Problem 15](https://artofproblemsolving.com/wiki/index.php/2004_AMC_10A_Problems/Problem_15)

**知识点：** 分式化简 · 不等式最值 · 区间分析

**题目：**

已知 $-4\leq x\leq -2$ 且 $2\leq y\leq 4$，那么 $\dfrac{x+y}{x}$ 的最大可能值是？

$$\mathrm{(A) \ } -1 \qquad \mathrm{(B) \ } -\frac12 \qquad \mathrm{(C) \ } 0 \qquad \mathrm{(D) \ } \frac12 \qquad \mathrm{(E) \ } 1$$

---

### 解题过程

1. **分式拆分**，把目标式改写成更容易分析的形式：

$$\frac{x+y}{x}=1+\frac{y}{x}$$

因为我们要最大化整个表达式，而 $1$ 是常数，所以只需最大化 $\dfrac{y}{x}$。

2. **分析符号与绝对值**。已知 $x<0$（区间全为负），$y>0$（区间全为正），因此 $\dfrac{y}{x}<0$，它是个负数。要让这个负数“尽可能大”（即最接近 $0$），等价于让它**绝对值最小**：

$$\left|\frac{y}{x}\right|=\frac{y}{|x|}$$

3. **取极值**。要让 $\dfrac{y}{|x|}$ 最小，就取分子尽量小、分母尽量大：

- $y$ 取最小值：$y=2$
- $|x|$ 取最大值：$x=-4$（此时 $|x|=4$）

代入得：

$$\frac{y}{x}=\frac{2}{-4}=-\frac12$$

所以

$$\frac{x+y}{x}=1+\left(-\frac12\right)=\frac12$$

4. **验证可达性**：当 $x=-4,\ y=2$ 时，确实落在两个区间内，且

$$\frac{-4+2}{-4}=\frac{-2}{-4}=\frac12$$

因此最大值 $\dfrac12$ 可以取到。

**答案：$\boxed{\mathrm{(D)}\ \dfrac12}$**

---

### 常见错误

- **误以为要同时取端点极值**：有人直接把四个端点全代入，容易漏掉“异号分式取最小绝对值”的组合，得到 $-1$ 或 $0$ 就草草收场。
- **忽略 $x$ 为负导致的不等号方向**：若把式子写成 $\dfrac{y}{x}$ 后试图“让 $x$ 最大（$-2$）来增大”，会忘记分母为负时绝对值反而变大，结果算成 $0$ 而错选 C。
- **把“最大值”当成绝对值最大**：题目要的是代数式的值最大（最接近正无穷），不是绝对值最大。

---

### 知识背景

这是一类典型的“在给定区间内求分式最值”问题，核心思路是**先分离常数、再分析符号**。当分子分母异号时，目标值落在负半轴，求最大值就是求“最靠近 0 的负数”，即绝对值最小。这类技巧在 AMC 10 的不等式与最值题目中反复出现，熟练后可秒杀类似小题。（约 180 字）

## 【几何】等腰三角形的外接圆面积

**难度：** ⭐⭐⭐（AMC 10 中等题，考查外接圆半径公式与等腰三角形面积）

**题目来源：** [2007 AMC 10B Problem 11](https://artofproblemsolving.com/wiki/index.php/2007_AMC_10B_Problems/Problem_11)

**知识点：** 外接圆半径公式 $R=\dfrac{abc}{4S}$ · 等腰三角形面积 · 勾股定理

**题目：**

一个等腰三角形有两条边长为 $3$、底边长为 $2$，且一个圆经过它的三个顶点。这个圆的面积是？

$$\textbf{(A) } 2\pi \qquad\textbf{(B) } \frac{5}{2}\pi \qquad\textbf{(C) } \frac{81}{32}\pi \qquad\textbf{(D) } 3\pi \qquad\textbf{(E) } \frac{7}{2}\pi$$

### 解题过程

1. **求三角形面积**。等腰三角形底边 $c=2$，两腰 $a=b=3$。从顶点向底边作高，高把底边平分为两段，每段长 $1$。由勾股定理，高

$$h=\sqrt{3^2-1^2}=\sqrt{9-1}=\sqrt{8}=2\sqrt2$$

面积

$$S=\frac12\cdot \text{底}\cdot \text{高}=\frac12\cdot 2\cdot 2\sqrt2=2\sqrt2$$

2. **用外接圆半径公式**。对任意三角形，外接圆半径

$$R=\frac{abc}{4S}$$

代入 $a=3,\ b=3,\ c=2,\ S=2\sqrt2$：

$$R=\frac{3\cdot 3\cdot 2}{4\cdot 2\sqrt2}=\frac{18}{8\sqrt2}=\frac{9}{4\sqrt2}=\frac{9\sqrt2}{8}$$

3. **求圆面积**：

$$R^2=\left(\frac{9\sqrt2}{8}\right)^2=\frac{81\cdot 2}{64}=\frac{162}{64}=\frac{81}{32}$$

$$\text{圆面积}=\pi R^2=\boxed{\frac{81}{32}\pi}$$

**答案：$\boxed{\textbf{(C)}\ \dfrac{81}{32}\pi}$**

---

### 常见错误

- **面积公式用错**：误把高当成 $\sqrt{3^2-2^2}$，忘了高平分的是底边（一半是 $1$，不是 $2$）。
- **外接圆半径公式记混**：与内切圆半径 $r=\dfrac{S}{p}$ 或中线公式混淆；本题必须用 $R=\dfrac{abc}{4S}$。
- **最后漏掉 $\pi$ 或平方算错**：有人算出 $R=\dfrac{9\sqrt2}{8}$ 后直接选带 $\dfrac{9\sqrt2}{8}$ 的，但题目问的是**面积**（$R^2\pi$），需再平方一次。

---

### 知识背景

外接圆半径公式 $R=\dfrac{abc}{4S}$ 是平面几何与三角的桥梁，可由正弦定理 $a=2R\sin A$ 与 $S=\dfrac12bc\sin A$ 联立推出，适用于**所有三角形**。对于等腰三角形，计算通常可先求高得面积，再套公式，比坐标法更快。该公式在 AMC 10/12 的几何题中属于高频工具。（约 170 字）
