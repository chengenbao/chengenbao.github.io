## 1. ADIndex：基于分组蒸馏的层自适应稀疏注意力索引

**来源**：arXiv cs.LG
**链接**：https://arxiv.org/abs/2611.12956
**标签**：稀疏注意力 · 长上下文推理 · 索引延迟 · 知识蒸馏 · GPU 加速

DeepSeek 稀疏注意力（DSA）通过 token 级选择降低注意力计算量，但其索引器仍需为每个 query 对整个因果前缀打分，在长上下文推理中成为主要延迟来源——索引器在长上下文预填充阶段可占据超过 50% 的 GPU 时间。ADIndex 提出层自适应稀疏注意力索引，通过组级蒸馏让不同层共享/复用索引决策，显著削减索引开销。该工作直面长上下文 LLM 推理中"索引比计算更贵"的痛點，对实际部署有较高价值。

**核心要点**：
- 指出 DSA 索引器在长上下文 prefill 中占比超 50% GPU 时间这一关键瓶颈
- 提出层自适应机制，按层特性动态选择稀疏索引策略
- 用组级蒸馏将索引知识在层间迁移，降低逐 query 全前缀打分的成本

- 挖掘 NVIDIA Profiler 未公开的底层指标以提升模型保真度
- 在保持解析速度优势的同时逼近周期级仿真精度

## 7. Token Pooling-Aware Training：面向多向量嵌入模型的训练方法

**来源**：Hugging Face Blog
**链接**：https://huggingface.co/blog/token-pooling
**标签**：多向量嵌入 · 检索 · Token Pooling · 向量压缩 · Sentence-Transformers

多向量嵌入模型为每个 query token 提供独立的文档匹配机会，表达力强但文档向量数量随语料迅速膨胀。Token Pooling 通过自适应池化预算压缩向量数量。本文提出 Token Pooling-Aware Training，在训练阶段即考虑池化策略，配合损失函数包装器与可选核加速，在检索精度与存储/算力成本间取得更好权衡，并给出与现有压缩技术结合的评估结果，对大规模向量检索落地很实用。

**核心要点**：
- 多向量检索表达力强但向量规模随语料爆炸式增长
- 在训练期纳入池化策略，而非事后压缩
- 提供 Sentence-Transformers 损失包装器与可选核加速，可组合现有压缩技术
