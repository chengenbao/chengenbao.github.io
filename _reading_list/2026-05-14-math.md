## 【初二】字母减法谜题

**难度：** ⭐⭐⭐（字母算术，需要逐位分析）

**题目来源：** [NRICH — Kangaroo Subtraction](https://nrich.maths.org/6756)

**知识点：** 数字推理 · 字母算术 · 逐位分析

**题目：**

在下面这道减法算式中，每个字母 K、A、N、G、R、O 各代表一个不同的数字（0-9）：

$$\text{KAN} - \text{GAR} = \text{OO}$$

其中 KAN、GAR 是三位数，OO 是两位数（两个相同的数字）。

**问题：** KAN 的最大可能值是多少？

---

### 解题过程

**第一步：分析 OO（两位重复数字）**

OO 是两位数，且两个数字相同，故 OO = 11, 22, 33, ..., 99。

由于 $\text{KAN} - \text{GAR} = \text{OO}$，从个位看：

个位：$N - R = O$（或借位后 $10 + N - R = O$）

若不借位：$N - R = O$，且 $A - A = 0$，但 OO 的十位和个位都是 O，所以十位也要等于 O。

**第二步：确定 O 的值**

若个位借位：$10 + N - R = O$，则十位：$A - 1 - A = -1$，需从百位借位。

此时：个位 $(10 + N - R) = O$，十位 $(10 + A - 1 - A) = 9 = O$

因此 **O = 9**，即 OO = 99。

**第三步：利用 O = 9 建立方程**

- $10 + N - R = 9 \Rightarrow R = N + 1$
- 百位借位后：$K - 1 = G \Rightarrow K = G + 1$

**第四步：最大化 KAN**

已知 O = 9，现在需要 K, A, N, G, R 各不相同且不等于 9。

要让 KAN 最大：
- 令 K 尽可能大 → K = 8，则 G = 7
- 令 A 尽可能大 → A = 6（9, 8, 7 已用）
- 令 N 尽可能大 → N = 5，但 R = N + 1 = 6 = A，冲突！
- 故 N = 4，R = 5

**验证：** KAN = 864，GAR = 765，OO = 99

$$864 - 765 = 99 \checkmark$$

所有字母：K=8, A=6, N=4, G=7, R=5, O=9，各不相同 ✓

$$\boxed{\text{KAN} = 864}$$

---

### 常见错误

- 忘记处理**借位**的情况，直接假设个位 N - R = O 而非 10 + N - R = O
- 忽略"每个字母代表不同数字"的约束，导致出现重复
- 试图暴力枚举而不分析结构，容易遗漏约束

---

### 知识背景

字母算术（Cryptarithmetic / Alphametics）是一类经典谜题，每个字母对应一个唯一数字。解题关键是**逐列分析进位/借位关系**，将约束逐步缩小，最终唯一确定所有数字。这类问题锻炼逻辑推理和系统性枚举能力，在数学竞赛中常以"数字谜"形式出现。

## 【初三】连续子集和整除性

**难度：** ⭐⭐⭐⭐（需要构造前缀和并应用鸽巢原理）

**题目来源：** [NRICH — Adding in Rows](https://nrich.maths.org/752)

**知识点：** 鸽巢原理 · 前缀和 · 数论 · 整除性

**题目：**

任意列出 3 个整数。

**命题：** 在这 3 个数中，总能找到若干个**相邻**的数，它们的和是 3 的倍数。

（"相邻"意思是这些数在列表中连续排列，子集可以是 1 个、2 个或所有 3 个数。）

**示例：** 列出 5, 7, 1
- 5 和 7 相邻，5 + 7 = 12，是 3 的倍数 ✓

**问题1：** 请证明对**任意** 3 个整数，总能找到这样的连续子集。

**问题2（拓展）：** 对于 4 个整数，是否总能找到连续子集使其和是 4 的倍数？

**问题3（挑战）：** 对于 $n$ 个整数，是否总能找到连续子集使其和是 $n$ 的倍数？

---

### 解题过程

**证明问题1（3个数的情形）：**

设三个整数为 $a_1, a_2, a_3$，考虑前缀和：

$$S_0 = 0,\quad S_1 = a_1,\quad S_2 = a_1 + a_2,\quad S_3 = a_1 + a_2 + a_3$$

这 4 个数模 3 的余数只有 0, 1, 2 三种可能。

由**鸽巢原理**：4 个数中，至少有 2 个余数相同，设 $S_i \equiv S_j \pmod{3}$，其中 $i < j$。

则 $S_j - S_i = a_{i+1} + a_{i+2} + \cdots + a_j \equiv 0 \pmod{3}$

这正是从第 $i+1$ 个到第 $j$ 个数的连续子集，其和是 3 的倍数。

**证明问题3（$n$ 个数的一般情形）：**

同理，构造 $n+1$ 个前缀和 $S_0, S_1, \ldots, S_n$，模 $n$ 只有 $n$ 种余数（0 到 $n-1$）。

由鸽巢原理，$n+1$ 个前缀和中必有 2 个余数相同，差值即为某连续子集之和，且为 $n$ 的倍数。

$$\boxed{\text{对任意 } n \text{ 个整数，总能找到连续子集使和为 } n \text{ 的倍数}}$$

---

### 常见错误

- 不知道构造"前缀和"这一技巧，直接讨论子集容易遗漏情况
- 混淆"鸽巢原理"的使用——需要 $n+1$ 个对象放入 $n$ 个抽屉
- 对"相邻子集"和"任意子集"的区别理解不清楚

---

### 知识背景

**鸽巢原理（Pigeonhole Principle）**：若将 $n+1$ 个物体放入 $n$ 个抽屉，则至少有一个抽屉包含 2 个或更多物体。这是组合数学中最基本也最强大的工具之一。**前缀和**技巧（将 $S_k = a_1 + \cdots + a_k$）是处理"连续子数组"问题的标准方法，将区间求和转化为端点差值问题。两者结合，能优雅解决大量整除性问题。
