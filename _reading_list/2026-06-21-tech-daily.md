## 1. Contagion Networks：LLM 评估器偏差在多智能体系统中的传播机制

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.20493  
**标签**：多智能体系统 · LLM评估偏差 · 传播矩阵 · DeepSeek · 偏差量化

当大型语言模型作为评估器嵌入多智能体系统时，其系统性评估偏差会沿智能体网络传播扩散。本文提出 Contagion Networks 形式化框架，用于度量评估器偏差在交互 LLM 智能体间的传播。在基于 DeepSeek-chat 的 3-agent 受控实验中，研究者测量了跨智能体传播矩阵 Γ₃，发现即便底层模型相同，不同偏差配置（结构化/平衡/证据导向）之间偏差仍会持续传播（γ ∈ [0.157, 0.352]）。研究结果对依赖 LLM-as-judge 评估的多智能体训练流程具有重要的方法论警示意义。

**核心要点**：
- 提出 Contagion Networks 框架，首次系统量化 LLM 多智能体系统中评估偏差的传播路径
- 实测跨智能体传播系数 γ 最高达 0.352，说明偏差扩散程度不可忽视
- 即使使用同一基础模型，不同提示策略引入的偏差配置也会互相"感染"
- 对 RLHF 多轮评估、自动化红队测试等流程的可信度提出质疑

## 2. CloakLM：通过 GPU 内存布局混淆防御模型窃取攻击

**来源**：arXiv cs.OS  
**链接**：https://arxiv.org/abs/2606.18400  
**标签**：GPU安全 · 模型窃取防御 · 内存混淆 · PCIe侧信道 · LLM部署安全

部署在第三方加速器基础设施上的大型基础模型面临实际的模型窃取风险。Hermes 已展示可通过被动 PCIe 观测无损重建 DNN，TunnelS 则实现了 HBM 内容的侧信道窃取。CloakLM 针对此威胁，在保持推理精度的前提下，对 GPU 内存布局实施混淆处理，使旁路观测者无法还原完整模型权重，为共享云 GPU 环境中的 LLM 服务商提供了一种实用的主动防御方案。

**核心要点**：
- 聚焦 PCIe 互连和 HBM 侧信道威胁，针对模型服务租户的实际攻击面
- 内存布局混淆在不修改模型权重本身的情况下提升重建难度
- 对第三方 GPU 云（无 TEE 环境）的 LLM 服务部署有直接防护价值
- 展示了 OS 层安全机制与 AI 服务安全需求的交叉研究方向

## 3. LiveStack：支持集群规模全栈实时仿真的操作系统机制

**来源**：arXiv cs.OS  
**链接**：https://arxiv.org/abs/2606.18958  
**标签**：集群仿真 · OS虚拟化 · 全栈保真度 · 分布式系统 · Linux虚拟化栈

在大规模分布式软件栈和新兴硬件组件部署前，集群级全栈仿真至关重要。LiveStack 是一套基于 Linux 虚拟化栈的 OS 级集群仿真方案，包含四个子系统：面向仿真的调度器、实时内存层次管理、仿真感知存储子系统，以及快速网络仿真层。该系统能在不修改生产软件栈的前提下，同时实现全栈保真度与足够的仿真吞吐，为迭代式配置探索提供了工程基础。

**核心要点**：
- 解决现有方法无法同时满足"全栈保真度"与"仿真性能"的矛盾
- 基于 Linux 虚拟化栈，无需修改被仿真的生产软件
- 四子系统协同：调度/内存层次/存储/网络，覆盖仿真全链路
- 对新型 AI 加速硬件上线前的验证流程有重要工程价值

## 4. Direct Advantage Estimation：可扩展的样本高效深度强化学习

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.20411  
**标签**：深度强化学习 · 优势函数估计 · 部分可观测 · 离散隐变量 · 样本效率

Direct Advantage Estimation（DAE）已被证明能提升深度强化学习的样本效率，但其对完全可观测环境的依赖限制了实际应用，而转移概率建模对高维观测带来了巨大计算开销。本文从两方面突破：一是将 DAE 的理论框架以最小修改扩展到部分可观测域；二是通过引入离散隐变量动力学模型，将计算复杂度从全维度降至隐空间规模，大幅降低了高维场景下的运算负担。

**核心要点**：
- 将 DAE 从完全可观测扩展到部分可观测（POMDP）设置，适用范围大幅扩大
- 离散隐变量动力学模型将转移概率建模的计算复杂度降低至隐空间量级
- 在保证样本效率优势的同时减少了对精确环境模型的依赖
- 对视觉输入强化学习、机器人控制等高维场景具有直接的工程应用价值

## 5. Sparsity, Superposition, and Forgetting：连续学习中表征保留的机制研究

**来源**：arXiv cs.LG  
**链接**：https://arxiv.org/abs/2606.20431  
**标签**：连续学习 · 灾难性遗忘 · 特征叠加 · 表征稀疏性 · 可解释性

连续学习（CL）系统频繁遭遇灾难性遗忘，但其内部机制在真实数据集上难以隔离研究。本文构建了一套可控的玩具世界框架：通过合成生成器-分离器流水线定义地面真值隐变量特征，构造具有可调稀疏度和任务重叠度的实验任务，并引入"表征强度"和"叠加度"的可测量指标。研究揭示了稀疏性和特征叠加如何分别影响知识保留与遗忘的时序动态，为网络剪枝与连续学习交叉研究提供了机制层面的理解。

**核心要点**：
- 首次在受控合成环境下将稀疏性、特征叠加、遗忘三者的因果关系可测量化
- 引入"叠加度"（特征间方向重叠）作为遗忘风险的新型量化指标
- 揭示任务重叠度与稀疏度对遗忘速率的非线性交互效应
- 为 LLM 持续训练（continual fine-tuning）的灾难性遗忘问题提供机制视角

## 6. Whisper 点积核卸载：CGLA 架构上的能效优化实践

**来源**：arXiv cs.AR  
**链接**：https://arxiv.org/abs/2606.19913  
**标签**：点积核 · CGLA架构 · 能效优化 · FP16推理 · 边缘AI

本文在 IMAX（一种可编程粗粒度线性阵列 CGLA 架构）上实现并评估了 Whisper 点积核的卸载方案。在 ARM Cortex-A72 上的 profiling 显示，点积运算占 FP16 执行时间的 90.6%、Q8_0 执行时间的 87.1%，是明确的计算瓶颈。通过组合内核映射、本地内存大小调优和突发调度，结合 FP16-FP32 内联转换、2-way SIMD FMA 及列向多线程，实现了向量段在 IMAX 与 ARM 间的混合执行，有效降低了边缘推理能耗。

**核心要点**：
- 实证确认点积运算是 Whisper 边缘推理的主要计算瓶颈（占比 87-91%）
- IMAX CGLA 架构支持可编程向量化，适合端侧 AI 推理加速
- 混合执行策略（aligned 段走 IMAX，非对齐段走 ARM）兼顾了灵活性与效率
- 对 IoT/边缘设备上运行语音模型推理具有直接的工程参考价值

## 7. BabelTele：LLM 未必需要人类可读的语言

**来源**：arXiv cs.CL  
**链接**：https://arxiv.org/abs/2606.19857  
**标签**：LLM表征 · 非标准编码 · 模型间通信 · 压缩表示 · token效率

LLM 通常通过人类可读的自然语言进行提示和交互，即便目标读者是另一个模型。本文探究语义信息是否可被编码为紧凑的非标准文本形式（BabelTele）——牺牲人类可读性但可被 LLM 恢复。研究通过可读性诊断、模型似然度量和下游任务评估，发现 LLM 确实具备生成和解释此类表征的能力。该发现对模型间通信协议设计、prompt 压缩以及 context window 利用效率具有重要的实践启示。

**核心要点**：
- 提出 BabelTele 概念：面向模型消费者的紧凑非可读表征，而非人类
- 实验证明 LLM 能生成和解释牺牲可读性的压缩语义编码
- 对多智能体系统中的内部通信协议设计有直接设计启发
- 为 prompt 工程中的 token 效率优化提供了全新研究方向
