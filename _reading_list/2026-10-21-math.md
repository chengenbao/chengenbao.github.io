## 【代数】四项式乘积的最小值

**难度：** ⭐⭐⭐（高中竞赛难度 · 多项式配方与完全平方非负性）

**题目来源：** [2019 AMC 10A Problem 19](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_19)

**知识点：** 对称配对（pairing） · 换元 · 完全平方公式 · 最值问题

**题目：**

当 $x$ 为实数时，表达式

$$(x+1)(x+2)(x+3)(x+4)+2019$$

的最小可能值是多少？

$\textbf{(A) } 2017 \qquad\textbf{(B) } 2018 \qquad\textbf{(C) } 2019 \qquad\textbf{(D) } 2020 \qquad\textbf{(E) } 2021$

---

### 解题过程

1. 观察到四个因式是连续的，采用**首尾配对**：
   $$(x+1)(x+4)=x^2+5x+4,\qquad (x+2)(x+3)=x^2+5x+6$$

2. 令中间量 $t=x^2+5x+5$，则
   $$(x+1)(x+4)=t-1,\qquad (x+2)(x+3)=t+1$$

3. 原式化为
   $$(t-1)(t+1)+2019=t^2-1+2019=t^2+2018$$

4. 因为 $t^2\ge 0$，所以表达式 $\ge 2018$。

5. 验证可取等：当 $t=0$ 即 $x^2+5x+5=0$ 时，判别式 $\Delta=25-20=5>0$，存在实数解（$x=\frac{-5\pm\sqrt5}{2}$），故最小值 **2018** 可以达到。

**答案：$\textbf{(B) } 2018$**

---

### 常见错误

- 直接把四个因式完全展开，陷入繁琐的多项式，容易算错系数。
- 配方后得到 $t^2+2018$ 却怀疑 $t=0$ 能否取到，忘记检验 $x^2+5x+5=0$ 有实根，从而误以为最小值不能达到。

---

### 知识背景

对称配对是处理“连续整数乘积”类最值问题的经典技巧：当首尾配对能化成平方差 $(t-a)(t+a)=t^2-a^2$ 时，令中间量 $t$ 即可把问题转化为完全平方的非负性。这种“换元 + 配方 + 非负性下界”的组合在 AMC 10/12 与 AIME 中频繁出现，是代数基本功的体现。

## 【几何】两条直线与截线围成的三角形面积

**难度：** ⭐⭐⭐（高中竞赛难度 · 解析几何求交点与面积）

**题目来源：** [2019 AMC 10A Problem 7](https://artofproblemsolving.com/wiki/index.php/2019_AMC_10A_Problems/Problem_7)

**知识点：** 点斜式直线方程 · 联立求交点 · 鞋带公式（Shoelace）求面积

**题目：**

两条斜率分别为 $\frac12$ 和 $2$ 的直线交于点 $(2,2)$。这两条直线与直线 $x+y=10$ 围成的三角形面积是多少？

$\textbf{(A) } 4 \qquad\textbf{(B) } 4\sqrt2 \qquad\textbf{(C) } 6 \qquad\textbf{(D) } 8 \qquad\textbf{(E) } 16$

（橙线为 $y=\frac12x+1$，蓝线为 $y=2x-2$，绿线为 $x+y=10$；红色三角形即所求区域。）

---

### 解题过程

1. 写出三条直线的方程（均过点或已知斜率）：
   - 斜率 $\frac12$ 过 $(2,2)$：$y-2=\frac12(x-2)\;\Rightarrow\; y=\frac12x+1$
   - 斜率 $2$ 过 $(2,2)$：$y-2=2(x-2)\;\Rightarrow\; y=2x-2$
   - 截线：$x+y=10\;\Rightarrow\; y=10-x$

2. 求三个顶点（两线交点）：
   - 前两线交点：显然为 $(2,2)$
   - 第一线与截线：$\frac12x+1=10-x\;\Rightarrow\;\frac32x=9\;\Rightarrow\;x=6,\ y=4$，得 $(6,4)$
   - 第二线与截线：$2x-2=10-x\;\Rightarrow\;3x=12\;\Rightarrow\;x=4,\ y=6$，得 $(4,6)$

3. 用**鞋带公式**求三角形面积（顶点按 $(2,2),(6,4),(4,6)$ 排列）：
   $$\begin{aligned}
   S&=\frac12\bigl|2\cdot4+6\cdot6+4\cdot2-(2\cdot6+4\cdot4+6\cdot2)\bigr|\\
   &=\frac12\bigl|(8+36+8)-(12+16+12)\bigr|\\
   &=\frac12|\,52-40\,|=\frac{12}{2}=6
   \end{aligned}$$

**答案：$\textbf{(C) } 6$**

---

### 常见错误

- 点斜式写错符号，例如把 $y-2=2(x-2)$ 误算成 $y=2x+2$。
- 联立解方程时把 $x+y=10$ 与 $\frac12x+1$ 联立算错，得到错误交点。
- 鞋带公式忘记除以 $2$，或顶点顺序导致正负号处理出错。

---

### 知识背景

解析几何中计算三角形面积有三种常用方法：① **解析法（鞋带公式 / 行列式）**，已知三顶点坐标即可直接套用；② **底 × 高 ÷ 2**，取一边为底、用点到直线距离公式求高；③ **向量叉积** $\frac12|\vec{AB}\times\vec{AC}|$。本题各系数很小，直接求三顶点再用鞋带公式最快，是 AMC 10 中高频的“直线与面积”题型。
