## 【数论】三角数中的完全平方数

**难度：** ⭐⭐⭐⭐（高中竞赛难度，需要识别佩尔方程结构并递推求解）

**题目来源：** [2022 AMC 12A Problem 16](https://artofproblemsolving.com/wiki/index.php/2022_AMC_12A_Problems/Problem_16)

**知识点：** 三角数与求和公式 · 佩尔方程（Pell equation）

**题目：**

称正整数 $t_n = 1+2+3+\cdots+n$（$n$ 为正整数）为**三角数**。既是三角数又是完全平方数的三个最小的数是

$$t_1 = 1 = 1^2,\qquad t_8 = 36 = 6^2,\qquad t_{49} = 1225 = 35^2 .$$

求第四小的既是三角数又是完全平方数的数的**各位数字之和**。

$$\textbf{(A) } 6 \qquad \textbf{(B) } 9 \qquad \textbf{(C) } 12 \qquad \textbf{(D) } 18 \qquad \textbf{(E) } 27$$

---

### 解题过程

**第一步：把条件写成方程。**

三角数的通项为

$$t_n=\frac{n(n+1)}{2}.$$

若 $t_n$ 是完全平方数，设 $t_n=k^2$（$k$ 为正整数），则

$$\frac{n(n+1)}{2}=k^{2}\quad\Longleftrightarrow\quad n(n+1)=2k^{2}.$$

**第二步：配方，化成佩尔方程。**

两边乘 $4$ 再加 $1$：

$$4n^{2}+4n+1=8k^{2}+1,$$

即

$$(2n+1)^{2}-2(2k)^{2}=1 .$$

令 $x=2n+1,\ y=2k$，得到标准佩尔方程

$$x^{2}-2y^{2}=1 .$$

**第三步：用最小解递推生成全部解。**

$x^2-2y^2=1$ 的基本解是 $(x_1,y_1)=(3,2)$，对应 $n=1,k=1$，即 $t_1=1$。全部正整数解由

$$x_{m}+y_{m}\sqrt2=(3+2\sqrt2)^{m}$$

给出。逐次展开：

- $m=1$：$3+2\sqrt2\Rightarrow (x,y)=(3,2)\Rightarrow n=1,\ k=1,\ t_1=1$
- $m=2$：$(3+2\sqrt2)^2=17+12\sqrt2\Rightarrow (x,y)=(17,12)\Rightarrow n=8,\ k=6,\ t_8=36$
- $m=3$：$(3+2\sqrt2)^3=99+70\sqrt2\Rightarrow (x,y)=(99,70)\Rightarrow n=49,\ k=35,\ t_{49}=1225$
- $m=4$：$(3+2\sqrt2)^4=577+408\sqrt2\Rightarrow (x,y)=(577,408)$

前三个解恰好对应题目给出的三个数，说明递推正确。

**第四步：算出第四个解。**

由 $x=2n+1=577$ 得 $n=288$；由 $y=2k=408$ 得 $k=204$。于是

$$t_{288}=\frac{288\cdot 289}{2}=144\cdot 289=41616=204^{2}.$$

**第五步：求数字和。**

$$4+1+6+1+6=18 .$$

**答案：$\boxed{\textbf{(D) } 18}$**

---

### 常见错误

- 直接暴力枚举 $n$，没有意识到解的增长是**指数级**的（$1,8,49,288,1681,\dots$），手算时误以为第四个 $n$ 只是几十的量级。
- 配方时忘记乘 $4$，写成 $(n+1)^2-\cdots$ 之类的形式，无法得到系数为 $1$ 的佩尔方程。
- 求出 $(x,y)=(577,408)$ 后忘记还原：$n=(x-1)/2$、$k=y/2$，误把 $577$ 或 $408$ 当成答案去求数字和。
- 最后一步算成 $204^2$ 的位数或 $t_{288}$ 的因数个数，而题目问的是**各位数字之和**。

---

### 知识背景

佩尔方程指形如 $x^2-Dy^2=1$（$D$ 为非平方正整数）的丢番图方程。拉格朗日证明它总有无穷多组正整数解，且全部解可由最小解 $(x_1,y_1)$ 通过 $x_m+y_m\sqrt D=(x_1+y_1\sqrt D)^m$ 生成——本质是二次域 $\mathbb{Z}[\sqrt D]$ 中单位元的幂。最小解可由 $\sqrt D$ 的连分数展开得到，$\sqrt2=[1;\overline{2}]$ 的渐近分数 $\frac32,\frac{17}{12},\frac{99}{70},\frac{577}{408}$ 正是本题各解。"平方三角数"是佩尔方程最经典的应用之一，其序列 $1,36,1225,41616,\dots$ 满足递推 $a_{m+1}=34a_m-a_{m-1}+2$。

## 【组合】重复数列的中位数

**难度：** ⭐⭐⭐（高中竞赛难度，考查计数与中位数定义的精确配合）

**题目来源：** [2021 AMC 12A Problem 16](https://artofproblemsolving.com/wiki/index.php/2021_AMC_12A_Problems/Problem_16)

**知识点：** 计数与求和 · 中位数定位

**题目：**

在下面的数列中，对每个 $1 \le n \le 200$，整数 $n$ 恰好出现 $n$ 次：

$$1,\ 2,\ 2,\ 3,\ 3,\ 3,\ 4,\ 4,\ 4,\ 4,\ \ldots,\ 200,\ 200,\ \ldots,\ 200 .$$

求这个数列所有数的中位数。

$$\textbf{(A) } 100.5 \qquad \textbf{(B) } 134 \qquad \textbf{(C) } 142 \qquad \textbf{(D) } 150.5 \qquad \textbf{(E) } 167$$

---

### 解题过程

**第一步：数清总项数。**

$$N=1+2+\cdots+200=\frac{200\cdot 201}{2}=20100 .$$

$N$ 是偶数，所以中位数是第 $10050$ 项与第 $10051$ 项的平均值。

**第二步：写出前缀计数。**

不超过 $k$ 的数共出现

$$S(k)=1+2+\cdots+k=\frac{k(k+1)}{2}$$

次。也就是说数值 $k$ 占据的位置区间是 $\left[S(k-1)+1,\ S(k)\right]$。

**第三步：找出包含第 10050 项的 $k$。**

需要求最小的 $k$ 使 $S(k)\ge 10050$，即

$$\frac{k(k+1)}{2}\ge 10050 \quad\Longleftrightarrow\quad k(k+1)\ge 20100 .$$

由 $\sqrt{20100}\approx 141.8$ 先试 $k=141$ 与 $k=142$：

$$S(141)=\frac{141\cdot 142}{2}=10011,\qquad S(142)=\frac{142\cdot 143}{2}=10153 .$$

**第四步：定位。**

因为 $S(141)=10011 < 10050$ 而 $S(142)=10153 \ge 10051$，所以数值 $142$ 占据第 $10012$ 到第 $10153$ 位。第 $10050$ 项和第 $10051$ 项都落在这个区间内，两者都等于 $142$。

$$\text{中位数}=\frac{142+142}{2}=142 .$$

**答案：$\boxed{\textbf{(C) } 142}$**

---

### 常见错误

- 把中位数理解成"数值范围 $1\sim 200$ 的中点"，直接答 $100.5$（选项 A 就是这个陷阱）。
- 忘记总项数 $20100$ 是偶数，需要同时检查第 $10050$ 和第 $10051$ 两项；若两项恰好跨越边界，答案会是 $x.5$ 形式（选项 A、D 正是为此设置）。
- 前缀和用错端点：把 $k$ 的位置区间写成 $[S(k),\,S(k+1)]$，导致答案偏移一位。
- 近似 $\sqrt{20100}\approx 142$ 后直接下结论而不验算 $S(141)$，运气不好就会选错相邻整数。

---

### 知识背景

这类"按权重重复出现"的数列，本质是把离散分布的**累积分布函数**离散化。设值 $k$ 的频数为 $w_k$，前缀和 $S(k)=\sum_{j\le k} w_j$ 就是累积计数，中位数即满足 $S(k)\ge N/2$ 的最小 $k$——这与连续情形下解 $F(x)=1/2$ 完全对应。本题的 $w_k=k$ 使 $S(k)$ 恰为三角数，于是中位数近似满足 $k^2/2\approx N/2$，即 $k\approx \frac{200}{\sqrt2}\approx 141.4$。一般地，若 $w_k=k^{p}$，则中位数约为 $200\cdot 2^{-1/(p+1)}$，可以作为快速估算的心算工具。有趣的是本题第一题的三角数也在这里出现了——同一个 $\frac{k(k+1)}{2}$，在数论与组合两个语境中扮演了完全不同的角色。
