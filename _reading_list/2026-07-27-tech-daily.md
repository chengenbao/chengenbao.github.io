## 1. Windowed-MTP：消除百万级上下文中全量草稿 KV 的开销

**来源**：arXiv cs.LG  
**链接**：http://arxiv.org/abs/2607.21535v1
**标签**：投机解码 · MTP · KV缓存 · 长上下文 · 推理加速

投机解码通过廉价草稿模型并行提议 token 来加速自回归生成，但前沿模型内置的 Multi-Token-Prediction（MTP）草稿头在百万 token 上下文下需要维护全量草稿 KV 缓存，带来巨大的显存与带宽开销。本文提出 Windowed-MTP，将草稿头的注意力窗口化，仅保留近期上下文的草稿 KV，从而在超长上下文场景下消除这一“草稿 KV 税”，同时保持接受率与生成质量。

**核心要点**：
- 定位百万级上下文下 MTP 草稿头全量 KV 缓存的显存/带宽瓶颈
- 以窗口化注意力替代全上下文草稿 KV，仅保留近期上下文
- 在保持投机解码接受率的同时大幅降低长上下文推理成本

## 2. KV 缓存驱逐的错误证书：基于随机化设计的可验证保障

**来源**：arXiv cs.CL  
**链接**：http://arxiv.org/abs/2607.21475v1
**标签**：KV缓存 · 缓存驱逐 · 随机化算法 · 误差界 · LLM推理

确定性 KV 缓存驱逐策略按重要性分数保留 top-k token 并删除其余部分，但本文证明这种设计“无法知道自己毁掉了什么”——被驱逐的值可以被任意篡改而服务系统无法察觉。作者提出基于随机化设计的驱逐机制，为缓存驱逐提供可计算的错误证书，使系统能够量化驱逐操作对输出的潜在影响。

**核心要点**：
- 从理论上证明确定性 top-k 驱逐无法检测被驱逐信息的损失
- 引入随机化驱逐设计，为每次驱逐生成可验证的误差证书
- 为生产环境 KV 缓存压缩提供了可量化的正确性保障思路

- 为 Apple Silicon 端侧 LLM 推理树立性能标杆

**链接**：http://arxiv.org/abs/2607.19922v1

随着 GPU 核心与显存规模持续膨胀，现代大型 GPU 内部呈现出显著的 NUMA（非一致内存访问）特性。本文提出 DGNA 框架，通过系统化微基准测试与数据分析揭示 GPU 内部的 NUMA 拓扑、访存延迟差异与带宽分布，帮助开发者理解并优化 kernel 在大型 GPU 上的数据布局与调度策略。

**核心要点**：
- 设计微基准系统探测 GPU 内部 NUMA 拓扑与访存特性
- 量化跨分区访存的延迟与带宽差异
- 为大型 GPU 上的 kernel 优化和数据布局提供实证依据

## 5. 受控周期性同步：高效数据并行训练的新范式

**链接**：http://arxiv.org/abs/2607.21224v1
**标签**：数据并行 · 梯度同步 · 分布式训练 · 通信优化 · DDP

标准 DDP 在每次迭代都同步梯度，在高速局域网中表现良好，但随着集群规模扩大与网络异构化，通信开销日益成为瓶颈。本文提出受控周期性同步方法，允许 worker 在多个迭代间局部更新后再同步，通过控制同步周期在收敛质量与通信效率间取得平衡，显著提升带宽受限环境下的训练吞吐。

**核心要点**：
- 分析每步全量梯度同步在慢速/异构网络下的通信瓶颈
- 提出受控周期性同步机制，在局部更新与全局一致性间动态权衡
- 在带宽受限集群上提升数据并行训练的端到端吞吐
