## 1. NVIDIA H100 上普通全局加载的并发响应特性

**来源**：arXiv/cs.AR
**链接**：https://arxiv.org/abs/2608.15764v1
**标签**：GPU · CUDA · H100 · 显存带宽 · Little's Law

本文从吞吐核算（而非实验测量的硬件池）视角出发，利用 Little's Law 解析 H100（Hopper）上内存受限算子的带宽上限。研究指出，CUDA 通过普通全局加载（ld.global）与异步拷贝（cp.async）等路径为该预算填充在途字节数，而这些机制的并发行为直接决定了内存受限 kernel 能维持的有效带宽。文章为编写高带宽利用率的 GPU kernel 提供了定量依据。

**核心要点**：
- 用 Little's Law 将吞吐建模为在途字节数与延迟的关系，而非直接测量硬件池
- 量化 H100 上 ld.global 与 cp.async 等路径对显存带宽预算的填充方式
- 揭示并发加载结构如何影响内存受限算子的有效带宽上限，指导高性能 kernel 编写

## 2. Beyond Capacity：基于高带宽闪存与直连 GPU/HBM 路径的可扩展 MoE 大模型推理

**来源**：arXiv/cs.AR
**链接**：https://arxiv.org/abs/2608.14333v1
**标签**：MoE · 推理加速 · HBM · 高带宽闪存 · 显存卸载

现代混合专家（MoE）语言模型的专家权重快速增长，对靠近 GPU 的高带宽内存（HBM）的容量与成本效率提出严峻挑战。高带宽闪存（HBF）提供更大容量，但传统设计通常让 GPU 与 HBF 经 HBM 间接通信而引入瓶颈。本文提出直连 GPU 与 HBM 路径的架构，实现超 HBM 容量限制的可扩展 MoE 推理，在容量、成本与延迟之间取得更好平衡。

**核心要点**：
- 指出现有 MoE 推理受限于 HBM 容量与成本，HBF 是更具潜力的替代存储层
- 设计 GPU 与 HBM 直连 HBF 的数据通路，绕开传统间接通信瓶颈
- 在超出 HBM 容量规模下实现可扩展推理，兼顾成本与延迟

## 3. DTX：面向扩散模型与 Transformer 的吞吐优先训练加速器

**来源**：arXiv/cs.AR
**链接**：https://arxiv.org/abs/2608.16953v1
**标签**：训练加速器 · Transformer · 扩散模型 · FP32归约 · 硬件架构

任何经单一 FP32 加法器串行求和的归约都会形成循环携带依赖，使机器无论物理设计如何都被钉死在约 2 FLOP/cycle。DTX 是一款面向扩散模型与 Transformer 的吞吐优先训练加速器，其设计保证不存在任何此类链——每个归约都可在硬件上并行展开，从而摆脱串行求和的吞吐天花板。该工作为大规模生成式模型训练提供了架构层面的吞吐优化思路。

**核心要点**：
- 揭示串行 FP32 归约是限制训练加速器吞吐的结构性瓶颈（约 2 FLOP/cycle）
- DTX 通过消除所有循环携带归约依赖实现并行化归约
- 面向 Diffusion 与 Transformer 训练，在架构层面提升而非堆叠峰值算力

## 4. 基于图结构在线难度估计的高效 RLVR 调度

**核心要点**：
- 指出 RLVR 中均匀分配 rollout 预算导致简单样本冗余、困难样本不足
- 用图结构刻画样本间关系，在线估计难度以指导探索预算分配
- 在保持推理能力提升的同时显著降低训练计算开销
