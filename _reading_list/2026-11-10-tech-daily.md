## 1. BitDecoding-FP4：基于算法-系统协同设计的原生 FP4 KV 缓存解码

**来源**：cs.AR (arXiv)
**链接**：https://arxiv.org/abs/2611.09825
**标签**：FP4 量化 · KV Cache · 算法-系统协同 · GPU Tensor Core · 长上下文推理

随着长上下文 LLM 服务普及，KV 缓存对显存容量与带宽的占用成为主要瓶颈。本文提出 BitDecoding-FP4，将 NVFP4/MXFP4 等 4-bit 微缩放格式贯穿 KV 缓存压缩与注意力计算，使注意力可直接在 FP4 Tensor Core 上执行，从算法与系统两层协同消除精度损失与数据搬运开销。

**核心要点**：
- 用 FP4 微缩放格式压缩 KV 缓存，显著降低显存与带宽压力
- 注意力计算直接在 FP4 Tensor Core 上完成，避免反复反量化
- 算法-系统协同设计在 4-bit 下保持接近 FP16 的解码精度

## 2. DUET：面向块扩散语言模型的双稀疏推理

**来源**：cs.CL (arXiv)
**链接**：https://arxiv.org/abs/2611.09239
**标签**：扩散语言模型 · 双稀疏 · 推理加速 · 块生成 · 注意力优化

扩散语言模型（DLM）通过迭代去噪实现并行 token 生成，但推理成本高——每次迭代都要对不断增长的上下文前缀重复做注意力计算。DUET 提出双稀疏推理机制，在序列维与特征维同时稀疏化，削减冗余计算，在保持生成质量的同时大幅加速块扩散模型的推理。

**核心要点**：
- 识别扩散 LM 推理中重复注意力计算的冗余来源
- 序列维与特征维双管齐下实现稀疏化
- 在不牺牲生成质量前提下显著降低推理开销
